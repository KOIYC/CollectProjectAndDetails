Agent-powered work.”  Listodo is a local desktop task tracker that can hand tasks to an agent. Capture tasks and checklists in Markdown, schedule them on a calendar, and run any task with **Codex** or **Claude Code** in a project folder you choose. Follow the live output, continue the session with follow-ups, and mark the task done when you have reviewed the result. Everything is stored locally in SQLite, with no account or hosted backend.  Built with **Go, SQLite, React, and shadcn/ui**. The macOS app uses the system’s native WKWebView instead of Electron.
