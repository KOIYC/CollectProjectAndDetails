Sugar Cube - 8x8 Pixel Font by Kebap Guy  # Sugar Cube - 8x8 Pixel Font  A downloadable font  ## Sugar Cube  An 8×8 pixel font for the kind of text a game actually needs: menu items, dialogue boxes, item lists, damage numbers and tiny footer lines.  Every stroke sits on the 8×8 grid, so at 8, 16, 24 or 32 px the text comes out razor sharp. No blur, no half-lit edges, no fighting with your engine.  ### What's inside  - Sugar Cube.ttf — TrueType, for game engines, desktop and Aseprite - Sugar Cube.otf — OpenType, for Photoshop, Figma and Illustrator - Sugar Cube.woff2 — web font, for web games and websites - bitmap/ — a PNG font sheet and a `.fnt` file for engines that don't load TrueType: Godot 3, GameMaker, Löve2D, Phaser, LibGDX, MonoGame, Defold, Construct - web/ — a ready-made `@font-face` stylesheet and a demo page you can open in a browser and type into - specimen.png — every character at a glance - README.txt — the exact settings to tick in Godot, Unity and GameMaker  ### Character set — 109 glyphs  - A–Z and a–z - 0–9 - Punctuation and symbols: !
