大家好，距离上次发帖已经过去挺久了。原因是 7 月底，我又失业了，哈哈哈。  不过这次失业我到没有那么焦虑了，原因是通过这一年的折腾，副业还是有了点成果。  然后就是哪怕失业了，我跟朋友那边也在合作做一些游戏项目，目前有稳定的订单，虽然赚的不多，但是起码饿不死。  然后我最近几个月呢，也在打磨自己的全新的产品[SpriteCanvas]( https://spritecanvas.com/zh/?utm_source=v2ex&utm_medium=social&utm_campaign=v2ex-create)，一个给 2D 游戏做角色动画的工具。  起因是自己做小游戏：角色立绘用 AI 很快就能出，但一到“让它动起来”就卡住。逐帧手画不现实；用视频模型生成一段动画，又得自己抽帧、抠背景、对齐脚底、拼成图集、写每帧时长，一套下来比做游戏还累。SpriteCanvas 就是把这条链路做完，最后给你一张游戏引擎能直接用的精灵图。  ## 效果  一张参考图，生成待机和攻击动画（ 35 帧，透明背景）：  ![一张参考图生成待机和攻击动画](  )  剑士三连击，38 帧：  ![剑士三连击](  )  技能特效也能单独生成，每个 6 帧、透明背景：  ![火球、闪电、爆炸特效](  )  导出时可以勾“像素风”，每帧重绘到小像素网格上，整张精灵图共用一套 32 色调色板，帧与帧之间颜色不闪：  ![普通导出和像素风导出对比](  )  ## 怎么用  1. 描述角色，或者上传你已有的角色图。一次出几张候选，挑一张。 2. 选动作：待机、行走、奔跑、攻击、跳跃是内置的，也可以自己写动作描述。所有动作都从同一个角色生成，造型不会跑偏。 3. 逐帧检查，选帧范围和帧数。 4. 导出 PNG 精灵图和 JSON 图集。JSON 是 Phaser 、PixiJS 能直接读的 JSON Hash 格式，带每帧时长和脚底锚点。  做完还能在内置试玩场里用键盘跑、跳、打几下，先看看手感：  ![工作台](  )  首页就有一个能玩的示例场景，不用注册：  ![首页](  )  视频演示（ YouTube Shorts ）： https://youtube.com/shorts/vfHBoUoWIm4  ## 不用登录的免费工具  顺手做了几个小工具，都在浏览器里本地处理，不用注册：  - [精灵图切片]( https://spritecanvas.com/zh/sprite-sheet-slicer/?utm_source=v2ex&utm_medium=social&utm_campaign=v2ex-create)：把一张精灵图切成单帧 - [GIF 转精灵图]( http…
