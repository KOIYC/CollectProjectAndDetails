## 摘要正文

Hi everyone,  For the ones who followed along: 640 stars now, up from 100 when I first posted here. Still the same messy solo side project, but v1.0 changed what it can do.  The short version of why it exists: I keep losing the thread when I walk away from a project. Notes in one app, configs in another, no big picture. So I built a canvas where all of it connects. That part you know.  What's new in v1.0 is the part I'm proudest of: the canvas is now a Git artifact. A project syncs to a repo, structure, notes and block positions version-controlled inside a .ideon/ directory with checksums. The rest of your repo stays untouched. You edit the canvas, you push, and the history sits in Git like code. Diffs, reviews, rollback. Not my cloud, your repo.  Also in 1.0: database block with typed columns, mermaid with live rendering, and a chained audit trail so every state change is traceable.  What's next: a plugin API so people can build their own block types, and a desktop app once the project grows enough to justify it.
