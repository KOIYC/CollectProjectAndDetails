# vinodhalaharvi/camwall  Every camera feed on one gap-free wall. Built on dyna and FFmpeg.  - Stars: 1 - Forks: 0 - Watchers: 1 - Open issues: 0 - License: MIT License - Default branch: main - Created: 2026-11-08T15:10:38Z  ## Languages  - Go - HTML - Makefile - Ruby  ## Top Contributors  - vinodhalaharvi (14 contributions)  ---  ## README  # camwall  Every camera feed on one gap-free wall: in your browser, or as one combined video stream.  camwall is for a shop manager who wants all their cameras in one place. Give it IP cameras, network streams, web videos, the computer's own camera, video files, animations or a still image or two. It finds the arrangement that shows the smallest feed as large as possible and fills your screen, trimming at most a sliver off a feed's edges to do it (or none, if you ask for whole pictures). Nothing is ever stretched.  Six pet cameras and a still photo on one wall  ```sh camwall serve rtsp://192.168.1.20/stream1 rtsp://192.168.1.21/stream1 rtsp://192.168.1.22/stream1 logo.png ```  Dragging the screen shape: the wall re-solves on every frame  ## Install  ```sh brew install vinodhalaharvi/tap/camwall ```  That's all: Homebrew installs FFmpeg with it.…
