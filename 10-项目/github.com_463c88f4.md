## 摘要正文

Hi HN, I'm Matteo from meshapplied (YC W27), building this with Peter and Janos.We think you can and should own your inference, so we built software that actually supports that. Goethe turns a Linux machine with an NVIDIA GPU into an API your OpenAI, Anthropic compatible clients can call.``` curl -fsSL https://goethe.sh/install.sh | bash goethe start ```Limits: it's Linux only rn and it supports Ampere or newer NVIDIA GPUs. Logging in with `goethe login` is optional and turns on the optimized kernels.Docs: [goethe.sh/docs](https://goethe.sh/docs)I'd love to hear what breaks and what you'd want next.
