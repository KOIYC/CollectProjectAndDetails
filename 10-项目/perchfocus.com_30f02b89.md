I'm an engineer, but I also hate using tools that make things overcomplicated.It's also tough with the new pace of AI-driven development to really get into the flow state, and maintain (still needed!) focus on 1 thing.So I built a tool that I actually want to use every day.Curious if others would find this useful, too, or have any feedback? Like if it's nearly there, what changes would make this a win for your workflow?Details:- It's a Mac app (Apple Silicon) that runs your Claude Code sessions side by side. Each piece of work gets a "context" with its own session, next steps, status, PRs, and links.- The dashboard groups contexts by whose move it is: yours, waiting on a reviewer or teammate, Claude working, or idle. You get a notification when a session needs you or a PR gets review comments.- For non-engineers, there's a Chat view instead of the terminal, a guided Claude Code install, and folder pickers instead of paths. Engineers can stay in the real Claude Code terminal.- It runs the actual claude CLI, and sessions keep running if you quit Perch.
