## 摘要正文

hi ，各位 V2EX 的朋友们，大家好，我是 Neytoph ，一个 3 岁娃的程序员奶爸，热爱各种 diy 折腾  第一次了解到 quadro 是在小红书被种草，是德国的模块化儿童攀爬架，产品配件相对标准化，灵活造型+丰富产品+鲜艳的配色+室内室外都能用，瞬间吸引了我。  ![quadro](  )  从 1 岁折腾到 3 岁，我给家里 quadro 攀爬架搭了七八种造型，也是把该体验的都体验了一遍，痛点其实还挺多的：  ![家里搭过的造型](  )  1. **不爱折腾的慎选！**买配件+根据家里定制+最终搭建，每次基本都要小一周的时间，其中尤其插管子经常会夹到手指，拧螺丝拧到手腕不适，脑力+体力的双重考验 2. **设计工具不够完善**。官方操作比较繁琐，且仅支持 windows ，先要学习软件，然后设计+修改一般两三天就过去了 3. **没有配件库存管理**，其实有不少三方小程序有这类功能，但是总觉得没有一个统一的管理位置，不是很方便 4. 自己搭建的造型，经常会**缺失配件**，一般就只能去小黄鱼或者官方再采买，这时候又两三天过去了。  所以我做了[小麦坊 https://xiaomaifang.com/]( https://xiaomaifang.com/)这样一个产品，基于开源社区的一些工具二开。  工具本身也做了开源，大家可以自行取用[https://github.com/Neytoph/quadro-builder]( https://github.com/Neytoph/quadro-builder)。  主要有几个亮点：  1. **在线编辑**：浏览器里直接搭建，同时联动库存/配件管理。     ![在线编辑](  )  2. **模型社区**：收录了所有官方造型，一键读取，也支持用户发布。     ![模型社区](  )  3. **库存管理**：家里有什么记一笔，模型设计好之后直接对比是否缺件。     ![库存管理](  )  4. **交易管理**：多的挂出去，缺的发求购，不用再切换平台采买。     ![交易管理](  )  5. **一键导出安装手册**：每步用哪些配件写在旁边，无脑跟手册搭建就行。     ![安装手册封面](  )     ![安装手册步骤](  )  6. **AI 设计**。还在构建中，敬请期待！哈哈  其实做产品前，有调研过这个市场，规模很小，所以预期并没有很高，能帮助到一些爬爬架用用户就很满意了！另一方面，也是想借这个产品，将整个 agent pipeline 跑通，也算是一次副业实践吧！  ### 如果大家遇到什么使用问题或者优化建议，欢迎随时联系我 hello@xiaomaifang.com 或者…
