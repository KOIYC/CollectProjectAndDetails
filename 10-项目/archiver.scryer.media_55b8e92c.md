## 摘要正文

I maintain a handful of archive libraries written in Rust and I had the crazy idea to throw them all together in a browser app, doing intense computational work, fully local in the browser. I've wanted to learn more about WebAssembly and this was a great opportunity to really see what it can do.Nothing is uploaded, there's no server behind it. Everything processes local and it even works offline and on mobile. I made a 7z on my phone in airplane mode today.There's a couple other tools like this out there, but they have sign-ups, ads, limitations. Archiver is a free tool for anyone and the only limits are what your disk can hold.For 7z specifically, it also picks the best compression filters for every file in the archive based on the file type, which is really powerful when you're archiving large, mixed data (text+pictures+binary) folders.Hope you enjoy.
