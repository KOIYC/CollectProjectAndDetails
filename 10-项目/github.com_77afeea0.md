# saranyan/agent-relay  - Stars: 1 - Forks: 0 - Watchers: 1 - Open issues: 0 - License: MIT License - Default branch: main - Created: 2026-10-25T03:27:19Z  ## Top Contributors  - saranyan (11 contributions)  ---  ## README  # agent-relay  tests  **Let AI coding sessions from different vendors work together, while you stay in charge.**  ## Why  Claude can hand work to Claude on its own. But when you work with sessions from **different vendors**, such as Codex for planning and review and Claude Code for the code, they can't talk to each other. Without a relay, **you're the one transferring context**: copying plans, results and reviews between terminals.  agent-relay carries the turns for you. One session leads, the other follows, and the relay passes each turn across, records it on your disk, and stops whenever something needs your decision. It's tested with Claude Code and Codex, and you can extend it to whatever agents you work with by writing an adapter.   Watch: what the managed session is doing, in plain language.  Decide: questions stop the loop until you answer.  ## Try it in two minutes  These demos use pretend sessions, so they're safe to run anywhere and use no model quota.…
