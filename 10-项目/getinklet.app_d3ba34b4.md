## 摘要正文

在外企打工，每天都是是脑子里想的是中文，手上还得敲英文。Slack、邮件写完总要读两遍，感觉怪怪的，又不知道怎么改。  之前一直用 Raycast 的 AI 改英文，但输入框太小，prompt 改起来也不太顺手。干脆自己搓了一个，叫 Inklet，常驻 Mac 菜单栏，专门干这件事。  用起来很简单：  在任何输入框按 `⌥ Space`（可以随意设置），中文英文随便写，回车生成自然的英文，再回车直接填回原来的输入框。不用切窗口，也不用复制粘贴。  ![Inklet](  )  另外还加了几个自己常用的功能：  - **免费开源**，MIT 协议 - **不用 API Key**，M 系列 Mac 可以直接跑本地模型，断网也能用 - 也支持 DeepSeek、Claude、OpenAI、Gemini 等云端模型 - 按住右 Option 直接说话，本地语音识别，中英混说也行 - 选中文字就能翻译、朗读 - Prompt 随便改，比如「礼貌一点但别太客套」 - 不用注册，没有埋点。用本地模型的话，数据不出电脑  支持 macOS 14+，安装包也做了苹果签名和公证。  官网： https://getinklet.app/zh  GitHub： https://github.com/wanming/Inklet  目前还在自己慢慢迭代，欢迎试用，有什么不好用的直接吐槽。如果觉得还行，也求个 Star，给独立开发者一点动力哈哈。
