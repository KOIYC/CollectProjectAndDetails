Floating notes hover above whatever you’re working on and disappear with one shortcut when you need the screen back. A single hotkey opens a command palette that lets you run commands, fuzzy-find notes, or search inside them. Drag two notes together and they snap with a satisfying click, then move as a group. Every note is a plain Markdown file with YAML frontmatter, stored in a folder you choose. Readable by any editor. No account, no sync server, no company in the middle. No telemetry, works offline.
