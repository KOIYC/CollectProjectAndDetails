## 摘要正文

I like to see what new projects people are working on in open-source, but I found it hard to find projects or news in any systematic way.I built Shadowgraph so that I could browse the latest in open source development in a more natural way. It ingests repos from github and scrapes hackernews, reddit, and X for mentions of them.I also identify noteworthy contributors on github and track what they're starring as a signal for potentially high quality projects that might otherwise fly under the radar. I also track their tweets or hackernews contributions for mentions of github repos for a more curated feed of content. Finally, there's an MCP and semantic search for repos and developers.This is a fun side project for me but I want it to be useful for people- feedback is very much appreciated.
