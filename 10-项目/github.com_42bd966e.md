## 写在前面  我目前从事数据平台和 AI 相关的技术售前工作。过去一年，AI 在我的工作和生活中逐渐从一个简单的问答工具，变成了在生活和工作中真正能帮到我的工具。现在工作上的技术调研、方案梳理、代码脚本、部署排障和演示材料，生活里的日历、待办、财务和家庭网络管理，基本都有 AI 参与。  这篇文章想分享一下我目前使用 AI 的方式，以及这一年摸索下来的一些经验和教训。没有太多高深的东西，主要是自己真实的使用经历，希望能给大家一些参考，也希望大家给出一些建议。  ## 订阅和硬件  ### 订阅  | 工具或服务      | 套餐与来源                                                   | | --------------- | ------------------------------------------------------------ | | ChatGPT / Codex | Pro ，$200/月，iCloud 订阅，这个月底应该会降到 $100           | | Claude Code     | Pro （$20/月）×2 ，iCloud 订阅，使用 cswap 切换。Max 要加钱，感觉性价比不高，也没有 Fable 使用需求，所以没升，犹豫中 | | Cursor          | 公司企业订阅，Composer 畅用，每月 $300 额外的额度，我都用来跑 Opus 5.5 | | X Premium       | Premium ，$30/月，刚开始订阅，主要用 Grok Bot                 | | ZenMux          | 个人 Starter 订阅，$20/月                                    |  ### 硬件  目前我的主力是一台放在家里的旧笔记本，安装了 Linux Mint ，平时基本不用管它，就让它一直开着。基本上所有的 AI 任务都跑在上面，通过 Paseo 调度，通过 RustDesk 远程访问。  我在家主要用 Windows 台式机，通过 Paseo 连接到这台 Linux 。  另外有一台 MacBook Air ，上面跑 Codex Desktop ，主要用它的电脑操作能力：Codex 能直接看屏幕、移动鼠标、敲键盘，像人一样去操作 Mac 上的浏览器和各种应用。录 Demo 视频时，要在真实的产品界面里点击、展开、滚动，这类需要操作图形界面的活，交给 Mac 上的 Codex 最方便；家里那台 Linux 则主要跑命令行和后台任务。出门在外，我也会用这台 Mac 通过 Paseo 连回家里的 Linux 。  ## …
