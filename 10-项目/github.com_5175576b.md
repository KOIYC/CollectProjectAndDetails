## 摘要正文

各位佬友，最近关于 **Gemini 4** 的风声越来越大，从各种内测流出的风向看，推理和多模态能力大概率又要上一个大台阶  Google **AntiGravity** 经过这么长一段时间的迭代，已经进化到了**临时生产力工具**的阶段：响应够快、上下文窗口给得大，最关键的是，目前的免费额度确实顶，白嫖起来是真香  但只要你稍微上点强度，一个巨头疼的问题立刻就会浮上来：  > **单号的 Quota 限额实在不够霍霍。** 稍微跑两个复杂的 Agent 任务或重构大项目，额度瞬间见底  想要多号轮换？每次切号都要经历一遍：**退出登录 ➔ 弹系统浏览器 ➔ 选 Google 账号 ➔ 点授权 ➔ 本地回调 ➔ 重新进 IDE**  而且手动退登还有个潜在问题：本地 `storage.json` 里的设备指纹（`machineId` 等）是完全固定的，服务端一眼就能看出是同一台机器在频繁换号  为了彻底解决这套折磨，我搓了这个开源工具：**AntiGravity Switch （`agy-switch`）**  它完整覆盖了目前全部的 **4 种客户端形态**： - 🖥️ **AntiGravity APP**（桌面应用） - 💻 **AntiGravity IDE**（独立开发环境） - ⌨️ **AntiGravity CLI**（同步原生命令行 `agy` 会话） - 🧩 **VS Code 或 JetBrains 插件**（插件凭据热同步，免重启主编辑器）  底层直接走 SQLite 凭据注入，告别浏览器弹窗实现秒级切换；同时给每个账号绑定了独立的虚拟设备指纹  ---  ### 这个工具适合谁？  如果你符合下面这几点，那它几乎就是为你量身定做的：  1. **手里正常有 3~5 个 Google 账号**：绝大多数普通开发者或 L 站佬友手里也就攒了三五个号，既不是搞黑产的工作室，也没打算批量刷号 2. **不想折腾反代，或者没心力去维护反代**：就为了手里这三五个号，去租 VPS 、买域名、搭第三方网关和负载均衡分流，纯属“杀鸡用牛刀”成本高不说，一旦网络抖动或鉴权失效，排查运维比写代码还累 3. **想要流程全自动化，且对用量有掌控感**：    - 额度用完了**后台自动无感秒切**下一个可用号；    - 在 macOS 菜单栏或 Windows 托盘里一眼能看到哪个号还剩多少、什么时候重置；    - 清楚知道自己今天到底烧了多少 Token 、对应折合了多少刀的 API 价值。  ---  ### 之后还会更新什么？  这个项目不会只停留在切号工具，后续版本重点推进两件事：  1. **AntiGravity IDE 设置项深度治理**：用过 Anti…
