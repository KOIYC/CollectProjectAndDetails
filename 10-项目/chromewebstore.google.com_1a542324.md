TabHop - Chrome Web Store  # TabHop  Overview  Switch tabs with customizable keyboard shortcuts. Command+Shift+Up/Down on Mac, Ctrl+Shift+Up/Down on Windows and Linux.  Move between tabs without reaching for your mouse. TabHop adds customizable shortcuts for the previous, next, first, and last tab in your current window. DEFAULT SHORTCUTS • Mac: Command + Shift + Up for the previous tab; Command + Shift + Down for the next tab. • Windows and Linux: Ctrl + Shift + Up for the previous tab; Ctrl + Shift + Down for the next tab. FEATURES • Navigate in tab-strip order, including pinned tabs. • Wrap from the last tab to the first, and back again. • Stay within the current window. • Assign optional shortcuts for jumping to the first or last tab. • See currently assigned shortcuts in the toolbar popup. • Open your browser’s shortcut settings directly from the popup. CUSTOMIZE YOUR KEYS Open TabHop from the extensions toolbar and select Customize shortcuts. Assign the combinations you prefer in your browser’s shortcut settings.
