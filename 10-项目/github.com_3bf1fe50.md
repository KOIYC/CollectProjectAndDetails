# Zero Breach Toolkit  A free, open-source check for traces of known mercenary spyware (Pegasus, Predator, Graphite, Candiru and others) on computers, Android phones and iPhone backups.  - **Read-only.** It does not modify source evidence or system settings. It writes only   temporary database snapshots and the reports you ask for. - **No network requests during a scan.** It never looks up spyware addresses and has no   upload feature. Python network calls are blocked and redirected paths are refused. This   is not an operating-system network sandbox; see [PRIVACY.md](PRIVACY.md). - **States its limits.** Every report says what was found, how strong the evidence is, and   what could not be checked. A clean result is never presented as proof that you are safe.  Made by archivegenocide.
