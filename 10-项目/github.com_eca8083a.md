## 摘要正文

Hello! Looking to share forbear, a immediate mode GUI library that looks like the web, has a React-like DX and is as fast as possible.I've already built a real program (https://github.com/gabrielmfern/calculator) to stress it, and the binary is only 3.6MB, the first frame shows up in ~300ms, it uses 10.5MB of working set memory, and it's all 1,155 lines of code.It can be used with Jai (Jonathan Blow's private beta programming language), and also from C or any C-compatible language.On Linux and macOS: curl -fsSL https://forbear.dev/quick-start.sh | sh  On Windows: irm https://www.forbear.dev/quick-start.ps1 | iex  It's missing basic features like accessibility, input method support, and built-in text input primitives.It has a LICENSE that makes it source available. It's free for nonprofits, open source software or internal tools, but, it charges a capped 1% royalty for any company that exceeds a revenue threshold.I would love to hear feedback, specially on the new C API as I am not very experienced with C.Thanks!
