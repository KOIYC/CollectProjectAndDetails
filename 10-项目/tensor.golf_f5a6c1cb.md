## 摘要正文

Hello HN!Excited to share Tensor Golf!I'm excited to share this with everyone here, I've been seeing a lot of requests for tensor manipulation exercises and so I thought I'd create a place to build confidence and fluency in working with PyTorch tensors!I've found that understanding ML concepts and mathematics is one thing, but implementing them in PyTorch is a totally seperate beast.Tensor Golf lets you practise working with tensors in a puzzle format, with the least number of operations giving you a better score - hence the "golf" part.The core set of practise questions are free and I'm considering open sourcing the core set of puzzles :)Let me know if you find this useful!ps: 1. this is my first show hn ever, pls go easy lol 2. more than 50 people have signed up and are loving it so far!! 3. you have to login to try it - sorry, not a huge fan of allowing access to the execution backend without having emails attached to prevent abuse
