## 摘要正文

Hey all,  Finally launching a computing system that lets people and ai agents run computations on idle devices while minimizing the possibility of leaking or exposing intellectual property.  The whole point is to use what you own first and burst to cloud only when you need to.  We realized that everyone is using the same mathematical functions in writing code and programs (at least simulation and calculations) but where and how they use it, the structure, is the intellectual property.  So by breaking things down to simple math, the ip stays put but you can distribute the work.  Currently only on Mac, but will be releasing Windows, Linux, and Android soon.  We have various working versions of these but what want to apply a layer of polish first.  We will be implementing a cloud backend to burst to a cloud provider of your choosing and spin up spot instances to make sure things get done on time if and when there is a deadline and there isn't sufficient capacity on your cluster.  The current work is limited but in the coming weeks will be looking at improving performance and speed (just in time fusion for known kernels) so it runs like a greased pig.
