## 摘要正文

Hi HN, I’m Mark. Companies are really pushing cloud agents, but I found myself wanting to run agents on my Mac off-hours on my existing Claude/Codex subs.I'd hit my usage limit coding with Fable, but not my limit on other models for tasks like marketing, research and content creation. So I built an orchestrator that organizes my agents into departments (or ships) where they have overriding goals/milestones and a "captain" agent can spawn other agents working in that department.I think this structure works better than individual agent workers in an office. (Mundler Difflin)The user can prompt the agent dispatcher for one-off or recurring tasks, which can be controlled from a Slack or a Telegram bot. Since Overboard has context about all your local projects it knows where it should spawn an agent. You can also talk to department heads or the main agent to see what human blockers are stalling projects, or give new direction for a department. Would love to hear feedback about the project. It's not open-source but there is a 14 day trial so anyone can test if it's useful before buying a license. (one-time $49)
