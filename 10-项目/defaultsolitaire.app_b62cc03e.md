## 摘要正文

I got irritated by the maximalism and lack of aesthetics present in modern software when trying to find a nice solitaire.A solitaire does not need a score, levels - and most of all it does not need to download anything, have user log in or do anything else except maintain game state.So since software comes automatically nowadays, I decided as a weekend project to create the last solitaire I'll ever need.The application is built on Rust so I can compile it to native. But it runs just as well as web app!I geeked out completely on design (it may look like "default" but that's the point) to create as non-intruding yet aesthetically pleasing experience as I could.I might have accidentally put in a complete card design system with a content pipeline (maybe I'll do default blackjack next) - but as a player you only see the one pack of cards.Anyway, hope someone here appreciates the minimalistic aesthetics.The game state is saved in the url so if you want to save a nice game you can do it by copypasting the link.The game engine is versioned so if I ever change the engine or state schema there will be support for the current version as well.There _is_ a novelty.If you click the "teach" butt…
