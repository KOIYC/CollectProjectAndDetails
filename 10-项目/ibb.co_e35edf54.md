# phone farm setup: [proof](https://ibb.co/0jK027xy)  everyone is talking about organic right now.  but IMO almost nobody has a REAL scalable system for it.  UGC blonde college girls are going crazy with the CPM's  so we built a TikTok/IG phone farm.  literally 11+ iPhones sitting on a desk.  and recently we started scaling the whole thing with slideshows.  current result:  **120K+ views/day across the farm**  [proof](https://ibb.co/QvnKH7FD)  # the basic setup  we currently have 11+ iPhones.  mostly second-hand iPhone 6s.  cracked screens.  bad batteries.  ugly as hell.  doesn't matter.  they just need to run TikTok/Instagram reliably.  why iPhone 6s?  because they're cheap and they work.  although if I was buying everything again today, I'd probably go newer.  iPhone X is REALLY good value/price IMO.  each phone usually has:  * 2-3 TikTok accounts * 1 Instagram account  we currently only use iPhones.  my personal experience/opinion is that they seem harder for platforms to randomly flag/ban than cheap Android setups.  not claiming this is some scientifically proven fact lol.  just what we've seen.  # what kind of views are we getting?  on average:  **1k-3k views per TikTok/Reel**…
