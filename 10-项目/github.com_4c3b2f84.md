# Aarv-1o/Attentry  to improve ai code  - Stars: 0 - Forks: 0 - Watchers: 0 - Open issues: 0 - License: MIT License - Default branch: main - Created: 2026-10-26T15:34:10Z  ## Languages  - CSS - HTML - JavaScript - TypeScript  ## Top Contributors  - Aarv-1o (137 contributions) - claude (40 contributions)  ---  ## README  # Attentry  Attentry checks the code your AI agent writes. It works with Claude Code: after each edit, it tells Claude about any security hole, crash risk, copied function or dead code that the edit added, so Claude can fix it straight away. When the task is done, you get a short summary of what changed.  Website: attentry.js.org  Attentry is in preview. It reads JavaScript, TypeScript (including JSX and TSX), Python and Astro.  ## Install  Install the extension from the VS Code Marketplace, or from Open VSX if you use Cursor, Windsurf or another VS Code fork. Then open the Attentry panel in the sidebar and click **Connect Claude Code**. That's all the setup there is.
