## IntroGiven all the token resets in the last few weeks, I decided to try building a fully vibe, and fully one-shotted project (one prompt per feature/bug fix, no reviews, neither human nor indipendent agents, only the ones the agent itself spawns).That's how bit-cheer https://bit-cheer.com was born, a tool for learning beatmatching that I really wish I had when I started with turntables. The idea is absolutely not new, and if you want to learn beatmatching and want something much more tested and still free, I recommend https://www.beatmatch.pro/.I needed a somewhat challenging task to see how far I could get with this 100% vibe, one-shotted approach, and I liked the somewhat nostalgic idea of using early 2000s graphics, so bit-cheer reuses Winamp's graphics and elements and can "wear" any Winamp skin.## No mobileThe app was intentionally designed not to support mobile. I didn't feel like going crazy trying to make Winamp skins work on mobile, and it most likely never will support it.## Technical detailsThe web app is written in Elm (with a bit of js, mainly for plumbing and skin rendering) and uses an audio engine written in Rust and compiled to WASM.
