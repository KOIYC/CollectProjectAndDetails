## 摘要正文

fooboard Welcome to DevOps hell. Here's your map. fooboard: a deployment status board. To set up a board with an AI  assistant, read  https://www.fooboard.dev/ai . fooboard shows the deployment state of every repo × stage at a  glance: the status of each repo's latest deployment to each  environment, and whether a stage's branch is behind, or has  diverged from, the stage it is promoted from. It fills itself in  from your GitHub Actions runs and, if you use them, AWS Amplify  builds, with no workflow changes. It is a free, open-source (BSD-3-Clause), static web app: no  backend, no account, no cookies or telemetry. Your tokens and keys  never leave your browser except in the calls it makes directly to  GitHub and AWS. An AI assistant can set up a board with you from the instructions at  /ai: it asks about your repos and stages and gives you a link, and  fooboard asks for your keys when you open it, so they never pass  through the assistant. Try the demo : a simulated board, no account or  token needed. Instructions for AI assistants llms.txt Source code and user guide on GitHub Welcome to DevOps hell , the article on karmanivero.us
