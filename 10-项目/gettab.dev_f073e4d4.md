Tab . The browser  The evidence  Security  Try the demo A DIFFERENT KIND OF BROWSER Tab . A new browser. Not a wrapper. An independent web browser, built on its own engine in Rust. Familiar on the surface. Entirely new underneath. Try the Linux demo  See the test results Pre-alpha Linux x86-64 Real engine. Real tests. Take a look 01 / THE EXPERIENCE The browser is the point. No Chromium, WebKit, or Gecko behind the curtain. Just Tab, rendering its own interface with the same engine it uses for the web. Tab's start page: plain HTML and CSS, drawn by Tab's own engine. A pre-release build of Tab on Linux. The screenshots are unedited, and the engine drawing these pages is the one the tests below measure. 02 / YOUR TURN Take it for a spin. The current experimental Linux build is ready for curious people to break it. One command installs Tab and opens a demo page. Tab is pre-alpha. It hasn't had a security audit, and plenty of real sites still break. Don't use it for banking, trading, or important logins. The first launch asks you to acknowledge this. While in pre-alpha, Tab counts its testers with one anonymous ping a day: a random ID, the version and your distro, never what you browse…
