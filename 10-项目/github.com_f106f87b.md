## 摘要正文

Hi HN, I’m Evan from Gauge. We’re open-sourcing our CLI to recursively improve your docs for coding agents. The CLI includes a local execution backend, so you don't need an account to try it. Explainer video here: https://youtu.be/zhLUlIKB1MgThe CLI supports a hillclimbing loop:- set up tasks for coding agents that would need your docs, like 'set up Gauge CI checks'- run the tasks- analyze session transcripts for friction or failures- create variants of your docs to resolve the issues- re-run the tasks with the doc variants injected (transparently, at the same hostname)- repeat until you have a variant that resolves the issuesThe same loop supports hillclimbing your Skills, CLI, and other agent-facing surfaces.We started out 2 years ago building open-source developer tools (like Tach https://github.com/tach-org/tach), then pivoted to AI Search optimization, and are now focused on the intersection of the two spaces. We were already working with awesome devtool companies, and they were the first ones to ask us how to optimize for Claude Code and Codex. We realized this would be something that eventually every company needs to do. Our CLI provides primitives for docs/devrel/eng teams …
