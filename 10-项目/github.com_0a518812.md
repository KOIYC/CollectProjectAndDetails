# ritza-co/hn-jev-sorter  Sort Hacker News comments into buckets in real time with Jev by TypeSafe  - Stars: 1 - Forks: 0 - Watchers: 1 - Open issues: 0 - License: MIT License - Default branch: main - Created: 2026-10-09T21:30:23Z  ## Languages  - HTML - JavaScript  ## Top Contributors  - sixhobbits (4 contributions)  ---  ## README  # HN Jev Sorter  A Chrome extension that sorts Hacker News comments into buckets while you watch. Pick the buckets ("accuses others of astroturfing", "it's overhyped", "off topic", or your own), press Run, and each comment flies into the bucket it belongs in. Hover a bucket to read everything in it.  Comments are classified by Jev, TypeSafe's decision model. Jev answers each one in about 300 ms, so the comments sort in real time.  HN Jev Sorter sorting a 131-comment Hacker News thread  ## Install  1. Download this repository: **Code → Download ZIP**, then unzip it. Or clone it:     ```bash    git clone https://github.com/ritza-co/hn-jev-sorter.git    ```  2. Open `chrome://extensions` and turn on **Developer mode** (top right). 3.
