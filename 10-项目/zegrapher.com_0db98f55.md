## 摘要正文

ZeGrapher is a free an open-source math plotter, first release in 2011 (I thought there were no such app on Linux at the time), that I kept sporadically updating ever since. Last version was 6 years ago but a lot of work went into it.v4 is a near complete rewrite to a modern interface and approach, inspired by desmos.Interesting differenciating features:- Computing and plotting recursive sequences - svg and pdf export at the physical size you see or set on your screen, in centimeters - "schrodinger" constants: define constants that take many values at once, any expression that depends on it is plotted for each value, with a user set color gradient. - an interesting graphical way to deal with CSVs and can handle large ones (millions of lines)The rest on the website !I want it to be able to make graphs that can be used in research articles, not quite there yet. I want math formatted (like katex) titles and legends at least.Already found stuff to fix on this rc, feedback welcome!
