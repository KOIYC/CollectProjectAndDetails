## 摘要正文

Founder here, I posted the beta version of ToolJet on HN in 2021 as a no-code/low-code builder. Ended up getting 400 upvotes.I wrote the first version in 7 weeks during the covid lockdown, and the drag and drop builder was the whole product. Over the last few months our customers wanted the UI flexibility and convenience of vibe coding without giving up the governance they came to ToolJet for. We resisted for a while.We did not pivot, but we did rebuild the app builder so an app can be built with code or without it. The frontend of apps is a React codebase, written by Claude Code, Codex, Cursor or by hand, and ToolJet is the platform it runs on.How it works: - Internal tools can be generated using your own coding agents or using our agent.- Frontend is React codebase, it can be edited from our app builder, VS code, or any other IDE.Code will be scanned for security issues before saving. Scanning policies can be set by admins.- Frontend never interacts with APIs, databases or other data sources.
