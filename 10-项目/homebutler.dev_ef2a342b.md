## 摘要正文

Safe AI ops for small homelabs Know what changed before you fix it. Homebutler turns server maintenance into narrow, readable operations: report what  changed, map exposed ports, catch crashes, and verify backups.  One Go binary. CLI, web, JSON, or MCP — no SSH key required. Install with brew install Higangssh/homebutler/homebutler ,  then run homebutler report to see what changed on your  server since last time.
