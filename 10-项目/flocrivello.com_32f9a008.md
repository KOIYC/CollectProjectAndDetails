## 摘要正文

Was tired of every good markdown editor out there being electron and their consuming 500mb + 3% CPU when idle(!) when they're just editing text.So I built one from scratch in pure native. * Launches in 0.1s * Takes 0.0% CPU when idle * Consumes 50MB memory even with a large workspace open * Binary is 15MB * Supports all markdown — LaTeX, Mermaid, tables, image attachments etc * Fully open source, GPLv3 licenseHat tip to writer.computer which inspired the idea!
