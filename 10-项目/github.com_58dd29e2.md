Hi folks,  I've been working on Zync, a desktop SSH workspace for Windows, macOS and Linux.  Website: [https://zync.thesudoer.in](https://zync.thesudoer.in/) GitHub: [https://github.com/zync-sh/zync](https://github.com/zync-sh/zync)  Zync is built for the everyday work of connecting to servers, checking logs, and moving files, without constantly switching tools:  * Terminal, SFTP browser, and port forwarding in one window * Credentials stored locally in an encrypted vault, no account, no cloud sync * Local shells and remote SSH sessions share the same workspace * Jump hosts, SSH config import, and visual port forwarding (local, remote, SOCKS) * Snippets, command palette, and session restore, pick up where you left off * Optional encrypted backup to your own Google Drive * A plugin marketplace for themes and plugins * Runs fully on your desktop, light on resources  **Recent update (v2.35.1): make the workspace your own:**  * Custom color themes, including import/export of theme JSON files * Renameable tabs and dockable panes * A side navigation bar you can toggle * Keyboard shortcuts are easier to discover and edit, including bindings that work while the terminal is focused  Update …
