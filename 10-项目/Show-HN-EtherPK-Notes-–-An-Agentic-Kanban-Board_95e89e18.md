## 摘要正文

Author: Gareth Brown  EtherPK is at its core a markdown and Wikileakbased editor with rich functionality to help you manage information and projects. EtherPK tasks are plain markdown. But the EtherPK client has built powerful functionality on top of markdown tasks, integrating a cananban board, an MCP server to allow you to manage your work in your notes and easily hand off with instruction and full task context to your AI agent, for example, Claude Code. This demonstration shows you using the tasks you have added to your notes in EtherPK to hand off with context to an AI agent. Using EtherPK, the agent knows how and where to find task context, and you can even link to additional documents in your graph, making your graph an extension of the context available to the agent. The cards on this board are representations of task lines in plain markdown notes. Claude code is running in the terminal, and it's updating the markdown, which modifies the cards as it works. Here we see Claude code connected to a synced EtherPK graph. We show handing Claude code a task from the board and later a whole lane of tasks for autonomous working.
