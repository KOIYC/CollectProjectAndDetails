The research code includes a one-pass **Direct** scorer and a conditional **Diffusion** scorer with deterministic DDIM sampling. The English-first design target is a model asset bundle under **64 MiB**, with CPU/WASM and optional WebGPU execution. This is a target, not a complete browser-package guarantee.
