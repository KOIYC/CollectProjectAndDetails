## 摘要正文

Docs Get started Blog  Support GitHub All posts PE Patric Eckhart  / October 24, 2026  GenesisDB 2.0 is Open Source  MIT licensed, drop-in compatible and free for everyone .  Today GenesisDB 2.0 is released, and with it the complete source code. The server, every SDK and the VS Code extension are now on GitHub under the MIT license.  What changes for you  No more Community and Enterprise editions. There is one GenesisDB, and it has every feature.  No license keys, no event limits, no subscriptions.  Use it commercially, modify it, embed it, redistribute it. Why open source  A database is a long-term decision. You put your history into it, and with event sourcing that history is the system. Nobody should have to wonder whether the vendor behind their event store will still be there in ten years. With the code in the open, that question goes away: GenesisDB belongs to everyone who builds with it.  What is in 2.0  One static binary: written in Go, standard library only in the engines, no runtime dependencies.  CloudEvents native: every event is a CloudEvents 1.0 record in a hierarchical subject tree.  Preconditions: atomic batch commits guarded by isSubjectNew , isSubjectExisting and …
