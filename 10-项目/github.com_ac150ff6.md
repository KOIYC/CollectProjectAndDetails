## 摘要正文

Hey HN Community!I created checkOwners to solve a problem by many engineering teams: who knows your codebase, and what will happen when they go away?This is an open-source, local-first tool which performs analysis based on Git history in order to find hidden knowledge risk in repositories.It is able to recognize true experts, recognize out-of-date ownership definitions, find knowledge bottlenecks, propose review candidates, and model what would happen when contributors go away.All the magic happens on your own local system without uploading source code or an LLM. It also works within GitHub Actions.Try it: ``` pip install checkowners checkowners audit checkowners risk ```Would appreciate any feedback from maintainers and platform engineers regarding the accuracy of Git history reflection of expertise and findings of risk analysis.
