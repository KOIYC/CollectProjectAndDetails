## 摘要正文

Hometowns  ### What happens to your contacts  - Phone numbers are reduced to their area code and aggregated. Names are kept alongside the count so you can see who is where. - There is no server behind this site. It is a folder of static files served by GitHub Pages, built from public source code. - A share link contains only a count per area code, and your own area code if you choose to include it, packed into the part of the URL after the `#`. - “Remember on this device” writes your map to your browser’s local storage only: the counts, the names, your own area code, and the numbers that could not be mapped.  ### See for yourself: cut the network  No web page can switch itself offline, but you can.  - Any device: turn on airplane mode. If you have opened this page before, it is cached and loads without a connection. - Chrome or Edge: press F12 (or ⌥⌘I on a Mac), open the Network tab, and change the throttling dropdown from “No throttling” to Offline.
