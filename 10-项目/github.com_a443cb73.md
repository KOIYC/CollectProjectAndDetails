## 摘要正文

Cloakroom is an open-source privacy tool that masks secrets and sensitive data from AI agents. It swaps real values for placeholders, then swaps them back to the originals locally.I was trying to build a full on local LLM setup on my machine, but the local models were not up to the mark (at least, not yet). I ended up building a hybrid setup, with the cloud for planning and local models for execution. I realized I needed a privacy layer so cloud models could not access sensitive data, and I built Cloakroom.It runs on your machine, it’s cross-platform, and it works with Claude Code, Cursor, Gemini CLI, and Codex CLI.
