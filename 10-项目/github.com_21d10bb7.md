## 摘要正文

用 Claude Code 和 Codex 写代码大半年了，后来又加了 Cursor 的 CLI ，桌面上常开着四五个终端。攒下来的烦恼大概是这些：  - Claude 的 5 小时额度用完，换 Codex 接着做，得把前因后果重新讲一遍 - 某个 Agent 早就停下来等我批准了，我在另一个窗口里完全没注意到 - 它在回复里说「上线前记得把 xx 配上」，第二天我就忘了 - 周额度明天就重置、还剩一大半，我却一直舍不得用 Opus - 每次模型总返回英语，还得发送一次转中文，白白浪费贵的模型 Token - 想要白天规划任务，晚上自动执行，次日验收成果  后来干脆给自己写了个桌面端来管它们，叫 **Antumi**（安图米）。自己用了一段时间，觉得别人可能也用得上，就整理了一下开源出来。  ![任务看板](  )  先说清楚它不是什么：它不是一个新 Agent ，也不代理任何 API 。它驱动的是你电脑上已经装好、登录好的 `claude`、`codex`、`cursor-agent`，额度走你自己的订阅。不用注册账号，不用填 key ，数据全在本机。  ## 跟多开几个终端比  | | 多开终端 | Antumi | |---|---|---| | 换个 Agent 接着做 | 复制粘贴上下文，再解释一遍 | 输入框里换个 Agent ，聊天记录和工作目录一起交过去 | | 谁在等我 | 挨个窗口切过去看 | 「总览」汇总等批准、等回答、待验收的，窗口不在前台时发系统通知 | | 额度还剩多少 | 各家分别去查 | 底部状态栏三家并排，悬停看重置时间 | | Agent 交代你之后要做的事 | 埋在聊天记录里 | 自动记成待办，可以逐项勾掉 |  ## 几个我每天都在用的功能  ### 移交：额度用完换个 Agent 接着干  点输入框左下角的 Agent 名字，换一个，补一句说明就行。新 Agent 会收到之前能看到的聊天记录，在同一个目录里继续。切回原来的 Agent 时，会恢复它自己的原生会话，并补上中间那段记录。  ![移交]( https://raw.githubusercontent.com/flyhero/antumi/v0.19.3/docs/assets/features/handoff.webp)  ### 额度一眼看清，还会提醒你「该花了」  状态栏同时显示 Claude Code 、Codex 和 Cursor 的用量。它会按每个窗口的重置时间算节奏：周额度快重置了还剩很多，就提醒你放心用 Opus ；照现在的速度会提前用完，就建议换个模型，或者把轻活交给另一个 Agent 。  这个功能是我自己最离不开的，以前每周都在浪费额度。  ![额度]( http…
