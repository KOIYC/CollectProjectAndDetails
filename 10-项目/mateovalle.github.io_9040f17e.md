Pixel Agents — Your Claude Code agents, working in a pixel office  # PIXEL AGENTS  Your Claude Code agents, working in a pixel office.  An open-source mission-control desktop app. Every project is an office on one campus map; every agent is a character you can watch think, code, and ask for permission.  macOS · Linux · Windows — free & MIT licensed  macOS: the app isn't signed yet — after installing, allow it in System Settings → Privacy & Security → "Open Anyway".   ● 5 agents working · 1 waiting for you today: $4.21 across 3 offices  ## WHAT'S IN THE BOX  Real Claude Code sessions — same login, same config, same transcripts. Start in the app, resume in your terminal, or vice versa. Nothing is locked in.  ### CAMPUS VIEW  Register project folders as offices on one pannable pixel map. See at a glance who's working, who's waiting for you, and what each project costs today.  ### RICH CHAT AGENTS  Powered by the Claude Agent SDK: streamed markdown, tool cards with real diffs, Allow/Deny permission buttons, image paste, session resume.  ### TASK ORCHESTRATION  Shared task lists between you and your agents. Assign a task with one click — an agent spawns, works, logs discovered work, and…
