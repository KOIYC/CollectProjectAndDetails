## 摘要正文

最近有财税记账的需求，写了个本地经营账本：BeanDesk  新版本刚刚集成 AI ，试了一把自动入账，完全跑通了，具体看图                  随手丢一张发票路径，一句话指令，直接在本地自动干完整套活：  1. 自动开立对应会计科目 2. 自动把发票原件归档并关联穿透预览 3. 自动识别出“个人抬头普票不可抵扣进项税”，全额计入费用 4. 自动判断“员工垫付未实际收付，不计入现金流量表” 5. 跑完本地合规规则校验，确保借贷分毫不差  还有入桌面端可以看报表	 对公标准三张表直接生成 数据 100% 留在自己电脑硬盘 支持本地版本快照 + S3 加密备份  开源免费，只要你的 AI 客户端支持 MCP 协议就可以使用。Mac 、Win 、Linux （没实测）都支持。  项目地址： https://github.com/SuperDaniel-cn/BeanDesk  有同样在折腾本地账本的 OPC 朋友或独立开发者，欢迎交流，请多多指教。
