WOML is an HTML-inspired language and self-hosted runtime for durable automation. Open a .woml file and its triggers, steps, decisions, approvals, and execution policy read from top to bottom. Run that same file and WOML turns it into an operational workflow backed by real JavaScript and a durable engine.  The source is not an export of the workflow. It is the workflow.
