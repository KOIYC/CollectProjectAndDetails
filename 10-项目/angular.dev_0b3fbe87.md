## 摘要正文

查 API 、挑组件、复现 Bug 、压缩图片、排查兼容问题……前端开发的一天里，很多时间花在寻找合适的资料和工具上。把常用入口整理好，遇到问题时就能少绕一些弯路。  这份 2026 版清单收录了 100 个网站，分成 10 类：学习文档、框架工具、组件库、在线调试、包管理与协作、测试性能、设计配色、图标字体、图片与 CSS 工具、实战练习。每个网站都附上入口和使用场景，可以按当前需求收藏。   整理时间：2026 年 11 月。  一、学习与文档类网站  知识会更新，查阅资料也需要讲究方法。理解概念时看教程，确认行为时看文档，遇到版本差异时回到对应版本的说明。  1 、npmcn.com：npm 包中文文档 https://npmcn.com/  读 npm 包的英文 README 时，可以先到这里查看已有的中文文档。网站提供包搜索、中文简介、README 和原文切换，也能浏览热门中文包与最新中文包。它适合用来初步了解一个包，再对照原文确认 API 和配置。中文内容由自动翻译流程生成，可能有措辞偏差，当前也没有覆盖所有 npm 包。  2 、MDN Web Docs https://developer.mozilla.org/  查 HTML 、CSS 、JavaScript 和浏览器 API 时，优先打开这份参考资料。它把语法、示例与相关概念放在一起，适合解决具体问题，也适合沿着学习路径补齐前端基础。  3 、web.dev https://web.dev/  页面能运行之后，怎样让它更快、更易用？这里围绕性能、无障碍和跨浏览器体验提供课程与案例，适合把零散的优化技巧整理成可以执行的开发与检查流程。  4 、JavaScript.info https://javascript.info/  适合系统学习 JavaScript 。教程从语言基础延伸到对象、异步与浏览器交互，配有练习；遇到概念理解不牢的问题，可以顺着章节补课，再用练习检验自己是否理解。  5 、TypeScript https://www.typescriptlang.org/  类型报错看不懂时，官方手册和 Playground 很有用。可以把复杂类型缩成一小段代码，观察推断结果，再核对接口、泛型与配置的正式说明，适合团队统一写法。  6 、Can I use https://caniuse.com/  准备使用一个新 CSS 属性或浏览器能力时，先查支持表。它按浏览器和版本展示兼容情况，适合评估目标用户能否使用某项特性，再决定是否增加降级方案。  7 、CSS-Tricks https://css-tricks.com/  以 CSS 和前端实践文章见长的资料站，适合在处理布局、样式细节时寻找思路。阅…
