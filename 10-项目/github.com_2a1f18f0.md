## 摘要正文

A while back I recall being told it can't be done and won't be "Discord". To that, I have to admit, it's not Discord. It isn't designed in a way to profile it's users and it respects privacy.There is still much work to do on this project, but it's in open beta with a web client so people can see how it works before committing to a desktop app download. Mobile apps will come later, if there is proven interest in this platform.I don't care to monitize it. The only thing users will ever see is a non-intrusive "Please donate" badge at most, with the intentions to just keep the maintainer nodes and some official relays running.There are no accounts. There is no way for me to see the messages.
