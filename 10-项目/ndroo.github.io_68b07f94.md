## 摘要正文

I have this boiler at a rental property I own. It has 3 smart thermostats (Ecobee). They're great and give the individual tenants zone control, but they only notify me something is wrong when it's already too late as they rely on observing the 'call for heat' and a ongoing decline in room temperature to trigger the alert.The boiler is pretty smart, it has all kinds of cool error codes, but the issue is I have no way of knowing theres an error flashing on the screen. That is, until now.I put a Tapo camera pointed at the boiler (getting Tapo to export still frames was a whole other issue, code for doing that is in the same github project for anyone interested) and use AI to read the screen and zone controller lights.The result is a system that sends me a text message any time something goes outside of the normal operating parameters. My goal is to deliver a great experience for the tenants living at this property, and now I'm able to connect my 'dumb' appliances to the internet without any of the typical risks associated with exposing critical infrastructure to the web.
