## 摘要正文

I've been working on a implicit text to cad system (scratchcad) that outputs STL. This is all built around fidget, a really cool experimental implicit engine by Matt Keeter. Scratchcad adds a rust http API on top of fidget and provides an mcp for any agent to interact with the API, so that it can script in Rhai, verify it's scripts and create STLs. My whole system is under Apache 2 so that anyone can build with it. It's still super early but I excited to see where this goes and what you all model or build on top of scratchcad.
