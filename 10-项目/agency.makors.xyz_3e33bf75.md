## 摘要正文

Everyone is buying a Mac Mini for their agents, or better, giving them a Linux box (see https://x.com/theo/status/2090528543746965991).I found this quite tedious to setup every time, so I built a "custom" nixOS image to create a repeatable and customizable computer for my agents. It takes ~5 minutes to install, has a sleek-ish dashboard, and is fully open-source.You could set this up yourself, but for setting up agent multiplexers like T3 Code I find this pretty easy / nice.Check it out. It's very early, so LMK if you run into any issues.https://agency.makors.xyz/ or https://github.com/makors/agency:)
