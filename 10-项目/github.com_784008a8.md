## 摘要正文

Hi HN! We're Tony, Kolom and Anastasiia, a small team from Ukraine.Today we are open-sourcing Openspot, our research project on using generative UI in day-to-day work.The idea is simple: generate a tool (spot) for your current task using coding agent, and keep it if you like it or remove it after use if you don't. We are using Openspot daily and really enjoying the possibilities it unlocks. Some examples of spots:- caffeinate, which allows the Mac to work with the lid closed- local file and screenshot search in natural language using EmbeddingGemma 2- draw on screen during calls or before screenshots- AI agents monitoring- AirDrop, but over the network (using iroh)We built it because of two things:1. Over the past year, we (and almost every designer and engineer we know) have started making small tools using coding agents. But the DX for macOS applications is very frustrating even for coders, and you have to pay for a developer account to share them.2. And we kind of miss the days of custom Winamp skins and Twitter clients. That's why every part of Openspot is customizable, so anyone can give it their own look and feel.This is a very early stage.
