## 摘要正文

Video as code took off with the Opus 5.5 release. People now make videos by writing code, with Remotion, HyperFrames and others.We wanted the same for 3D videos. You can use something like Blender, but it's heavy to install and slow to render.So we made ManimGX:- Lightweight: a 65–110 MB download, depending on the OS- Easy to install: pip install manimgx (Python 3.13+), with no system dependencies- Cross-platform: macOS, Windows and Linux, and even the browser via Pyodide and WebGPU- Blazingly fast: a Rust + wgpu engine, 90.6× faster than Manim CE and 18.7× faster than Blender Workbench, from launch to finished MP4- Compatible with Manim Community Edition's API, with LaTeX and Typst math built inNow it's much easier for anyone with a coding agent to make 3D computer graphics videos.Repo: https://github.com/academa-labs/manimgxDocs: https://manimgx.academa.aiX post: https://x.com/sinaatalay/status/2109045945149395421Happy to answer any questions!
