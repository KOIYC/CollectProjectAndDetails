Expect rough edges, and feel free to raise issues.  Screenshot of Panel in action.  ## Before you start  - Node 22.18 or newer (or 24.12 and newer) - pnpm - uv, which fetches the Python it needs (3.12 or newer) by itself - Claude Code, installed and signed in: run `claude` once and log in. The agent and the literature review run through it.  ## Install and start  ```sh pnpm install uv sync pnpm start ```  Then open. `pnpm start` builds the app first, so the first start takes a minute. Ctrl-C stops everything it started.  ## Where your things are  - `~/Panel/panel.db` holds your conversations and everything the agents did. - `~/Panel/workspaces` is where new Workspaces are created,…
