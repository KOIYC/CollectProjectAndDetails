https://reddit.com/link/1xre6fl/video/kuobaorijh0i1/player  [https://github.com/sshah03/recalc](https://github.com/sshah03/recalc)  Since spreadsheets are so versatile, really looking for feedback on where people would want this to go, in a way that can be useful to them, or what use cases they see themselves using it for in its current iteration that I can make more seamless.  I can provide some context on why it was useful for me / why I built it. I was using Claude to help me build benchmark sets, and found pouring through CSVs / MD files of the results a bit tiresome, so I decided to build a spreadsheet app for myself that's driven by Claude Code, and where each cell can be its own Agent if you want (and can later be opened up and continued in a full terminal if needed as its own session).  You can use it as a standard spreadsheet, or use a cell as a shell command / agent. Having built a startup for using AI in tax work, I also realized it can be very powerful for tax work, legal work, etc... so I built in some examples for running that, though I'm not sure how many people in those professions use claude code.
