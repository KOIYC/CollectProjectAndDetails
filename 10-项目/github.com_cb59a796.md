## 摘要正文

兄弟们，好久不见。今天回来，直接上硬货——三个我亲手打磨的开源项目，全部开源，全部可用，全部欢迎来喷。  ---  项目一：OmniStudio 一句话：一个把模型下载、三引擎推理、对话/语音/生图/视频/OCR 揉进同一个窗口的本地大模型万能工作台。解决什么：本地跑模型这件事被拆得太碎了。下载在这、llama.cpp 在那、vLLM 另开一摊，对话、TTS 、ASR 、生图还要各自配一套。我受不了这种「装完引擎才刚开始干活」的体验，所以做了一个本地优先、选完就能用的一体化桌面工作台。核心特性：  * 模型市集一键搜、下、管：GGUF / safetensors 全格式，断点续传，首次引导直接拉 Qwen 就能聊 * llama.cpp / vLLM / SGLang 三引擎统一管理 + 本地网关，一套接口同时给对话、Agent 、外部工具用 * 对话、语音、生图、视频、音乐、OCR 、翻译、知识库、共享记忆、Skills 全在一个工作台里，云端 API 也能接进来当后备   技术栈：TypeScript + Bun ，桌面端本地优先，MIT 仓库： https://github.com/kunpengtalk/OmniStudio 适合：想在自己机器上把本地大模型真正用起来的人，而不是只想「跑通一次 demo 」的人   一套工作台走完本地 AI 的整条链路：最左图标栏切换应用，应用内左栏选后端、填参数，右侧直接看结果 —— 所有页面共用同一套布局。  ### **🎨 AI 生图 · 🎬 AI 视频**  | **AI 生图 · 云端 API / 本地 MLX / ComfyUI** | **AI 视频 · MiniMax H3 / Seedance / ComfyUI** | |----|----| | [![AI 生图](  )](  ) | [![AI 视频](  )](  ) | | 同一页切换云端生图、Apple Silicon 本地 MLX （ mflux ）与 ComfyUI 三种后端，比例 / 宽度 / 高度 / 数量随手调；出图即进历史区，可回看、下载，右侧最近生成一排缩略图随手翻。 | 三种后端统一为「提交任务 + 轮询」：MiniMax H3 支持首帧图生视频，时长 / 宽高比 / 分辨率 / 首帧图都在左栏，成片进历史库可直接播放、下载或删除。 |  ### **🧰 提示词广场 · 🧩 小应用**  | **提示词广场 · 内置 2,733 条可复制题库** | **小应用 · 一次做一件事的沙箱工具** | |----|----| | [![提示词广场](  )](  ) | [![小应用](  )](  ) | | 生图 638 / 视频 2,060 / 大模型 35…
