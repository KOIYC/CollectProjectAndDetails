## 摘要正文

家里用的是小达人点读笔，但官方一直没有 Mac 客户端。以前为了给笔装个点读包，我只能在 Mac 上装 PD 虚拟机，再在 Windows 里运行官方客户端。  本来就不富裕的存储空间，光这一套就硬生生占了 30 多个 G 。每次只是想给点读笔装本书，还得先启动 Windows ，总觉得有点折腾。  于是这次借助 Codex ，一边提需求、一边连着自己的点读笔测试，搓出了一个 Mac 小工具，取名叫「点读伙伴」。我不是程序员，算是一个门外汉给自己做的工具。目前自己需要的安装、管理功能已经跑通了，就把它开源分享出来，希望也能帮到有同样需求的人。  ## 目前能做什么  - **安装 DAB 点读包**：选择电脑上的文件、核对书名贴号后，直接安装到点读笔。 - **支持 UNB 包独立安装**：从原始 DAB 安装，不需要笔里事先有同一本书的旧文件。 - **管理已安装内容**：查看书名、贴号、类型和大小，支持搜索；默认按贴号排序，也可以点击表头按大小等排序。 - **多选批量移除**：按住 Command 多选、Shift 连选，一次移除多个点读包。 - **安全推出**：安装完成后，在软件里推出点读笔，再拔线开机。  它是一个本地 Mac 应用，运行不需要 Windows 、PD 、Python 或其他开发工具。默认使用快速安装，需要排查问题时也可以在菜单中开启完整回读校验。  ## 我自己怎么测试的  我用的是小达人 908 。测试时移除了笔里原有的牛津树点读包，再从原始 DAB 重新安装，安全推出、拔线开机后，用手上的实体书测试，已经可以正常点读。  目前主要解决我自己的日常需求，还是测试版。我手里只有这一支 908 ，其他型号还没有实机验证，欢迎大家补充兼容性反馈。  ## 下载和使用  - **项目和源码**：[GitHub · 点读伙伴]( https://github.com/54philos/xiaodaren-mac) - **应用下载**：[Releases 下载页]( https://github.com/54philos/xiaodaren-mac/releases/latest)  当前版本是 **0.5.0**，发行包适用于 **M 系列芯片的 Mac ，macOS 14 及以上**。  普通用户下载 `DianduPartner-0.5.0-macOS-arm64.zip`，解压后把「点读伙伴.app 」拖到「应用程序」即可。GitHub 页面里的 Source code 是源码包。  首次使用时，把点读笔关机，用支持数据传输的数据线连接 Mac 。软件识别后选择自己的 DAB ，按照资源说明核对贴号和参数，再开始安装。安装完成后安全推出，拔线开机测试点读。  应用…
