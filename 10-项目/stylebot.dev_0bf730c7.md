## 摘要正文

I started Stylebot in 2010 to change how websites look without writing CSS by hand. I have kept maintaining it since then. Now, with AI tools, I’ve finally been able to fix bugs and add features I never had time for.4.0 has a new, modern editor that shows each element's actual styles, profiles, better sync, versioning and includes a CLI for coding agents.I am most excited about adding the CLI, which lets claude code or any other agent restyle any webpage in your real browser and check its work with screenshots. It lets me restyle webpages quite dramatically using coding agents. For example, you can see the example newspaper-style HN themes: https://stylebot.dev/#galleryIt's free and open source in Chrome, Edge and Firefox (Safari coming soon!). Code: https://github.com/ankit/stylebotI'd love to hear ideas and suggestions. My plan is to add a Stylebot Gallery next, which would let users share and install creations from other other users. I also plan to make improvements so its more resilient to website and CSS changes. Thank you!
