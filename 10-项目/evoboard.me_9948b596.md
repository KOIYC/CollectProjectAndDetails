## 摘要正文

Hey HN!I built evoboard, a web app which shows your consistency on a year long heatmap.I liked the contribution graphs on GitHub and LeetCode, and wondered if I could make that idea for my everyday habits. I also made it so the habits can be completed automatically when you do them.For example, if you commit to GitHub, play a game of chess, do a LeetCode problem, it can update your habit automatically. You can connect other apps with the use of the API or chrome extension.You can also share your profile with others so you can stay motivated. I’m really proud of this project and I’m going to continue using it myself.I’m happy to answer any questions or feedback!
