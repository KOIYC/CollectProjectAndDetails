# getkalem/kalem  - Stars: 30 - Forks: 1 - Watchers: 30 - Open issues: 9 - License: Apache License 2.0 - Homepage: https://getkalem.github.io/kalem/ - Default branch: main - Created: 2026-09-28T15:10:48Z  ## Languages  - CSS - Emacs Lisp - Fluent - HTML - JavaScript - Python - Rust - Shell - TeX - Typst  ## Top Contributors  - mhmtskrc2 (1106 contributions) - claude (321 contributions)  ---  ## README   Kalem   One fast editor for all the files of your work, instead of one program per format. Written in Rust. In a window and in a terminal.  Kalem (Turkish for "pen") shows a file the way it reads and never touches what you did not edit. A Markdown, Org, LaTeX or CSV file opens as what it is, a document or a grid, and under it the file stays plain text, byte for byte. PDF files, pictures and Excel workbooks open in viewers next to your documents, plugins installed the first time you open such a file; every other text file opens as code. A format Kalem does not know yet is a plugin away, written in Rust: you read and edit it here too, in the same editor.  **Status: alpha.** It is in daily use, and it has rough edges.
