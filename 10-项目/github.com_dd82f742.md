## 摘要正文

国庆几天基本没怎么休息，一直在折腾 Codex 、Claude Code 和 AI 视频制作。  没想到折腾出了点意外收获：  小红书近 30 天曝光 1206 万，播放 275 万，国庆这几天涨粉大概 2000 。  数据截图放下面，省得被说吹牛。   ![小红书数据截图](图片直链)  先说结论：  AI 确实把个人做内容的门槛拉低了。但真折腾下来我发现，最麻烦的从来不是让 AI 写稿，而是怎么让它稳定地把一条视频做完。  之前踩过的坑：  稿子看着很完整，一核查事实就露馅 资料、脚本、分镜、配音、字幕经常对不上 改两句话，后面的字幕、封面、镜头全得重来 生成了一堆文件，最后自己都分不清哪个是最终版  所以国庆期间我干脆把自己的视频流程拆成了一套 Skills ，目前开源了 11 个：  资料和素材索引 基于证据的故事脚本 视频分镜与素材规划 机制解释动画 AI 概念镜头规划 配音与字幕同步 封面设计及独立审查 成片质检和发布文案  支持 Codex 、Claude Code ，以及其他兼容 SKILL.md 的 Agent 。  它不是"输入一句话，自动出大片"那种项目，更像是一套给 AI Agent 用的视频制作 SOP：每个 Skill 只干一件事，并留下对应产物，下一步可以直接接着做，出了问题也只需要局部重做。  仓库地址（ MIT 协议，免费开源，可单装也可组合用）： https://github.com/Ucmp0001/video-production-skills  目前还在持续完善，欢迎拍砖、提 Issue 。尤其想听听大家在多 Agent 协作和视频工作流上有没有更好的思路。  说点题外话  最近也在认真折腾 X ，发现技术圈有个挺有意思的现象：很多人能花三天写出一个不错的开源项目，却不愿意花三分钟介绍它。  我以前就是这样。  现在开始把开发过程、AI 实验和踩坑经验发到 X 上，也想顺便认识更多做独立开发、AI Agent 和开源的朋友。  我的 X： https://x.com/eazymoney888  V 站有同样在经营 X 的朋友吗？欢迎在评论区留下你的 GitHub 、X 或者最近在做的项目，有意思的我都会去看看。  最后想聊一个问题：  当 AI 把内容制作成本压得越来越低，未来真正值钱的会是什么？是会写代码，是会做内容，还是知道什么东西值得做？
