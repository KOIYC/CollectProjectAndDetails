Atlarix for Chrome — an AI agent in the browser you already use  # An agent in the browser you are already signed into  Open the side panel, ask for something, and Atlarix works on the page in front of it — with the sessions you are already logged into, without asking you to copy anything into a chat window.  ## What you can do with it  It is the same agent as the desktop app, working on web pages instead of a repository.  ### Reads the page you are on  Ask about what is in front of you, or about a tab you have not opened yet. It follows links and works across several tabs at once — comparing, cross-referencing, collecting.  ### Fills forms, and stops before sending  Anything that sends, buys, posts or deletes stops and asks you first. Filling is automatic; submitting never is.  ### Reads whole documents  Attach a spreadsheet or a PDF and ask about it. It reads the entire file rather than the first page of it.
