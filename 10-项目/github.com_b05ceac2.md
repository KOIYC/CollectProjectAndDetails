## 摘要正文

Skills, tools and a shared knowledge base that let any AI coding agent mod almost any PC game you own.   The agent finds the game, works out the engine and the route, reads the real code, builds the mod, makes art, 3D and sound   with fal, tests it in the running game, cuts the video, and writes down what it learned for the next agent.  Coming next: the mod hub. Publish your mods, remix other people's, and make new ones.   Share what you make, get help, and follow along:  ## Install  Pick your agent.
