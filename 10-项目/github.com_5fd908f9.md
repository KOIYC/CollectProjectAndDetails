## 摘要正文

This is the developer of XDMIn a time of bunch of vibe coded download managers XDM one of the oldest open source downloader that is been serving as IDM alternative from 2013. Apart from a modern beutiful UI XDM now comes with torrent support powered by Libtorrent (the engine behind famous qBittorrent) and a new yt-dlp wrapper on top of XDM's built in browser extension based video grabber.New features:* Torrent and magnet link support* Additional option for video download based on yt-dlp* Lightweight but modern UI. XDM still runs under 50mb of RAM* Brand new social media reels and profile downloaderCore features:* Dynamic segmentation based battle tested multi threaded download engine* Takes over downloads from browser and detects video playing in the browser* Runs on Windows, Linux ( with native wayland support ) and macOS.* Usual features: Pause/resume/refresh expired links, queue, scheduler, speed limit, custom actions after completion, proxy, authentication and many more.* Android version soonPlease visit GitHub repo for more info: https://github.com/subhra74/xdm
