From a phone, you can check agents, manage workspaces, use terminals, send files, and choose notifications. Herdr still does the work.  https://github.com/user-attachments/assets/233f6030-c8c4-4ae8-827d-02913e2c4982  ---  ## Requirements  Shepherdr supports Herdr 0.8.0 through 0.8.2. The `herdr` executable must be on `PATH`, and Herdr must be running locally.  Run Shepherdr and Herdr as the same operating-system account. Shepherdr needs that account's owner-only local Herdr socket, and Herdr agents need to be able to read files uploaded through Shepherdr. Files sent through Terminal become local paths on the machine running Shepherdr; they are not sent directly to a model.  ## Install  Release archives are the recommended installation.
