## 摘要正文

Hey HN,Powercycling and basic power supply measurments are essential part for embedded devices development debug.But there are no interface for pwoer control for coding agents. So I created that python package which interacts with portable Fnirsi DPS-150, can toggle output, set voltage and current limits.Unexpected outcome is that it is MUCH MORE convenient to manage it in terminal and tmux than clicking on the box itself.TUI dashboard with charts, numbers and hotkeys is included.
