## 摘要正文

I am avid reader of blogs (always been since 2005 onwards), so it was always on my list to build a rss reader at some point.Initially I've built lectura for myself (the first version started when I've experimented with server side rendering/Thymeleaf + Spring Boot) and self hosted on a server (without a domain). Then I decided to vibecode multi user support. And this is the final result.What are some highlights:- It doesn't track/record what the users are doing. There are no emails (no password recovering in case you lose your password). The only information that's kept are your own subscription, that others can see as well. But that's it. Because of this, creating a username takes 5 seconds (depending on how fast you write);- It supports different layouts that I find useful with my RSS reader. For example there's a 'random' content view so you can read "historical articles" you've might missed. There's a another view called 'Quiet Sources' so you can 'prioritise' blogs that don't publish often. I'll let you find the other views.- It has good accesibility support, or it should.
