## 摘要正文

大家好，最近在维护一个叫 **Floe** 的 macOS 菜单栏整理工具，目前发布了 **1.0.1**，想拿出来和大家分享，也收集一些实际使用反馈。  先交代一下来源：Floe 源自 `jordanbaird/Ice`，基于 `cavaldos/Ice` 的分支继续开发，采用 GPL-3.0 协议。感谢原作者和上游贡献者提供的基础。  我最近主要在做界面和交互上的调整：重新设计设置界面，统一浅色、深色外观，补充中英文支持，以及优化图标整理、悬停提示和连续拖拽的反馈。  ![Floe 菜单栏布局界面](  )  *界面预览，使用示例图标。*  Floe 可以把菜单栏图标分成“可见”“隐藏”和“始终隐藏”三个区域。常用的留在外面，偶尔才用的收起来，需要时通过点击、悬停、滚动或快捷键展开。  除了在系统菜单栏中展开，还可以使用独立的 **Floe 浮栏**。浮栏支持横向图标、名称列表和网格，图标比较多的时候可以滚动，也能固定在某个显示器的位置。  目前主要有这些功能：  - **整理图标**：拖动调整分区和顺序，支持搜索、悬停查看名称，以及新图标的默认放置规则。 - **连续拖拽**：即时显示落点，后续操作排队执行，减少整理过程中反复等待、手动刷新的情况。 - **外观设置**：跟随系统、浅色、深色，以及菜单栏圆角、着色、模糊和边框等选项。 - **中英文界面**：默认跟随系统，也可以单独切换语言。  支持 **macOS 14 及以上**，提供同时包含 **Apple Silicon 和 Intel** 的 Universal 安装包。  也说明一下当前的限制：安装包采用 **ad-hoc 临时签名，尚未做苹果公证**，首次打开可能遇到系统限制，Release 页面有安装说明。管理菜单栏项目需要辅助功能权限，图标捕获和部分外观功能会用到屏幕录制权限。  不同系统版本、多屏、全屏等组合还在持续验证。项目中保留了上游问题的修复记录和待验证清单，方便了解具体处理到了什么程度。  - **项目地址：** https://github.com/wudb/Floe - **下载地址：** https://github.com/wudb/Floe/releases/latest  如果你也觉得菜单栏越来越挤，欢迎试试看。遇到问题可以在 GitHub 提 issue ，带上 macOS 版本、显示器配置和复现步骤，会更方便定位。也欢迎分享你更习惯哪种整理方式，或者参与改进。
