Hey HN!I got this idea that Jev would be a good fit for content moderation, so I investigated how good it is exactly, see my write up at https://tn1ck.com/blog/jevditAnd it is actually quite good at it and dirt cheap.I built this reddit like site to see if it actually holds true when exposed to the internet.
