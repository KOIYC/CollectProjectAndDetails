## 摘要正文

同时让几个 AI 编程 agent 做事，难点不只在于怎么给任务。一个在本机改接口，一个在检查测试，服务器上还有一个处理数据。你得不断切回终端，确认谁还在工作，谁正等着你。  我做的 [Shepi]( https://shepi.app/?v=20261107)，是 Herdr 的原生 Mac 客户端，与 Herdr TUI 实时共享同一套工作空间、标签页和 agents ，并支持简体中文、英文和日文。它不是另建一份桌面会话，也不需要你迁移现有工作。Herdr 负责维持 AI 编程 agent 的终端会话，Shepi 提供桌面入口，让任务、进度、产物和需要你参与的时刻，都有清楚的位置。  ## 01 · 现有的终端会话，打开就在那里  Shepi 和 Herdr TUI 连接同一个 Herdr server ，实时共享同一套工作空间、标签页和 agents 。在终端启动的会话，会直接出现在 Shepi ；从 Shepi 启动的，也能在终端里看到。两端可以同时使用，不用迁移，不是复制一份，也不会为桌面界面另开一套独立会话。  Claude Code 、Codex 、OpenCode 、Gemini CLI 、Cursor 、Copilot CLI ，仍然运行在完整的真实终端里。旋转标记表示工作中，空心圆表示空闲，状态也有文字；当前输入的窗格是更浅的卡片。想用桌面窗口就打开，想回 TUI 就回去，接着做的是同一份工作。  ![Shepi 窗口：左侧是工作区和 agent 的边栏，顶部是标签页，中间是三个窗格，底部是状态栏。]( https://shepi.app/guide/img/zh/window.webp)  *工作区、agent 状态和真实终端，在同一个窗口里。（指南原图）*  ## 02 · 需要你时，不必靠反复巡视发现  当 agent 停下来请求确认，例如准备部署、删除或安装时，侧栏、窗格标题和状态栏会亮起琥珀色； agent 提供操作信息时，也能看见它要执行什么。收起侧栏仍有横幅，切到其他应用会收到 macOS 通知，知道谁停了、工作了多久，点击查看就能回去。声音沿用 Herdr 的提醒时机，远程机器也一样。我希望你能专心做别的事，而不是守着输出等待。  [查看演示视频]( https://shepi.app/guide/img/zh/needs.mp4)  ## 03 · 把背景和选项讲清楚，再请你决定  在你要求时，agent 可以发来带背景、选项及各自后果的提问卡。你从任何窗格都能点选，或写自己的回答，答案直接回给对应 agent 。它也能打开网页、在名称下报告进度，或在自身上下左右打开测试和日志窗格，标明归属而不抢键盘焦点；远程 agent 同样可用。这些动作让确认与检查留在工作旁边，不必从长段…
