A fast, open-source take on the AutoCAD workflow: the command line, object snaps, layers,   dimensions, hatches, blocks and DXF drawings you already know. It runs natively on macOS,   Windows, Linux and FreeBSD, and in the browser via WebAssembly.   By the ArtCraft team.
