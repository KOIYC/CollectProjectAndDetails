## 摘要正文

最近做了一个 macOS 剪贴板工具，叫 **Cliplet · 拾片**。  灵感来自 Raycast 的剪贴板体验，但 Raycast 完整功能都没用上，新版本的聚焦也替代了快速搜索的功能，我只想要一个轻巧、专注的独立应用，于是有了这个项目。  - Swift 原生开发，无第三方依赖，应用约 **5.5 MiB** - 支持文本、图片、文件历史，搜索、置顶和快捷粘贴 - 本地识别图片文字与二维码，数据留在自己的 Mac - 适配 **Liquid Glass**，支持中文和英文  已经 **MIT 开源**，欢迎试用，也欢迎提建议。  [GitHub：xgenya/cliplet]( https://github.com/xgenya/cliplet)  ![截图](  )
