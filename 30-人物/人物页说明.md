# 30-人物 · maker / 独立开发者画像

**放什么**：从 `20-语料/` 的 `author` 聚合出的人物页——同一人发布了几个项目、赛道分布、发言与复盘、是否可追踪。

**当前状态**：3 个（Patrick McKenzie / Pieter Levels / Courtland Allen，来自 c1c7 渠道）。建页由 `kind=person` 的条目自动分流（`kb_collect.write_person_note`）。

> **为什么不叫 README.md**：`30-人物/` 和 `40-方法论/` 各有一份说明页，同名 stem 会让
> `[[README]]` 解析歧义（Obsidian 按文件名解析，撞名结果不确定）。说明页一律命名
> `<目录主题>说明.md`，全库 stem 唯一 —— 规范见 [[命名与目录规范]]。

**怎么填**（下一轮任务）：

```bash
# 按 author 聚合出现次数（示例）
python - <<'EOF'
import json, glob, collections
rows = []
for f in glob.glob('90-原始/*/*.jsonl'):
    for ln in open(f, encoding='utf-8'):
        if ln.strip():
            rows.append(json.loads(ln))
lat = {r['item_id']: r for r in rows}          # 按 item 取最新
c = collections.Counter()
for r in lat.values():
    if r.get('author'):
        c[(r['author'], r['source_id'])] += 1
for (a, s), n in c.most_common(40):
    print(f"{n}\t{a}\t{s}")
EOF
```

筛选规则建议：同一 author 出现 ≥2 个项目 → 建人物页；标记其项目（wikilink 到 `10-项目/`）与代表性发言（wikilink 到 `20-语料/`）。
