Send files and text instantly using a six-character code
Space moves photos, videos, files, links, and text between any devices using a simple six-character code or lets you start a space drop zone for local file sharing with others in the same room. It encrypts data on your device and only relays sealed chunks, so the server can’t read your content. Files auto-delete in about 15 minutes. Use it on iPhone, Android, Mac, or any browser without creating an account. Features include nearby device radar, Direct Send by @username (basic email sign-up required), Quick Drop, and Spaces for live, read-only boards that update in seconds.
