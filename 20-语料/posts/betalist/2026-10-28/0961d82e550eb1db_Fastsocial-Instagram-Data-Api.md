FastSocial Instagram Data API
Access public Instagram profiles, posts, and reels as clean JSON
FastSocial Instagram Data API offers a REST API and MCP server for public Instagram data including profiles, follower counts, posts, reels, stories, highlights, comments, and engagement rates, all returned as clean JSON. It provides 27 read-only endpoints, uses one API key, and supports the OpenAPI 3.1 specification. You can add the MCP server to Claude, ChatGPT, or Cursor to query data such as follower counts. Most calls cost 1 credit, and failed calls are free. The free plan includes 50 credits monthly with no card required. Paid plans start at $4.99 a month. The service only provides public data and is not affiliated with Instagram or Meta.
