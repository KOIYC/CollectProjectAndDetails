Upfling.host
Host any site or file by dragging it in and get a live URL in 20 seconds
Upfling lets you put a website or file online without Git, builds, or a deploy dashboard. Drag in an index.html, a folder from an AI builder, or a ZIP file. It finds the entry point, scans the files, and provides a clean URL and QR code in about 20 seconds. Use it for sites, PDFs, images, and documents. You can add a custom domain, password protection, and replace files without changing links. Start free, then scale storage and site limits as you grow.
