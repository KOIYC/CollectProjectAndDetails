Naetive
Keep your project's understanding shared across AI agents
Every new agent session starts from zero and reads everything again. Naetive keeps what your agents learn about the project—how it is built, what has been decided, and what must not break—and passes it to the next agent you open, whether Claude Code, Codex, or ChatGPT. Claims about the code cite the lines they came from and are marked for re-check when that code changes. The understanding can be exported into your repo as a plain .naetive folder so it travels with every clone.
