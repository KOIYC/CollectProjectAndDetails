QRFLOW
Generate, edit, and track QR codes with AI chat bots and MCP server
QRFLOW.codes runs as an MCP server, so assistants like Claude or ChatGPT can create and manage codes for you. It also offers a fast, no-signup QR code generator with live previews and instant PNG or SVG downloads. You can create link, Wi-Fi, vCard, phone, SMS, and other codes, then save them to a dashboard to edit destinations later. The premium plan lets you make every code dynamic, add your own domain, embed logos, and access detailed scan analytics with CSV export and bulk generation.
