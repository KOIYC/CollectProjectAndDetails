Shapeweld
Convert and view 3D files in the browser for free without an account
Shapeweld offers 88 free 3D tools that run in your browser. You can drop an FBX file to get a GLB with textures packed in, convert GLB back to FBX for Unity or Unreal, send STL to 3MF for slicing, or make USDZ for AR on iPhone. Each converter clarifies format limitations, and results open in a viewer with one click.
Viewers for GLB, FBX, OBJ, STL, 3MF, USDZ, VRM, and G-code run locally without uploads. It also includes mesh tools like decimate, repair, UV unwrap, VRM tools for VTuber models, 415 free VRM avatars, and an MCP server for coding agents to convert files. No account or installation required; uploads are deleted after 3 days.
