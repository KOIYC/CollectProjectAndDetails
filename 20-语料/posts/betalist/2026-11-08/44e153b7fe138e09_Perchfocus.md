Perch
Keep Claude Code organized on your Mac with alerts only when needed
Perch provides a calm Mac workspace for Claude Code by gathering every session, pull request, and link in one place. It resumes chosen Claude sessions exactly where they left off, shows PR context across repos, and notifies you only when Claude, a reviewer, or CI needs attention. Perch keeps sessions running through quitting and updates, supports deep focus on a single context, and stores everything locally with no accounts or tracking, using your existing Claude and GitHub CLIs.
