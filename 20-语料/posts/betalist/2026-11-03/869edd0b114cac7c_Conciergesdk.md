ConciergeSDK
In-app support chat with AI agent and MCP server for mobile apps
ConciergeSDK is a native support chat for iOS, Android, React Native, Flutter, or web apps, installed with one prompt to your coding agent. An AI agent replies first from your docs, labeled as AI, then hands off to you for personal support. If users mention cancelling or cost, an offer card opens your purchase flow. Only happy users get review prompts. Apple refund requests are answered using your policy. Manage the inbox via Claude Code, Cursor, or Codex through a 51 tool MCP server. Includes unlimited apps and seats, plus 1,000 AI replies monthly.
