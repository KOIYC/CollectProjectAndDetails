 Seven weeks after launch: using MarketOtter on my second product
When I launched MarketOtter here in August, its only real test was planning its own launch. That's a convenient test: I wrote the tool, so of course it fit my product.
 The honest test is a second product. I'm now running the launch of StoriesDen, a writing studio for indie authors, through MarketOtter. Launch day is 3 November, and the run-up started this week.
 What held up. The research. It found the six tools authors actually compare StoriesDen against and built a feature-by-feature comparison, which is now a page on StoriesDen's own site. It also scheduled a run of "credibility" posts before any promotion: genuine questions, no link, no pitch, because the channels it picked punish accounts that only show up to sell.
 What broke. Using it on a second product surfaced a bug the first one never did. The public comparison read the checked, sourced results, but the comparison grid on the product's own overview read a separate list of names, so the two disagreed and the grid came up blank. Now both read the same results, and each cell shows where its answer came from.
 The numbers. No paying customers yet. Revenue is $0, which is what the product page says.
 A question for anyone who has launched more than one thing: for your second launch, did you reuse the first one's plan, or start from scratch?
