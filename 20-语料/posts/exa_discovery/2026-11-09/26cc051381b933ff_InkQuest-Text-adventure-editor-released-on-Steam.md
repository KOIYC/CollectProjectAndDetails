## InkQuest: Text adventure editor released on Steam

 07.11.2026 2 minutes read

The InkQuest: Text Game Engine has been released for Linux on Steam.

InkQuest is an editor for creating text adventures without any programming: rooms are drawn on a map, rules are set via dropdown menus. It costs €13.49, with a launch discount of 19% (€10.92).

Finished games can be exported as a web version (runs offline in the browser) or as a desktop app for Windows, macOS and Linux - with no watermark, royalties or revenue share.

> InkQuest is a program for making text games — the kind you play by reading a description of where you are and deciding what to do next. Think of a book where the reader chooses what happens.
>
> You build the game like this: you draw a map of rooms, you write what the player sees in each one, and you set the rules by choosing from menus. Then you press one button and you have a finished game you can share with anyone.
>
> You do not write any code. Not one line.
>
> Draw the world. ... Fill the rooms with things, people and doors.
>
> Set the rules. Every rule is one sentence you build from dropdown menus: WHEN the player enters the vault, IF they carry the lamp, THEN show this text.
>
> Press play. Your game runs in the same window you are editing in, so you can try an idea and see it working seconds later.
>
> Classic text games ask the player to type (take the lamp, go north). Newer ones show a list of choices to click. InkQuest does both, and it is one setting.
