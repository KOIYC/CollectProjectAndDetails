Polishory, created by developer HYEON GYE YONG, has officially debuted on Product Hunt as a specialized web evaluation platform designed to help builders elevate their digital presence. Developed during the OpenAI GPT-6 Astra Challenge, the tool addresses a frequent problem faced by solo founders and independent engineers: websites that function properly but suffer from generic, unpolished visual aesthetics often described as AI slop. By analyzing any public URL across desktop and mobile formats, Polishory delivers automated design scorecards, visual feedback linked to captured screenshots, and prioritized recommendations covering spacing, layout, typography, and visual hierarchy. Crucially, the system operates completely externally without requiring access to source code or modifying site files directly, offering an objective roadmap for design refinement.

As modern software development accelerates through automated scaffolding and AI code generation, functional applications can be spun up faster than ever. However, this velocity often introduces a recurring aesthetic dilemma: products that execute their intended features smoothly yet look visually indistinct, bland, or unfinished. Maker HYEON GYE YONG launched Polishory on Product Hunt specifically to address this gap. The platform targets the ambiguous instruction to "make it look better," translating vague design dissatisfaction into structured, tactical evaluations. Rather than making assertions about whether artificial intelligence generated a site, Polishory provides a measurable design guide aimed at helping builders eliminate visual clutter and prevent what the tech community increasingly terms "AI slop."
...
The creation of Polishory highlights modern rapid prototyping dynamics. Built for the OpenAI GPT-6 Astra Challenge, the project was turned from a bare concept into a functional product in just three days. Leveraging modern web infrastructure—including Vercel for hosting, Clerk for user management, and Paddle for billing integrations—HYEON GYE YONG utilized GPT-6 Astra to build the analysis pipeline and repeatedly refine the mechanism that interprets visual layouts and translates findings into actionable guidance. The developer intends to expand Polishory beyond the initial challenge, focusing on improving recommendation accuracy and delivering even clearer execution steps for developers.
...
Polishory is an automated design review platform built for solo founders, indie creators, and web developers. It inspects public desktop and mobile web pages to identify generic design patterns, provide visual scorecards, and outline specific fixes for typography, spacing, and layout.
...
Polishory was developed by HYEON GYE YONG as an entry for the OpenAI GPT-6 Astra Challenge. The maker used the model to build the core evaluation pipeline and accelerate product iteration, taking the tool from initial idea to working deployment in three days.
