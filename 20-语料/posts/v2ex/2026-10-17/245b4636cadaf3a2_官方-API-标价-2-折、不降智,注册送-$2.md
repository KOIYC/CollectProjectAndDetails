# 蜂桥 AI：官方 API 标价 2 折、不降智，注册送 $2

**蜂桥 AI （ BeeBridge ）** 是一个面向个人用户和独立开发者的 AI API 接入服务。

如果你平时会用 AI 辅助写代码，或者在支持自定义 API 的客户端里做翻译、写作、总结，也许可以试试。

先说大家最关心的三件事：

- **价格按对应模型官方公开 API 标价的 2 折，也就是 20% 计费。** 具体模型和计量项的价格可以在站内模型广场查看。
- **不降智：不私自换成低档模型，不擅自降低推理配置。** 不靠这些方式降低价格；你选什么模型，就应该按对应模型的能力和配置来使用。
- **新用户注册送 $2 API 体验额度。** 这笔额度用于站内 API 调用，具体领取和使用规则以注册页面为准。


“不降智”说的是服务端不主动做模型降档或降低推理配置，不是承诺每次回答都正确。可以拿熟悉的代码问题、文档或工作任务，在相同模型和相近参数下对比体验。

个人用户调用模型，往往只是为了写一个脚本、改一个小功能，或者处理一份文档。这类零散任务，除了模型能力，也需要关注工具是否兼容、一个任务实际花了多少，以及费用能否查清楚。

目前比较适合这几类用法：

- **辅助编程**：在支持自定义模型服务的编程工具里，读代码、改功能、排查报错。
- **日常文本处理**：搭配兼容客户端，做翻译、润色、长文总结。
- **个人小工具**：给自己的脚本、笔记工作流或小应用接入模型。

开始使用的流程是：注册账号，创建 API Key ，然后按照接入文档，把地址、Key 和可用模型填到兼容工具里。控制台可以查看调用记录、Token 用量和费用，方便判断一个任务实际花了多少。

**蜂桥是独立服务，提供模型 API 接入，与模型厂商的官方订阅分别管理和计费。** 这里说的“2 折”，指 API 调用价格的比较，不是 ChatGPT 等网页产品订阅的折扣。工具兼容性、可用模型和具体价格，请以站内说明为准。
