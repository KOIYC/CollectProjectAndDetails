# 个人技术工作室 · 承接网站及前端开发项目

**专注前端开发，用技术把你的想法变成现实！**

无论你是创业者、企业负责人、设计师，还是有开发需求的个人，只要你有想法、有设计、有业务需求，我都可以为你提供专业的前端开发服务。

## 一、业务范围

**01｜网站开发**
- 企业官网、品牌展示网站
- 产品官网、营销落地页、活动专题页
- SaaS 平台、管理后台、数据可视化页面
- AI 工具网站、个人作品集、独立站
- 网站改版、页面重构、性能优化

**02｜小程序开发**
- 微信小程序页面开发
- 产品展示、预约报名、信息查询
- 用户中心、表单系统、业务功能页面
- 小程序 UI 还原、交互开发与功能迭代

**03｜浏览器插件开发**
- Chrome / Edge 浏览器扩展
- 网页数据提取与自动化辅助工具
- 网页功能增强、效率工具
- 第三方 API 对接与插件功能定制

**04｜其他前端开发需求**
- Figma / PSD 设计稿还原
- 现有项目 Bug 修复与功能迭代
- 响应式布局与移动端适配
- 前后端接口联调、第三方服务集成
- AI 产品前端开发与交互实现

## 二、技术栈

熟练使用主流前端技术，为不同项目选择合适的技术方案：

- **Vue / Vue 3**：企业应用、管理后台、业务系统
- **React**：交互式 Web 应用、复杂前端项目
- **Next.js**：SEO 友好的网站、SaaS 产品、AI 工具平台
- **TypeScript / JavaScript / HTML / CSS**：稳定、规范、易维护的代码实现

## 三、合作优势

**沟通直接，需求响应快。** 无需复杂的沟通流程，直接对接开发人员，减少信息传递成本。

**按需定制，灵活合作。** 支持整包开发、按功能模块开发、短期技术支持及长期项目合作。

**重视质量，注重交付。** 关注页面还原度、交互体验、代码质量、运行稳定性与后续维护。

**预算灵活，合理报价。** 根据项目需求、开发难度和交付周期评估工作量，提前沟通范围与费用。

## 四、合作流程

需求沟通 → 方案评估 → 报价与排期 → 开发实施 → 测试验收 → 项目交付

无论是一个简单的展示页面，还是一套完整的 Web 应用，都欢迎交流。
