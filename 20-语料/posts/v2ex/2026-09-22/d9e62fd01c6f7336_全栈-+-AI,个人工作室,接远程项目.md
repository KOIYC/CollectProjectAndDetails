个人工作室（时述信息技术工作室），坐标哈尔滨，远程工作。项目制合作、按阶段交付、长期合作、远程全职都可以。

**做过什么**

独立承接过一个政务方向的 AI 写作 SaaS 平台（ Vue3 + Python FastAPI + PostgreSQL + 向量数据库 + Docker Compose ），从需求分析、技术方案评审、报价到开发交付，全程一人完成。

同时在维护一个自研的带记忆系统的 AI 对话应用，已上线 iOS TestFlight ，日常使用中。完整的 RAG 检索系统、多模型编排、HealthKit 集成、后端定时任务调度，从架构到部署到运维都是自己在做。

**技术栈**

▸ 前端：Vue3 / Vite / UI 设计 / CSS3 动画 / Canvas / SVG / 移动端适配

▸ 后端：Node.js / Express / Python / FastAPI / PostgreSQL / Qdrant

▸ AI：多模型编排 / RAG / Agent 工作流 / Prompt 工程

▸ 部署运维：Nginx / PM2 / Docker Compose / Codemagic CI·CD / Linux 服务器

▸ 移动端：Capacitor 8 → iOS TestFlight 持续交付

**能接的方向**

AI 应用开发（ RAG / LLM 编排 / Agent / SaaS ）、全栈 Web 交付、单独前端或后端、iOS 打包交付、项目早期的需求分析和技术方案评估。项目制合作，按阶段交付。
