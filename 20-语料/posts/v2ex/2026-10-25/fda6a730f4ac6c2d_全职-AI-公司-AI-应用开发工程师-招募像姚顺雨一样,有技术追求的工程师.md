#  [全职 / AI 公司]  AI 应用开发工程师｜招募像姚顺雨一样，有技术追求的工程师

姚顺雨，腾讯史上最年轻的首席 AI 科学家，技术突破的硬核代表！

清华姚班出身，后赴普林斯顿大学攻读博士。

博士五年只死磕一件事：让大模型学会先想再做。

他以第一作者身份提出 ReAct 框架，让 AI 先推理、再行动、拿行动结果修正判断。

今天主流的 AI 智能体产品，底层都是这个思路。

2024 年，他加入 OpenAI ，主导开发出第一个智能体产品 Operator ，

让 AI 第一次能自己打开浏览器、自己把事办成。

  
从普林斯顿到 OpenAI 再到腾讯，姚顺雨靠的从来不只是天赋，

而是对问题纯粹到极致的好奇心，和认准一个方向就死磕到底的钻研。

  
如今，Agent 正从学术前沿加速迈入产业落地的黄金时代，这是当下最明确的时代风口！

  
比特鹰紧抓 AI 浪潮，是国内领先的 AI 产品型公司，主打 AI 数据决策智能体研发，目前正处于高速上升期。

我们正在招募像姚顺雨一样，对 Agent 与 AI 前沿充满热情、敢于挑战技术极限、渴望用代码改变产业的追梦工程师。

我们为每位成员定制专属 AI 成长路径，全力赋能个人成长，助你与最优秀的同行者一起，成为 AI 时代的超级个体！

** [公司介绍] **  
比特鹰是一家快速成长的 AI 产品公司，赋能每一人成为 AI 时代的超级个体。

我们要找的不是调几个 Prompt 跑通 Demo 的人。

我们需要能独立承担并持续维护一套线上 AI 对话／ Agent 系统的工程师。

从多模型接入、Agent 编排、上下文与记忆、流式响应，到评估、可观测、成本与稳定性，都需要参与。

系统已经在生产环境运行，你入职后会接手既有代码并持续迭代，有资深工程师一起做方案设计和 Code Review ，但我们期待你能尽快独立扛事。

公司公众号：比特鹰 labs

公司地址：广州市天河区

** [还有哪些岗位招聘？] **

-    工程师：基建工程师、AI 开发、后端、前端、大数据、爬虫、测试、安全
-    运营设计类：运营经理、产品经理、AIGC 设计师

** [为什么要加入我们] **

-    **无限 Token 的 AI 研发支持**：公司提供 Claude Code ／ Codex 等顶级工具且不限量，鼓励用 AI 辅助写代码、调研、设计 Prompt 、搭评估，研发效率拉满。
-    **做真东西，不做 Demo**：系统已服务公司核心业务，重视架构、质量和长期可维护性，不是写完就废的一次性脚本。
-    **完整技术栈成长**：从 LLM 编排、上下文工程、向量检索，到异步、消息队列、可观测性、云原生部署，一条龙都会接触。
-    **有高手带，也给你舞台**：资深工程师带你拆需求、定方案、治理模型不确定性，同时给你独立负责模块的空间。
-    **业务前景明确**：AI 是公司的底层核心能力，这个岗位直接影响产品形态和业务增长，不是边缘支持岗。
-    **团队扁平直接**：看重解决问题的能力和学习速度，不搞复杂层级，不卡学历和专业。
-    **有想象空间的回报**：长期贡献突出者，提供年终奖与股权激励机会。

** [岗位职责] **

-    负责线上 AI 对话／ Agent 系统的开发、调优与维护，保障回复稳定、准确、及时；
-    维护并扩展多模型／多供应商接入层，处理不同模型在能力、参数、计费、限流、故障上的差异，做好自动降级与容错；
-    设计与迭代 Agent 编排：意图路由、工具／技能调用、多步任务执行，在“可控”和“灵活”之间做合理权衡；
-    做上下文工程与检索／长期记忆：在有限上下文窗口内决定“放什么、放多少、怎么排”，并用向量检索提升回复相关性；
-    维护流式响应链路，处理流式带来的一致性、持久化与异常问题；
-    建设和使用评估与可观测体系：让模型／ Prompt 的每次改动可量化、可回归，让线上的“静默错误”可快速定位；
-    做成本与稳定性治理：Prompt 缓存、按任务分级选型、超时重试、幂等、限流等，把账单和延迟压在合理范围；
-    基于异步 Python ＋消息队列＋数据库持续提升系统并发能力与可维护性，参与微服务部署与运维。

** [入职要求] **

-    不限学历专业，看重实际能力、学习能力和解决问题的韧性；
-    熟悉 Python ，能熟练写 asyncio 异步代码，有并发与性能优化意识；
-    有真实的大模型应用开发经验（ GPT ／ Claude ／ DeepSeek ／任意模型），深入理解流式输出、结构化输出／ Function Calling 、多轮对话与上下文管理；
-    用过至少一种 Agent ／编排框架（ LangChain 、LangGraph 、CrewAI 、Agno 等），能讲清节点／工具／状态是怎么串起来的，遇到问题能自己 Debug ；
-    理解 RAG ／向量检索原理，知道朴素“切块—Embedding—检索”为什么会翻车，并能说出改进方向；
-    有“治理不确定性”的工程意识：清楚 LLM 会失败、会抽风，愿意为可靠性、重试、降级、评估买单
-    熟悉 PostgreSQL （或同类关系库）与 Redis ，能独立做数据建模和事务／缓存设计；
-    接触过消息队列（ RabbitMQ ／ Kafka 等）与异步任务处理，理解至少一次投递与幂等；
-    熟悉 Docker ，能在容器化环境下开发和排查问题。

** [加分项] **

-    搭过评估体系，能讲清“怎么判断一次改动是改进还是退化”，用过 LLM － as － judge 并知道它的坑；
-    有 Token 成本／延迟优化实战，理解 Prompt 缓存原理；
-    用过 pgvector 等向量数据库，或做过长期记忆／知识库类系统；
-    接触过可观测性工具（ Langfuse 、OpenTelemetry 、Prometheus 等），做过 AI 全链路追踪/质量监控；
-    了解 Prompt 注入等 AI 特有安全风险，有纵深防御意识；
-    熟悉 Kubernetes ／微服务架构，有线上部署与运维经验。

** [企业福利] **

-    对做出突出贡献的核心伙伴，提供更匹配能力和贡献的长期回报；
-    导师带教，定制学习成长路线，帮助提升业务和技术体系；
-    节假日礼品、生日关怀、办公设备和基础生活用品支持；
-    每月团建、聚餐，每周运动活动，每年免费体检；
-    餐补、房补、零食不限量；
-    书籍、课程等学习费用可报销。
