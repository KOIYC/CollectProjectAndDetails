## 正文

我们正在招聘以下岗位，主要负责区块链对接、基础设施运维和开发工具建设：

**职位名称：区块链集成工程师**

**岗位定位**

负责公链应用基础设施的技术方案和集成交付，连接协议研发团队、基础设施合作方和生态开发者。早期以实际开发和问题解决为主，同时承担技术决策、任务拆解和上线验收。

**工作职责**

1. 制定应用基础设施路线图，明确钱包、RPC 、浏览器、索引、多签及资产进出渠道的建设顺序，评估自建与合作接入方案。
2. 设计链与外部服务之间的接口、适配层和数据约定，维护网络参数、交易格式、资产标识与版本兼容要求。
3. 推进钱包、浏览器、多签及其他基础设施的接入，完成技术评估、适配开发、联调和验收。
4. 实现必要的链上组件、集成服务及参考应用，验证从用户授权到交易确认的完整流程。
5. 建立集成测试和上线标准，覆盖交易失败、重复提交、权限异常、节点故障及协议升级等情况。
6. 与协议研发团队共同定位问题，推动底层能力、接口和工具改进。
7. 配合外部安全审查，落实问题修复；评估生态资助项目的技术方案和交付质量。

**任职要求**

- 具备扎实的软件工程经验，能够独立完成系统设计、编码、测试与上线；有复杂系统集成或技术负责人经历。
- 理解区块链账户、签名、交易生命周期、手续费、事件和最终确认机制。
- 熟悉至少一种主流公链开发栈，具备智能合约或链上程序的开发、部署和调试经验。
- 熟悉 API 设计、版本管理、自动化测试及常见安全问题。
- 能阅读英文技术文档和开源代码，与外部技术团队协作解决问题。
- 能在有限资源下判断优先级，将技术方案拆解为可验收的交付任务。

**加分项**

- 参与过公链、钱包、跨链、多签或链上数据平台的集成。
- 有开源项目贡献、安全审查整改或主网上线经验。

**入职前六个月的主要成果**

- 建立应用基础设施架构、接口约定和上线验收机制。
- 打通钱包连接、交易提交、结果查询和资产进出等关键流程。
- 支持 2—3 个独立生态团队完成接入，并持续改善集成效率。

**协作边界**

对集成方案、技术取舍和交付质量负责；与协议团队共同处理底层问题。平台运行由运维工程师主责，SDK 和开发文档由开发者体验工程师主责。

**职位名称：运维工程师（区块链基础设施方向）**

**岗位定位**

负责支撑应用开发与运行的平台服务，保障节点接入、RPC 、浏览器、索引及相关服务的可用性、数据准确性和运行成本。

**工作职责**

1. 部署和维护测试网、主网所需的全节点、RPC 网关、浏览器、索引及相关数据库服务。
2. 建设自动化部署和配置管理流程，支持环境隔离、版本发布、备份恢复及故障切换。
3. 建立监控与告警体系，持续跟踪链同步、RPC 成功率与延迟、索引滞后、存储容量及资源消耗。
4. 排查服务中断、节点落后、数据不一致、请求超时等问题，建立故障处理手册并开展恢复演练。
5. 实施访问控制、密钥与凭证管理、限流和基础网络防护，落实生产环境操作审计。
6. 与外部 RPC 、索引及云服务商协作，验证服务能力、故障支持和替换方案。
7. 进行容量评估与成本优化，为生态项目提供生产接入建议，避免公共测试服务承担不适合的生产负载。
8. 参与团队轮值和事故复盘，推动重复问题通过自动化或架构调整解决。

**任职要求**

- 具备生产系统运维、平台工程或 SRE 工作经验。
- 熟悉 Linux 、网络、容器、数据库和至少一家云平台，能够独立排查系统问题。
- 熟悉自动化部署、基础设施配置管理、日志、指标和告警工具。
- 理解高可用、备份恢复、容量规划和故障隔离，能够设计并执行验证方案。
- 具备脚本或后端开发能力，可使用 Python 、Go 、Shell 等完成运维自动化。
- 了解区块链节点同步、RPC 、交易确认和链上数据索引；能够通过文档与代码快速掌握具体链的运行机制。

**加分项**

- 有公链节点、RPC 服务、区块浏览器或索引平台的运行经验。
- 有高并发 API 、大规模数据同步、数据库性能优化或重大故障处置经验。

**入职前六个月的主要成果**

- 建立可重复部署、可监控、可恢复的平台环境。
- 完成 RPC 故障切换、数据恢复和服务异常演练。
- 建立可用性、数据新鲜度、响应时间及运行成本报表，支持首批应用稳定运行。

**协作边界**

对应用基础设施的运行质量负责，与协议团队划分节点软件及网络问题的处理责任。生产值守由团队和服务商共同安排；资金及关键权限操作按多签或审批机制执行。

**职位名称：SDK ／开发者体验工程师**

**岗位定位**

负责让外部开发者快速理解、接入并持续使用公链。通过 SDK 、示例应用、文档和技术支持，降低应用开发成本，并将开发者反馈转化为产品改进。

**工作职责**

1. 开发和维护面向应用开发者的 SDK 、钱包连接适配和常用组件，优先复用成熟开源工具。
2. 封装交易构建、签名协作、提交、状态查询、事件读取和错误处理等常见流程。
3. 建设应用模板和参考项目，提供可直接运行的转账、资产领取、合约调用及查询示例。
4. 编写和维护快速入门、API 文档、部署指南、故障排查和版本迁移说明。
5. 建立 SDK 的测试、发布和版本管理流程，验证其与钱包、节点及协议升级的兼容性。
6. 支持首批生态团队接入，复现问题、定位原因，并与集成和平台工程师协作解决。
7. 跟踪首次部署耗时、接入成功率和常见报错，持续改善接口设计、错误提示和文档。
8. 参与开发者交流、技术演示和开源社区维护，将高频问题整理为可复用的工具与知识。

**任职要求**

- 具备软件开发经验，熟悉 TypeScript ／ JavaScript ；其他语言要求根据公链技术栈确定。
- 有 SDK 、开发工具、公共组件或 API 客户端的设计与维护经验，重视接口易用性和兼容性。
- 理解钱包签名、链上交易、合约调用、事件和资产授权等基本流程。
- 能独立开发和调试一个包含前端与链上交互的完整示例应用。
- 熟悉包管理、自动化测试、持续集成及版本发布。
- 具备清晰的技术写作和沟通能力，能够阅读英文文档、定位开发者问题并提供可执行的解决方案。

**加分项**

- 维护过有外部使用者的开源 SDK 、组件库或开发框架。
- 有开发者支持、技术教育、钱包适配或多链应用开发经验。
- 了解账户抽象、嵌入式钱包或手续费代付相关工具。

**入职前六个月的主要成果**

- 交付稳定的 SDK 、应用模板及完整接入文档。
- 让未参与内部开发的工程师能够按文档独立完成首个应用部署。
- 支持 2—3 个生态团队复用现有工具，减少重复开发和反复咨询。

**协作边界**

对开发者接入体验和工具质量负责；与技术负责人共同确定接口约定，与平台工程师协作处理服务问题。技术支持中发现的共性问题，应沉淀为代码、测试或文档改进。
