## 二、岗位详情

### 1. 高级 Java 开发工程师

**薪资待遇：15-20K · 13 薪**

#### 岗位职责

1. 带领开发团队进行需求分析、系统设计、开发和优化，确保项目按时、高质量交付。
2. 制定和推动编码规范，保证代码质量和开发效率。
3. 负责团队成员的技术指导与培养，提升团队的整体技术水平。
4. 参与系统架构设计，优化系统性能和可靠性。
5. 协调与产品经理、测试和运维团队的沟通，确保各部门间的有效协作。

#### 任职要求

1. 计算机科学、软件工程或相关专业，本科及以上学历。
2. 5 年以上 Java 开发经验，2 年以上开发团队管理经验。
3. 精通 Java 基础知识，熟悉 Spring、Spring Boot、MyBatis 等常用框架。
4. 有大型分布式系统设计和开发经验，熟悉微服务架构设计、消息队列、中间件等技术。
5. 具备优秀的代码编写能力和良好的设计文档书写习惯。
6. 对新鲜事物持开放心态，能按工作需要学习新的开发语言、业务流程、商业模式等。
7. 优秀的沟通协调能力和团队协作能力，能够推动项目进展。
8. 有责任心，具备良好的抗压能力和问题解决能力。
9. 有电商、供应链、仓储相关系统经验者优先。

---

### 2. Java 开发工程师

**薪资待遇：13-16K · 13 薪**

#### 岗位职责

1. 参与需求讨论，负责基于 Spring Cloud 技术体系的供应链相关系统开发。
2. 参与制定开发计划，根据计划独立完成中小型系统的系统分析、设计、编码、调试、测试和维护工作。
3. 及时暴露和解决开发过程中出现的问题和风险。

#### 任职要求

1. 大专及以上学历，计算机相关专业，3 年以上互联网行业 Java 开发经验。
2. 能理解 UML、DDD 等建模语言。
3. 精通 Java EE 技术体系，熟悉 Spring Boot、MyBatis 等常见开发框架，有 Spring Cloud 相关微服务系统开发经验者优先。
4. 熟悉分布式、多线程、网络通信、数据库（MySQL）、消息中间件（RocketMQ）、分布式缓存（Redis）、搜索引擎（Elasticsearch）等相关技术。
5. 熟悉 DevOps 流程规范，并参与过平台搭建；有电商行业、供应链系统开发经验者优先。

---

### 3. AI 工程师

**薪资待遇：15-25K · 13 薪**

#### 岗位职责

1. 使用 Python 语言开发 AI 应用。
2. 分析和评估现有数据集，并进行数据预处理和特征工程，以提高 AI 模型的准确性和性能。
3. 将 AI 模型集成到现有软件系统中，并进行测试和调试，确保其正常运行。
4. 提供技术支持和问题解决，确保 AI 模型的稳定性和应用效果。

#### 任职要求

1. 国内 985、211 院校统招本科，或国外常青藤等一流大学毕业生；计算机科学或相关领域本科学历，或者具有相关工作经验。
2. 熟练掌握 Python 编程语言。
3. 英语能作为工作语言，具备英语技术文档阅读和理解能力，能够独立学习和掌握新的技术知识。
4. 对机器学习和自然语言处理有基础理解。
5. 对 AIGC 等前沿 AI 技术有强烈兴趣，愿意不断学习和探索应用于业务场景。

---

### 4. 高级数据产品经理

**薪资待遇：20-30K（薪资月数未注明）**

#### 岗位职责

1. 维护平台运营安全及风险管控，包括决策、统筹、设计、执行、管理（部门内外）。
2. 维护和经营与电商平台的战略合作关系。
3. 负责团队管理，有针对性地制定相关操作规范，确保平台组工作有序、高效地完成。
4. 赋能业务，与公司内各业务部门合作并实施公司的商业计划。

#### 任职要求

1. 全日制本科及以上学历，具有留学经验，5 年以上数据分析、产品经理经验者优先。
2. 具备清晰的逻辑思维。
3. 具有较强的执行力、沟通表达能力和服务意识。
4. 熟悉或接触过跨境电商、Amazon 业务者优先。

---

### 5. 中级系统测试工程师

**薪资待遇：13-18K · 13 薪**

#### 岗位职责

1. 负责业务系统的功能测试、接口测试、数据测试，编写测试方案、测试用例，执行测试、跟进缺陷闭环，保障版本上线质量。
2. 使用 SQL 完成数据验证，熟练增删改查、多表联查，定位数据类问题。
3. 基于 Python 编写简单脚本、自动化或辅助工具，落地 AI 测试提效实践（用例生成、接口校验、数据构造等）。
4. 参与需求评审、用例评审，识别需求风险，输出测试结论。
5. 沉淀测试方法、提效工具，持续优化测试流程。

#### 任职要求

1. 2 年及以上软件测试相关工作经验。
2. 熟练 MySQL，掌握增删改查、连表查询，能够独立通过 SQL 校验业务数据。
3. 熟悉 Python，可独立编写测试脚本、小工具。
4. 有 AI 测试落地经验，会使用大模型辅助测试工作（用例、数据、缺陷分析等）。
5. 精通功能测试、接口测试、数据测试，了解接口测试工具（Postman、JMeter 等）。
6. 有跨境电商业务测试经验者优先。

---

### 6. 业务数据分析师

**薪资待遇：15-18K · 13 薪**

#### 岗位职责

1. 负责跨境电商 Amazon 业务板块的数据分析与模型支持工作，通过数据驱动运营决策，提升业务效率与算法能力。
2. 日常监控业务行为与结果指标，及时发现指标异常波动，开展归因分析，输出分析报告，支撑运营快速响应。
3. 参与数据模型的设计与上线工作，负责底层数据处理、清洗及分析，为业务端提供高质量的数据支持。
4. 总结内部算法在实际业务中的表现，识别潜在问题与优化空间，为算法迭代提供数据支撑与业务背景分析。
5. 协助业务开展模式建设类项目，包括项目背景梳理、内外部需求调研、数据处理与分析等工作，推动项目落地。

#### 任职要求

1. 本科及以上学历，数据科学、信息与计算科学、统计学等相关专业优先，具备 2 年以上跨境电商或 Amazon 运营分析经验者优先。
2. 熟练使用至少一种 BI 工具（如 FineBI、Tableau、Power BI 等），精通 Excel，掌握 Python 进行数据处理与分析。
3. 具备独立开展课题分析或专项研究的能力，逻辑清晰，善于从数据中提炼业务洞察。
4. 熟悉 MySQL 等主流数据库，熟练掌握 SQL 语言，能够高效完成数据提取与处理。
5. 具备良好的数据敏感度，能够快速理解业务逻辑，具备扎实的分析能力与系统性思维。
6. 具备良好的团队合作意识与跨部门沟通协调能力，责任心强，乐于主动学习，能适应快速变化的业务环境。

---

### 7. AI 技术专家

**薪资待遇：30-55K · 13 薪**

#### 岗位职责

1. 从 0 到 1 设计并搭建高并发、高可用、可扩展的系统架构，负责核心业务模块的系统设计与底层代码编写。
2. 负责大语言模型（LLM）、计算机视觉等前沿 AI 技术在复杂业务流中的深度工程化集成（熟练应用 Agent 工作流、RAG 等）。结合实际场景评估模型调用与算力成本，在系统性能、识别准确率与资金 ROI 之间实现最优平衡。
3. 负责泛电商、供应链场景下海量非结构化数据（多模态文本、图像等）的清洗、标准化与特征提取。统筹规划新架构与公司现有内部核心系统（如 ERP、WMS）及外部第三方数据接口的无缝、安全集成。
4. 建立并推行符合现代软件工程的 CI/CD（持续集成/持续交付）流程、需求研发漏斗与代码规范。深入业务一线，实质性地提升团队代码质量、安全防范意识与系统鲁棒性。
5. 拆解复杂的商业需求，制定务实的技术选型、架构演进路线与迭代计划（Sprint），确保业务核心系统在快节奏的商业环境中按时、稳定交付。

#### 任职要求

1. 计算机相关专业统招本科及以上学历，5 年以上扎实的后端架构与重度开发经验。精通 Java、Go、Python（至少熟练掌握其中两种），具备极强的 Hands-on 能力。
2. 对大模型应用层开发有认知和积淀，主导过至少一个将 AI 技术（如文本结构化解析、多模态图像比对、Agent 自动化业务流）深度嵌入实际商业交易或匹配系统的成功案例。
3. 深刻理解电商供应链、履约网络或采购系统底层逻辑。有 B2B、MRO 工业品或大规模长尾 SKU 系统研发和管理经验者优先。
4. 具备目标导向和小步快跑的敏捷交付意识，以及建立交付秩序的成功经验；具备极佳的跨职能沟通能力，能与研究型技术专家默契配合，实现前沿技术成果向商业产品的平滑转化。
