## 正文

各位朋友好，分享一个自己长期维护的 AI API 聚合站，支持标准 OpenAI / Claude 接口格式，可直接对接 Claude Code、Codex、Cherry Studio、CC Switch、LobeChat、NextChat、沉浸式翻译等工具。

站点地址： https://api.apichatgpt.org

---

### 核心福利（零氪可直接用）

1. **国产旗舰模型 0 倍率全免费**
   令牌分组选择 **「全模型白嫖」**（分组倍率 `0`），调用完全不扣余额。
   目前已接入 DeepSeek（V4.1-Flash / V4-Pro 等）、GLM（5.2 / 5.3 系列）、Kimi（K3 / K3.1-Pro）、Qwen 3.8、MiniMax M3、豆包 Seedream、混元、阶跃星辰、商汤日日新等全系主流国模及部分开源视觉/生图模型。

2. **每日签到送余额**
   个人中心每天可签到一次，无门槛随机掉落站内美刀额度。

3. **每 2 小时全站余额空投（太阳掉落）**
   页面常驻活动，大约每 2 小时刷新一次太阳图标空投，每次开放 3 个名额先到先得，随机开出几毛到几十元不等的站内额度。签到和空投攒的余额可以直接拿去调付费区的 GPT / Claude / Grok。

### 价格与倍率说明（透明计费，无套路）

站内计算公式：**最终人民币花费 = 充值兑换汇率 × 分组消耗倍率 × 官方基准价**

**1. 充值/套餐兑换基准（买多少送多少）：**
- **按量余额**：`0.10 元 = $1` 站内额度（1 元充 $10）
- **周卡套餐**：`0.09 元 = $1` 站内额度（9 折）
- **月卡套餐**：`0.08 元 = $1` 站内额度（8 折）

**2. 主流分组折算实付价（叠加充值汇率后）：**
- **全模型白嫖（国模专区）**：分组倍率 `0` -> **完全免费（0 元）**
- **GPT Plus 超低价福利组**：分组倍率 `0.5` -> 余额折合 **0.05 元 / $1**，月卡折合 **0.04 元 / $1**
- **GPT PRO 正价不降智组**：分组倍率 `0.7` -> 余额折合 **0.07 元 / $1**，月卡折合 **0.056 元 / $1**（正价兜底、不降智不限速）
