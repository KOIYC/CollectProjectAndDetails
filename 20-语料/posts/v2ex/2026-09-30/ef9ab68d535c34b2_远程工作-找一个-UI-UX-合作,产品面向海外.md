UI 设计师｜ Web / Web3 / FinTech
我们正在寻找一名 基本功扎实、审美在线、有创意的 UI 设计师，主要负责 Web 端产品的视觉与交互设计。
希望你不只是“把页面做出来”，而是具备较好的视觉判断力，能够理解产品定位，并独立完成具有品牌感、专业感和国际化审美的产品设计。


**岗位职责**

负责公司 Web 端产品的 UI / UX 设计，包括官网、产品后台、Dashboard 、数据平台等；
根据产品需求独立完成页面布局、视觉设计、交互方案及设计规范；
与产品经理、前端开发协作，推动设计方案高质量落地；
持续优化产品的视觉体验、交互体验和品牌一致性；
能够结合业务特点进行原创设计，而不是简单套用现成模板；
关注海外优秀产品和设计趋势，并能将其合理应用到实际项目中。


**任职要求**
UI 基本功扎实，对排版、字体、色彩、间距、栅格、层级、图标等有良好的把控能力；
审美在线，能够判断什么是好的设计，并有自己稳定的设计风格和判断标准；
有创意、有想法，不局限于常规 SaaS / 后台模板化设计；
熟练使用 Figma 等主流设计工具；
熟悉 Web 端设计规范，了解响应式设计及基本的前端实现逻辑；
能够独立完成从需求理解、视觉探索到最终交付的完整设计流程；
有较好的沟通能力，能够清楚表达自己的设计思路和设计依据。

**加分项**
有海外 / 国际化项目设计经验优先；
有 Web3 、区块链、Crypto 、交易平台等项目经验优先；
有金融、FinTech 、证券、支付、数字资产等行业设计经验优先；
做过 Dashboard 、数据可视化、交易页面、资产管理、区块链浏览器等复杂 Web 产品；
有成熟的 Design System / 组件库设计经验；
英文阅读能力较好，能够长期关注海外优秀产品及设计趋势。

我们更看重
相比工作年限和学历，我们更看重你的 作品集和实际设计能力。
希望你的作品能够体现：

扎实的基本功 + 良好的审美 + 原创能力 + 对产品的理解。
