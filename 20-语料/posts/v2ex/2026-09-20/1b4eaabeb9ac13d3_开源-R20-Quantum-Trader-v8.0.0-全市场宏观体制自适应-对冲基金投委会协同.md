## 🎯 核心架构哲学：认知决策归模型，物理风控归底座

市面上的“AI 炒币/量化”软件大多停留在单提示词问答或生硬指标加减分，极易遭遇大模型幻觉导致的意外爆仓。

R20 将架构严谨解耦为三层：
1. **大模型与投委会（只有交易意图的“提案权”）**：负责宏观大局研判、多周期动能理解与多席位博弈；
2. **底层 Python 执行底座（拥有一票否决的“拦截权”）**：每一笔开仓必须穿透不可绕过的物理硬拦截门禁（ 4H 宏观大势顺势检验、真实盈亏比 R:R ≥ 2.0 几何校验、同向持仓额度控制等），任何拦截插件报错无条件 Fail-Closed 熔断；
3. **多交易所平权执行引擎**：统一 OKX 、Binance （币安）、Gate （芝麻开门）数据与风控标准，自动适配币安 Conditional 条件单与 Gate 双向持仓。

## 🚀 v8.0.0 重大更新特性

### 1. 全市场宏观体制自适应识别引擎 (Market Regime Engine)
告别“单边市跑网格被套牢，震荡市跑趋势被反复洗盘扫损”的宿命。系统基于全标的池因果微积分一阶速度 $v$、二阶加速度 $a$ 与定积分能量分布，自动推导大盘宏观四态：
- **`TREND_EXPANSION`（单边动量趋势）**：顺应大势做主升浪，给足 1.8x~2.2x ATR 呼吸空间让利润波段奔跑；
- **`WIDE_RANGE_OSCILLATION`（宽幅上下震荡）**：高波动箱体边际高抛低吸，宽止损隔绝插针，1.5R 快速移损保本；
- **`LOW_VOL_CHOPPY`（窄幅低波横盘）**：低波休眠，自动提高置信度门禁，彻底杜绝无序横盘频繁摩擦磨损；
- **`VOLATILITY_SHOCK`（极端波动冲击）**：识别突发黑天鹅或巨量抽插，激活避险锁仓，坚决捍卫本金底线。

系统全自动生成量化趋势分、波动分与震荡指数，并作为语义变量 `{{market_regime}}` 原生注入大模型推演流。

### 2. 深度思考链 (CoT) 与推演逻辑原生白盒透视
彻底终结大模型“黑盒开仓”！前台操盘轨迹抽屉现已支持逐单展开查看模型在四个维度的完整推演心流：
- **形态结构 (`marketStructure`)**：1H/4H 高低点抬升与箱体边界量化定位；
- **微积分动力学 (`calculusDynamics`)**：速度与加速度符号、做功功率反向耗散判定；
- **数学期望 (`mathProbRationale`)**：条件延续概率、击穿概率与 R:R ≥ 2.0 期望推导；
- **推演草稿 (`reasoning`)**：大模型未经裁剪的完整长推演思考链记录。

### 3. 官方双旗舰预设策略套件
- **默认主策略「全维度波段强化版」**：顺应 4H 宏观多空趋势，给足呼吸空间，严禁过早提损保本，让主升浪充分奔跑；
- **出厂预设「宽幅震荡箱体收割版」**：专抗剧烈洗盘行情！严禁半山腰追价，在箱体上下轨边际挂单，2.2x ATR 宽止损隔绝假突破影线插针，浮盈 1.5R 稳固波段果断移损保本锁死胜率。

### 4. 对冲基金多模型决策委员会 (Council Pro)
模拟华尔街对冲基金 Trading Desk 协作博弈模式：
- **席位自由定义与独立模型绑定**：进攻官、风控官、量化数理官与首席投资官 (CIO) 可独立绑定 Claude 、DeepSeek-R1 、GPT-4o 、Qwen 等不同厂商模型，各展所长；
- **双轮交叉质询辩论 (Cross-Exam)**：第一轮各席位独立提案 ➔ 第二轮同行交叉漏洞挑刺质询 ➔ 第三轮 CIO 综合数理期望与执行风控终审批复发单，消除单模型冲动交易。

### 5. 17 项 Fail-Closed 物理硬拦截流水线
- 4H 顺势单向否决门禁（多头通道严禁摸顶开空，空头承压严禁逆势抄底）；
- 真实盈亏比 R:R ≥ 2.0 几何硬底线（做多 `SL < Entry < TP`，做空 `TP < Entry < SL`）；
- 单笔风险以 1.0R 为基准，根据账户可用资金动态计算，单标的封顶与单日亏损熔断（比例 + 绝对双封顶）；
- 任何风控插件异常，开仓请求无条件强制拦截。

## ⚡ 极速私有化部署 (Linux / macOS)

系统对个人 VPS 非常友好，最低 2C 4G 机器即可顺畅运行，默认直接接入交易所 DEMO 模拟盘，0 资金风险：

```bash
# 1. 克隆代码并安装依赖
git clone https://github.com/555cute/r20-quantum-trader.git
cd r20-quantum-trader
sh deploy/install.sh

# 2. 编译现代化前端管理后台
cd frontend
npm install
npm run build
cd ..

# 3. 启动后端主引擎
python -m uvicorn r20_backend.app:app --host 0.0.0.0 --port 8080
# 或直接通过 ./start.sh 一键运行
```

- 🖥️ **前台极客操盘大屏**：`http://localhost:8080/`
- ⚙️ **后台策略管理控制台**：`http://localhost:8080/admin/login`（默认用户名 `admin`）
