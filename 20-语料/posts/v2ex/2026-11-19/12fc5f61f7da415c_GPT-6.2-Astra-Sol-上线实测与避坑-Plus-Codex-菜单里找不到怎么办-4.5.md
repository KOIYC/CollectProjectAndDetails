# GPT-6.2 Astra / Sol 上线实测与避坑：Plus / Codex 菜单里找不到怎么办？4.5x 速度 6x 扣量怎么算？

## 正文

V 友们好，OpenAI 在 11 月 17 日发布了 GPT-6.2 Astra 和 GPT-6.2 Sol，首发覆盖 ChatGPT Work、Codex 和 API。这两天社区里很多人在问为什么刷新后菜单里还是没有 6.2，以及 Ultrafast 到底怎么扣额度。

结合 OpenAI 官方文档、实际账号界面抓包以及多家第三方机构和开发者的首日实测，我整理了一份硬核避坑笔记，省流结论放最前面：

## 省流版结论（TL;DR）

- **去哪找模型：** 普通 Chat（聊天）菜单本轮没有加入 GPT-6.2 Astra 与 GPT-6.2 Sol。网页与客户端必须手动切换至 Work（工作） 模式，或者把 Codex 桌面端 / CLI 更新到最新版后切换。

- **日常用哪款：** 写代码、改仓库和多步骤办公首选 GPT-6.2 Sol（Work 模式默认启用，API 单价只有 GPT-6.2 Astra 的 1/4，多项基准紧咬甚至反超旗舰）；超长上下文、3D/CAD 交互、科研或高难度代码审查再切 GPT-6.2 Astra。

- **计费大坑预警：** Plus、Pro 100、Business 没有 Ultrafast；Pro 200（仅限 Codex 中的 GPT-6.2 Sol）和 Pro 500 开启 Ultrafast 时，生成速度上限为 Standard 的 4.5x，但套餐额度按 6x 扣除。API 涉及工具调用必须走 Responses API。

---

## 一、为什么刷新后菜单里找不到 GPT-6.2？（四步排查）

绝大多数情况不是账号没推送到，而是入口隔离或前端状态缓存导致的：

### 1. 普通 Chat 不开放，必须切到 Work 模式

- OpenAI 在更新日志里明确写了本轮不将 GPT-6.2 加入普通 Chat 菜单。

- **同一已登录 Pro 账号 Chrome 网页端实测：** 普通「聊天」里展开菜单只能看到 GPT-6 和 GPT-5.6 Sol；切到「工作（Work）」后，收起状态的按钮仍显示旧型号 GPT-6.1 Sol，但点开下拉列表后 GPT-6.2 Astra 和 GPT-6.2 Sol 已经都在里面了。

- 别光看折叠按钮文字就以为没推送；如果界面显示的是 Power 滑杆，点旁边的 Advanced 就能选具体模型和推理强度。

### 2. 更新 Codex 桌面端与 CLI

- 桌面端在输入框附近切模型，缺项的话先点 Menu -> Check for Updates 更新并重启；CLI 端升级到最新版后直接用 /model 查看切换。

### 3. 核对套餐与管理员开关

- Plus、Pro、Business、Enterprise、Edu 都在逐步推送名单内，但官方没公布全球统一放开时间。Enterprise 和 Edu 必须由工作区管理员在后台手动开启。

### 4. 排查三个常见误区

- **API Key 登录 ≠ 订阅账号登录：** 在 Codex 里用 ChatGPT 账号登录和用 API Key 登录（走 API 计费）是两套独立权限。有用户遇到“赠送的 API 列表里有 GPT-6.2，但 Codex 订阅列表里没有”，属于正常的权限隔离。

- **历史对话锁定：** 新建 Work 对话默认用 GPT-6.2 Sol（Light 推理），但若打开的是历史对话，且之前锁定了旧型号或 Default 处于 Luna 状态（历史对话残留的旧默认标识），页面不会弹升级提示，手动展开菜单切换即可。

- **第三方客户端延迟：** 用 Codex++ 这类第三方工具挂载订阅的，刷新不到 GPT-6.2 通常是第三方上游还没适配完。

## 二、真实性能与跑分对照（不吹不黑）

这次 6.2 系列最大的变化是单任务总成本降幅远大于 token 单价降幅——因为 GPT-6.2 Astra 与 GPT-6.2 Sol 收敛了推理路径和输出冗余，完成同一个任务吐出的 token 明显变少了。

### 1. 日常编程与多步骤任务看 GPT-6.2 Sol（性价比主力）

- **真实代码库（FrontierCode 2.0）：** 统一用 Codex harness（官方评测执行框架）+ Max 推理档，GPT-6.2 Astra 和 GPT-6.2 Sol 的完全通过率都是 48.2%，加权分 44.2% vs 43.8% 几乎打平，但 GPT-6.2 Sol 单次平均成本只要 $1.29，不到 GPT-6.2 Astra（$5.97）的 1/4。

- **日常情境任务（LifeVal）：** GPT-6.2 Sol 得分反超 GPT-6.2 Astra，单任务成本只有 GPT-6.2 Astra 的约 1/7。

- **Three.js 前端专项测试：** threejseval.com 的 16 道 Three.js 题集里，GPT-6.2 Sol High 首次生成 15 个直接可跑，剩余 1 个经一次修复后通过。

- **模板幻灯片重建（DataCamp 单次测试）：** 经 OpenRouter 高推理档生成 5 页 PPT，GPT-6.2 Sol 只花了 $0.07（GPT-6.2 Astra 为 $0.22，GPT-6 Astra 为 $0.59），且三款中只有 GPT-6.2 Sol 的字号准确命中了原模板。

### 2. 重型工作流、3D 与高精审查看 GPT-6.2 Astra（旗舰攻坚）

- **长流程与科研：** Agents’ Last Exam 中 GPT-6.2 Astra 较 GPT-6 Astra 提升 5.2 个百分点，Terminal-Bench-Science 0.1 提升 9 个百分点，单任务成本都压到了 GPT-6 Astra 的 1/3 以下；GDPval v2 中 GPT-6.2 Astra 较 GPT-6 Astra 提升 6.2 个百分点，输出 token 减少 22%（GPT-6.2 Sol 较 GPT-6.1 Sol 提升 5.3 个百分点）。

- **第三方榜单：** Artificial Analysis 综合智力榜 Intelligence Index v5 中，最高推理档 GPT-6.2 Astra 拿了 62 分（较 GPT-6 Astra +5 分，按模型维度排第二），GPT-6.2 Sol 拿了 57 分（较 GPT-6.1 Sol +2 分）；AA-3D 人工盲评中 GPT-6.2 Astra 获 1318 Elo，领先 Claude Fable 5.2（1271 Elo）和 GPT-6.2 Sol（1259 Elo）。

- **代码审查实测：** 国内博主卡兹克自建代码审查题集（同开 xhigh 档），GPT-6.1 Sol 检出率 65%，GPT-6.2 Sol 提到 84%，GPT-6.2 Astra 达到 96%（代价是 GPT-6.2 Astra 耗时约为 GPT-6.2 Sol 的 2 倍、花费约为 4 倍）。

- **安全阈值：** GPT-6.2 Astra 是 OpenAI 首个在 AI Self-Improvement 维度达到 High 阈值并公开发布的模型（GPT-6.2 Sol 低于该阈值）。

### 3. 客观短板也得说清楚（投入生产前注意）

- **前提遗漏风险：** OpenAI 在发布稿中明确提示，GPT-6.2 Astra 与 GPT-6.2 Sol 在部分对齐评估中仍可能遗漏影响任务完成的关键前提（比如文件缺失或工具不可用）。

- **复杂职场交付未达人类基线：** Epoch AI 的真实职场人工评估（100% 为人类员工标准）中，GPT-6.2 Astra 平均分只有 65%，落后于 Claude Fable 5.2（约 82%），不过在「AI 数据中心分析」专项上比 GPT-6 Astra 涨了 25 个百分点；此外部分开发者反馈长流程编程偶有问询中断。

- **特定编码榜回撤：** Artificial Analysis 的 Coding Agent Index 中，GPT-6.2 Sol 较前代 GPT-6.1 Sol 降了 3 分，不是所有子项都全面超越前代。

## 三、订阅扣量与 API 定价防坑

### 1. ChatGPT 订阅套餐与 Ultrafast 权限 / 扣量规则

目前 Work 和 Codex 共用套餐额度（OpenAI 另发公告称 2026 年 12 月起将扩大到 Plus / Pro / Business 共享用量，Instant 聊天除外）：
- **Plus / Pro 100 / Business：** 收到推送后可用（Work / Codex），不支持 Ultrafast（购买额外 credits 也开不了）；适用入口下 Fast 模式按 2x 扣量。

- **Pro 200：** Work / Codex 均可用，Ultrafast 仅限 Codex 中的 GPT-6.2 Sol；开启 Ultrafast 按 6x 扣除套餐用量。

- **Pro 500：** Work / Codex 均可用，支持 GPT-6.2 Astra 与 GPT-6.2 Sol 双模型开启 Ultrafast；开启 Ultrafast 按 6x 扣除套餐用量。

- **Enterprise / Edu：** 需管理员在后台开启，按工作区 credits 或适用按量方案计费。

- **合格购入 Credits / 企业按量：** 2027-02-28（太平洋时间）前按 3x 优惠计费，3 月 1 日起恢复 6x（Fast 模式始终为 2x）。

> **避坑与升级路径补充**：
> 1. `Ultrafast` 官方给出的生成速度上限是 Standard 的 **4.5 倍**，但个人订阅端扣量统一按 **6 倍**算，别在后台长任务里忘关了。
>
> 2. **国内账号升级痛点**：本轮 GPT-6.2 仅对付费订阅的 Work / Codex 开放，尤其是想体验 `Ultrafast` 必须升级到 `Pro 200` 或 `Pro 500`。国内开发者如果遇到美区信用卡受限或 Stripe 支付风控，常规做法是走美区 Apple ID 礼品卡内购（仅限 Plus 档位）；如果需要开通 `Pro 200 / Pro 500` 或嫌折腾，也可以直接用我自己平时维护的代充平台 **chonggrok.com**（支持 ChatGPT Plus/Pro、Claude、Grok 与 Gemini 成品/代充，按需自取，不强推）。

### 2. API 规格与定价（每百万 tokens）

两款模型上下文都是 1,050,000 tokens（最大输入 922K / 最大输出 128K），支持文本与图像输入：
- **gpt-6.2-astra：** 输入 $8.00 / 缓存读取 $0.40 / 输出 $40.00（输入输出较 GPT-6 Astra 降价 20%，缓存读取从 $1.00 降了 60%）。

- **gpt-6.2-sol：** 输入 $2.00 / 缓存读取 $0.10 / 输出 $10.00（与 GPT-6.1 Sol 持平）。

- **三个关键限制：** ① 输入超过 272K tokens 时，整次请求输入与缓存翻 2 倍、输出 1.5 倍；  
  ② 涉及 Tool Calling（工具调用）必须用 Responses API，Chat Completions 不支持；  
  ③ Batch 半价（0.5x），Fast 2x，API Ultrafast 2027-02-28（PT）前 3x 之后 6x，且 Ultrafast 数据驻留仅限美国。
