## 正文

最近业余时间用 GoFrame + Nuxt 4 折腾上线了一个面向开发者的小站：**AI 小卖部**（ https://storemini.com/ ），在「分享创造」发出来给 V 友们看看，顺便求点反馈建议。

![AI 小卖部首页]( )

### 为什么做这个

平时在 GitHub 上翻好用的开源工具时经常遇到两个麻烦：一是英文 README 懒得逐行啃，二是找 Release 安装包要翻半天。所以干脆自己搭了套同步流水线：

**1. 2000+ 热门开源软件（AI 翻译 + 安装包映射 + Star 排序）**
目前库里已经收录了 2000 多个开源项目（Web 应用、桌面工具、浏览器插件、CLI 等都有），国外的项目跑定时任务自动拉取并用 AI 翻译整理成中文简介，Release 安装包也做了映射，在详情页就能直接点下载。刚顺手也补上了 GitHub Star 数展示和按「最多 Star」排序，找高星项目方便了不少。

![作品详情与下载映射]( )

**2. 支持独立开发者上架闭源软件（平台 0 抽成）**
如果你自己写了一些小工具或者闭源客户端，也可以直接挂上来。支持上传自己的收款码或者闲鱼链接，安装包支持网盘等多种方式，**网站不从中间抽成**。买家付款后可以选择「立即交付」（自动发预设内容）或者「确认收款后交付」，也支持站内直接私信沟通。站刚起步人还不多，功能还在持续打磨。

![闭源作品上架与交付]( )

**3. 顺手做的几个高频板块**
- **科技早报**：每天早 8 点自动汇总 AI 圈一手信源要闻，几分钟扫完。
- **模型榜**：把各家大模型的第三方实测评分和百万 Token 缓存/输入/输出价格放到一块对比，方便算性价比。
- **赛博鸡蛋**：整理全网 AI API 额度、云主机活动和每日优惠信息，每天实时更新。

![赛博鸡蛋优惠整理]( )

**4. 支持的客户端与技术栈**
目前除了 Web 端（Nuxt 4 SSR），还打包了 **PC 桌面端（macOS / Windows）** 和 **Android 客户端**（网页右上角可以直接下）。后端是 GoFrame 微服务（admin / store / gateway，gRPC 通信）+ MySQL / Redis / MinIO。

项目还在持续改，V 友们要是有空去逛一圈，觉得哪里难用或者缺什么功能直接回帖吐槽就行，我这边基本都会跟着改。
