## 正文

最近自己在做浏览器扩展的独立开发，顺手翻了翻过去两年（2025–2026）V2EX「分享创造」和「Chrome」节点下大家发布的扩展作品。

整体看下来很有意思：早期大家多是在做“改个网页样式、去个广告”的小脚本；到了 2025 下半年至 2026 年，随着 Manifest V3 全面落地以及本地 AI Agent（Claude Code、Codex、MCP 等）的爆发，独立开发者的浏览器扩展开始明显往**“AI Agent 浏览器控制”**和**“垂直场景工作流提效”**集中。

我花了点时间把近两年站内有代表性、且仍在维护的 20+ 款独立开发扩展按赛道整理了一份清单，方便大家交流和参考：

### 1. AI Agent 浏览器控制与自动化（2026 年最热新赛道）
随着本地 CLI Agent 的普及，今年下半年集中涌现了一批让 Agent 直接复用日常 Chrome 登录态的扩展：
* **Xtaff Browser**：开放 MCP 接口的浏览器操作插件，支持网站 Playbook 录制与会话暂存，让 Agent 复用日常 Chrome 登录态。
* **BeatBrowser**：MIT 开源浏览器控制插件 + 本地 Node 桥接，支持 Codex、Claude Code、Cursor 共用已登录的 Chrome，独立窗口运行并支持人工随时接管。
* **WebCLI**：解包不到 300 KB 的极简执行端，提供 25 个基础工具（读写、点击、截图等），将浏览器变成外部 AI Agent 的执行终端。

### 2. 社交媒体与内容运营工具
* **波波小红书助手（小红书原图下载扩展）**：我自己最近开源并上架的一款轻量工具，支持无水印小红书原图、LivePhoto 与高清视频批量提取下载，纯净无广告，支持 Chrome 与 Edge。Chrome 商店：https://chromewebstore.google.com/detail/hpdomiahmefpopmpgcihooocjolkggpl
* **波波抖音内容运营助手**：针对抖音网页版的自动化运营与获客工具，支持推荐流模拟挂机、多关键词搜索筛选、评论区截流及 AI 神评。Chrome 商店：https://chromewebstore.google.com/detail/clneekebmllhkokbpggpaaiddhcbiknh ｜ Edge 商店：https://microsoftedge.microsoft.com/addons/detail/jlncifnebnelgnhpfjaiggnolkldcngc
* **PostKeeper**：纯本地运行的 X (Twitter) 帖子与书签收藏离线备份扩展，防原帖删除丢失。
* **全能围脖**：整合微博网页版美化、关键词屏蔽、日夜间配色与媒体下载的一站式扩展。
* **Media Sniffer Vibe**：开源 m3u8 流媒体视频嗅探器，对标 CoCoCut，方便本地下载观看。

### 3. 标签页、书签与浏览器界面重构
* **TabTerrace**：将多个标签页合并到单页“宫格工作台”（最多 9 格、30+ 布局），支持独立缩放与无刷新拖拽排序。
* **VertiTab**：主打侧边栏树状标签页与标签页聚焦（Tab Focus）的效率工具。
* **WeDock**：历时 3 个月开发的桌面级 Dock 栏与浏览器快捷启动增强扩展。
* **UTags 书签管理器**：支持为任意网页和链接添加自定义标签的书签与内容管理扩展。
* **AI 书签管理插件**：集成 AI 自动为书签生成标签，提供书签使用数据统计与智能搜索。

### 4. AI 摘要、翻译与文档转换
* **一览**：主打简洁阅读体验的 AI 网页内容摘要扩展。
* **MD to Word Professional**：纯前端本地运行的 Markdown 专业排版转 Word 文档工具。
* **Chrome 离线翻译插件**：基于 Chrome 内置 Translator 与 LanguageDetector API 的纯本地离线网页翻译工具，兼顾隐私与速度。
* **CopyRef**：使用 WXT + TailwindCSS 开发的开源一键复制当前标签页为 Markdown 引用链接工具。

### 5. 开发者调试、网络代理与社区辅助
* **V2EX 评论上下文**：开源无侵入式阅读辅助，自动识别 `#楼层` 或 `@用户` 并在当前楼层上方展示原回复。
* **GitHub 中文化**：本地化实现 GitHub 界面汉化、下载加速源切换与搜索结果规则净化。
* **Proxi 极简代理切换**：替代臃肿代理插件的极简一键代理切换工具。
* **Modify HTTP Headers**：因同类老牌插件被下架，开发者重新编写的纯净无广告 HTTP 请求头修改调试扩展。
* **Multi-Account Switcher**：支持保存并一键切换网站不同账号 Cookie（含 httpOnly）与 LocalStorage 数据的多账号管理扩展。
* **Bark Sender**：适配 Manifest V3 的开源网页右键推送文本/链接至 iPhone（Bark）工具。
* **Docker Image Downloader**：通过浏览器直接拉取 DockerHub / ghcr.io 容器镜像 tar 包用于离线加载。

### 几点个人观察（独立开发者视角）
1. **技术栈高度趋同**：现代扩展开发基本已经转向 `WXT / Plasmo + React/Vue + TailwindCSS`，配合 Chrome 侧边栏（Side Panel）原生 API，包体积普遍控制在几百 KB 以内，开发体验比早期原生写 Manifest 顺畅太多。
2. **商业模式务实**：由于 AI API 存在调用成本，独立开发者出海或国内变现普遍避开了重运营的订阅制，转而采用 **BYOK（自带 Key）** 或 **Cloudflare Workers + 一次性小额买断（$2.99～$9.99 / ¥19.9）**，把边缘算力成本压到最低。
3. **冷启动普遍较难**：很多功能很扎实的作品在商店里长期处于几十个用户、零评分的状态，酒香也怕巷子深，国内用户还面临访问 Chrome 商店不便的问题。

为了方便国内用户免梯子直接检索、下载官方原版 CRX 安装包以及做安全权限体检，也为了给咱们独立开发者的作品多一个曝光和外链收录渠道，我把上面这些优秀扩展和自己的作品一起整理收录到了我维护的 **[CRX8.com](https://crx8.com)** 扩展聚合导航站里。
