## 正文

美企科技公司，做创新健身应用开发，目前招聘一名兼职 React Native 移动开发工程师 Mobile Engineer ，公司直招！业务在美国，产研团队在中国，现在业务量增加 App 开发团队需要量增加一名兼职，工作方式为远程办公。

任职要求，划重点！

- 精通 React Native 与 Expo：prebuild 、config plugin 、EAS 构建； 5 年以上移动端经验，其中 3 年以上 RN 生产经验，有独立上架并持续维护的 App 。
- 同时精通 iOS 与 Android 原生：能独立用 Swift / Kotlin 写改原生模块，能解决 Xcode 、CocoaPods 、Gradle 、签名与商店审核问题。
- 精通 TypeScript：有 20 万行级代码库的维护经验。
- 精通新架构与渲染性能：Fabric / TurboModules 、Reanimated 4 、FlashList 、Gesture Handler ，能独立定位卡顿与重渲染。
- 有离线优先经验：WatermelonDB / SQLite / ORM 、数据迁移、增量同步与冲突处理。
- 熟悉状态与数据流：zustand 、RxJS 、SWR ，能处理跨页面状态一致性与订阅泄漏。
- 能独立负责发版：双端签名、TestFlight / Play 内测、审核、灰度、OTA 热更新与回滚。
- 有线上质量意识：会用日志定位问题；修 bug 先写回归测试。
- 有原生平台能力经验（至少两项）：HealthKit / Health Connect 、Live Activity / Widget 、推送、ATT 、动态图标。
- 英文技术文档阅读无障碍，有产品判断力，能对不合理需求给出替代方案；接受小团队、端到端负责。
- AI 使用有边界：能借助 AI 辅助快速实现功能、定位 bug ，但必须能脱离 AI 独立完成同样的事，并对 AI 产出的代码负责。

岗位开放中，薪资面议。少有的好机会，大家抓紧投递！！
