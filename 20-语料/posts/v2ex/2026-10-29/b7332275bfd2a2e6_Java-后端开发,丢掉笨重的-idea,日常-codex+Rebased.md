## 正文

后端 Java 开发，或者说现在工作也是全栈了，现在是 codex 和 cc 都用，主力还是 codex ，公司电脑 16G 内存，以前还是会用 idea 看看核心改动代码，然后确认没问题再提交，这个 git 这块 idea 还是用习惯了不错的，除此之外 idea 再无用处，idea 的缺点就不用说了占用大量内存，
直到后面发现 jb 家的 git 独立产品 Rebased 和 idea 一样的独立的 git 模块，小乌龟，sourceTree 用下来都差点意思，推荐给大家： https://github.com/DetachHead/rebased ，而且一直在更新，Java 开发习惯了 idea 的可以试试
