# Base 厦门，招后端工程师主 Java 。薪资 12-16K。有没有比较 Geek、动手能力强的小伙子。

## 正文

任职要求：
1.本科及以上学历，计算机相关专业，3-5 年及以上 Java 开发经验。
2.扎实的 Java 基础，熟悉集合、多线程、JVM 、IO 、网络编程等核心知识。
3.熟悉主流 Java 开发框架，如 Spring 、Spring Boot 、Spring Cloud 等，有实际项目经验。
4.熟悉常用中间件及技术组件，如 MySQL 、Redis 、MQ （ Kafka/RabbitMQ ）、Nginx 等。
5.熟悉 RESTful API 设计规范，具备良好的数据库设计能力和 SQL 优化能力。
6.有分布式系统、微服务架构设计及开发经验者优先。
7.有 App 、小程序、Web 端相关业务后端支持经验者优先。
8.有 ComfyUI 、AIGC 开源项目经验、海外项目经验，或具备国际化、多语言、多时区业务支持经验者优先。
9.英语良好加分项。
10.具备良好的责任心、沟通能力和团队协作精神，能够独立分析和解决问题。
