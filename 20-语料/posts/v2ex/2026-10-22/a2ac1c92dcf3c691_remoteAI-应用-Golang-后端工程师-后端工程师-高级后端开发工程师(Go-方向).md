主力语言：Golang 为主（精通）； PHP 能读能改（能维护存量业务、参与迁移）。

AI 开发（核心）：有大模型（ LLM ）应用落地经验，包括接入 OpenAI / Claude 等大模型 API 、
Prompt 工程、RAG （向量检索问答）、Function Calling / Agent 编排、流式输出（ SSE ）。
能把模型能力工程化成稳定、可控成本的线上服务。

框架能力：熟悉 Gin / Go-Zero / Kratos 等 Go 框架，理解框架设计原理；
PHP 侧了解 Laravel / ThinkPHP 。

数据库：精通 MySQL （表设计、索引优化、SQL 调优）；熟练 Redis （缓存 / 分布式锁 / 限流）；
熟悉 Elasticsearch （索引设计、检索调优，向量检索加分）。

容器与编排：熟练 Docker ；有生产级 Kubernetes （ k8s ）使用经验；了解 k3s （轻量 / 边缘集群）加分。

架构能力：熟悉微服务架构、分布式系统设计，有高并发项目实战经验。

工具链：熟练使用 Git 、Linux 环境，熟悉 CI/CD 流程。

质量意识：具备良好的代码规范意识，熟悉单元测试、接口测试。

沟通能力：远程办公环境下具备良好的文档协作与异步沟通能力。

 [加分项] 
- 有向量数据库经验（ Milvus / Qdrant / pgvector / ES kNN ）
- 熟悉 LLMOps / 模型推理服务部署（ vLLM 、Ollama 、Triton ）
- 有消息队列 / 大数据管道经验（ Kafka 等）
- 有开源贡献或技术博客

# 高级后端开发工程师（ Go 方向）
20K - 30K
工作经验：5 年以上

岗位级别：高级 / 资深

## 岗位职责

1. 负责公司核心业务系统的后端架构设计、开发及持续优化，保障系统的高性能、高可用和可扩展性。
2. 负责高并发、高流量业务场景下的技术方案设计，解决系统性能瓶颈、稳定性及数据一致性问题。
3. 参与微服务架构设计与治理，推动服务拆分、接口规范、服务降级、限流熔断等技术方案落地。
4. 负责数据库架构设计与性能优化，包括 MySQL 、Redis 等存储系统的合理使用及优化。
5. 参与核心业务需求分析、技术方案评审、开发排期及代码 Review ，确保项目交付质量。
6. 负责线上复杂问题的排查与解决，持续优化系统监控、日志、链路追踪及故障应急机制。
7. 熟练运用 AI 编程工具提升研发效率，并能够独立评估、验证及优化 AI 生成的代码。
8. 持续关注新技术发展，推动团队工程规范、研发效率及系统架构优化。

## 任职要求

1. 大专及以上学历，计算机相关专业，5 年以上后端开发经验，具备独立负责中大型项目的能力。
2. **精通 Golang**，熟悉 Goroutine 、Channel 、Context 、GC 、内存管理及并发编程机制，具备扎实的工程实践能力。
3. 熟悉 MySQL 、Redis ，具备数据库索引优化、SQL 性能调优、缓存设计及高并发数据处理经验。
4. 熟悉微服务架构，掌握 gRPC 、HTTP 、消息队列等常用技术，理解分布式系统设计原则。
5. 具备高并发系统设计经验，熟悉分布式锁、幂等控制、限流、熔断、降级、分布式事务等解决方案。
6. 熟悉 Linux 、Docker 、Kubernetes 等技术，具备一定的容器化部署及线上故障排查能力。
7. 具备良好的系统架构设计能力，能够独立完成技术选型、方案设计及复杂业务模块开发。
8. 熟悉 Git 、CI/CD 等研发工具及流程，具备良好的代码规范意识和质量意识。
9. 熟练使用 Claude Code 、Cursor 、Codex 等 AI 编程工具，能够利用 AI 提升开发效率，同时具备独立判断代码正确性和质量的能力。
10. 具备良好的沟通协作能力、责任心及主动解决问题的意识，能够推动复杂问题闭环。

## 加分项

1. 有高流量互联网产品、直播、音视频、即时通讯、支付交易等业务开发经验。
2. 有大型分布式系统架构设计、性能优化或高可用建设经验。
3. 熟悉 Kafka 、RabbitMQ 、Elasticsearch 、ClickHouse 等中间件。
4. 了解 LLM 、AI Agent 、RAG 、LangChain 、LangGraph 等 AI 应用技术，有相关项目落地经验。
5. 具备从 0 到 1 的项目架构设计及落地经验。
6. 有技术团队管理、技术方案评审或带领团队解决复杂问题的经验。

## 我们希望你

- 不只是完成需求开发，更能够主动思考系统设计和长期可维护性。
- 遇到复杂问题能够独立分析、定位并推动解决，而不是依赖他人提供方案。
- 善于使用 AI 工具，但不盲目依赖 AI ，对代码质量、系统稳定性和交付结果负责。
- 具备较强的业务理解能力，能够在保证质量的前提下高效交付。
- 有责任心、执行力和团队协作意识，能够适应快速迭代的研发环境。
