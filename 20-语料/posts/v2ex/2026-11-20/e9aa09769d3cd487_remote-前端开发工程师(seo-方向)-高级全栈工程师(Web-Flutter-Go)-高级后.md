##前端开发工程师（seo 方向）
20-25K
岗位职责
    负责站群多主题模板体系：服务端渲染模板的组件化与皮肤化，让同一套结构长出多张不同的脸。
    对 Core Web Vitals（LCP / CLS / INP）负责：首屏 CSS 拆包、资源哈希与长缓存、图片自适应与懒加载。
    HTML 语义化与页面结构：标题层级（单一 H1、H2–H6 不跳级）、article / section / nav / main 等语义标签用对、图片 alt、链接可抓取，让爬虫能读懂页面在讲什么。
    落地结构化数据（JSON-LD）、canonical / hreflang / og、分页与内链结构，直接影响收录与排名。
    支撑多语言站扩张（繁体及多国语言）：多语言 URL 结构与 hreflang、语言切换、界面文案全量外置、不同语种文案长度差异的布局适配。
    运营后台迭代（Vue3 + Vite + TypeScript + Element Plus）：内容管理、批量操作、权限菜单、大列表性能。
    短剧 App 客户端迭代（Flutter 安卓 + Web）：播放器、追剧、会员支付、性能与包体优化。
任职要求
    2 年以上前端开发经验，至少一个完整项目从 0 到上线的主力经历，具有远程工作经验。
    不限框架（Vue / React / Svelte / Flutter / 原生 SSR 模板均可），但需具备「SEO 友好渲染」或「App 端开发」其中一项硬能力。
    熟练使用 AI 编码工具（硬性要求），能用 Agent 批量生产模板与组件并保证质量一致。
    能 1:1 像素级还原 Figma 设计稿，这是我们的硬性交付标准。
    严格遵守多语言（i18n）架构：界面文案一律走词条不写死，布局能容纳不同语种的长度差异——这是我们的团队红线。
    懂 SEO 站的前端优化点：HTML 语义化与标题层级、图片 alt 与懒加载对收录的影响、内链与锚文本、rel 属性（nofollow / sponsored / ugc）、noindex 的正确用法。我们靠搜索引擎流量吃饭，模板写法直接决定收录。
    理解浏览器渲染、缓存与性能指标，能自己定位性能问题。
加分项
    有 SEO 站、内容站、站群前端经验，做过收录与排名相关优化并有数据结果。
    有服务端渲染（任意技术栈）的深度实践。
    有 Flutter 或音视频播放（HLS、加密流、自定义播放器）经验。
    有多主题、多品牌换肤体系的设计与实现经验。
    做过多语言站或国际化项目，处理过 hreflang、繁简差异、RTL 等问题。
    熟悉 Node 工程化，能自己写构建脚本与自动化工具。

##高级全栈工程师（Web / Flutter / Go）

15-28K
一、岗位职责
系统架构设计： 负责公司内容分发平台及相关产品的整体技术架构设计，涵盖前端、后端及跨平台应用，保障系统的高可用、高并发、可扩展性及稳定性。
全栈开发交付： 负责公司 Web 端、Flutter 跨平台应用及后端服务的核心功能开发、维护与迭代，能够独立完成从前端页面、业务逻辑、API 接口到后端服务的完整开发交付。
后端服务建设： 负责基于 Golang 的后端服务开发，制定 RESTful API 规范，设计和优化分布式服务、数据库及缓存架构，解决高并发场景下的系统性能瓶颈。
前端技术建设： 负责基于 React、TypeScript 等技术栈的前端架构设计与开发，持续优化前端工程化体系、页面加载速度、SEO 及用户体验。
系统性能与稳定性： 建立系统监控及性能分析机制，持续优化前后端性能，解决高流量场景下的资源消耗、响应延迟、并发处理等技术问题。
工程化与部署： 负责系统容器化改造及 CI/CD 持续集成与交付体系建设，熟悉 Docker、Kubernetes 等技术，提升研发效率和系统部署稳定性。
技术创新与规范： 持续关注前后端及跨平台技术发展趋势，推动技术架构优化、代码规范、模块化建设及研发效率提升，合理应用 AI 编程工具改善研发效能。

二、岗位要求
本科及以上学历，计算机相关专业，5 年以上全栈开发经验，具备扎实的计算机基础、系统设计能力和全栈开发经验。
前端技术： 熟练掌握 React、TypeScript、JavaScript、HTML5、CSS3 等前端技术，熟悉 Node.js，熟练使用 Webpack、Vite 等工程化工具，有大型 Web 系统架构设计、开发或重构经验。
跨平台开发： 熟悉 Flutter 开发框架，具备跨平台应用开发及性能优化经验，能够独立完成相关业务功能开发。
后端技术： 熟练掌握 Golang，熟悉 GoZero、Gin 等主流开发框架，具备复杂业务系统及 RESTful API 设计开发能力，精通 Go 高并发编程及相关底层原理。
分布式架构： 熟悉分布式系统设计，具备高可用、高并发、负载均衡、服务治理等实际项目经验，能够独立进行系统架构设计及技术难点攻克。
数据库与中间件： 熟悉 MySQL、Redis、Kafka、RabbitMQ、gRPC 等常见数据库及中间件，理解其基本原理，具备数据库设计、缓存优化及消息队列应用经验。
性能优化： 具备高流量、高并发场景下的系统性能优化经验，熟悉内存管理、性能调优、分布式缓存、CDN 及前端加载优化等技术。
工程化与运维： 熟悉 Docker、Kubernetes 等容器化技术及 CI/CD 流程，具备主流云平台应用和生产环境部署、监控及问题排查经验。
架构与质量意识： 具备系统模块化、代码重构、跨浏览器兼容、系统扩展性及可维护性优化经验，能够编写技术方案、架构设计及接口文档。
综合能力： 具备较强的技术学习能力、执行力和问题解决能力，能够独立承担复杂技术任务，并具备良好的跨团队协作能力。

三、加分项
有内容分发平台、广告平台、流量平台、视频或资讯类产品的实际开发经验。
有大型高并发、高流量 Web 系统从 0 到 1 架构设计及落地经验。
有 AI 辅助编程、AI Agent 及研发自动化工具的实际应用经验。
有优秀的开源社区项目贡献或大型技术项目主导经验。

##高级后端开发工程师

18k-25k

一、岗位职责​
1. 负责后端项目（API 服务、内容站群等）的设计、开发、迭代及维护工作。​
2. 参与业务需求评审，梳理业务对象、角色权限及功能验收标准。​
3. 负责技术方案、接口设计、数据库设计及开发计划的制定。​
4. 独立完成用户、权限、内容、订单支付、运营配置等核心业务模块的开发。​
5. 负责 Redis 缓存、计数器缓冲及高并发场景下的性能优化，保障系统稳定性。​
6. 负责事务处理、接口幂等、定时任务、异常补偿及数据对账等工作。​
7. 参与前后端联调，完成接口对接、问题排查及技术支持。​
8. 负责代码评审、系统性能优化、日志监控及线上问题排查。​
9. 熟练使用 AI Coding 工具提升开发效率，并对生成代码进行审核，保障代码质量及安全性。​
10. 沉淀技术规范、接口文档及开发文档，持续提升团队研发和交付效率。​
二、任职要求​
1. 具备 3 年以上 PHP 后端开发经验，能够独立负责完整项目或核心业务模块。​
2. 熟悉 PHP 开发框架及自定义生命周期管理，熟悉 Eloquent ORM 的独立使用。​
3. 具备 CMS 二次开发经验，理解插件机制、静态化缓存及站群优化方案。​
4. 熟悉 MySQL 数据库，具备主从读写分离、大表在线 DDL 及 SQL 性能优化经验。​
5. 熟悉 Redis 应用及常见数据结构，了解 Redis Cluster、Hash Tag、计数器缓冲及批量落库模式。​
6. 具备搜索引擎接入经验，熟悉 OpenSearch 或 Elasticsearch，能够设计索引同步及异常降级方案。​
7. 熟悉 RESTful API 设计规范，掌握接口鉴权、参数校验、错误码及接口版本管理。​
8. 深入理解事务、幂等、并发控制、缓存一致性、慢 SQL 治理、限流及异常补偿机制。​
9. 有用户管理、权限管理、内容管理、订单支付、运营配置等业务模块开发经验者优先。​
10. 具备前后端联调能力，能够阅读和编写前端代码，独立完成接口联调及问题定位。​
11. 熟悉 Docker 开发环境搭建、配置及调试。​
12. 熟练使用 AI Coding 工具辅助开发，具备独立判断业务逻辑、代码质量及安全风险的能力。​
