岗位职责
  - 参与企业内部系统的后端开发与迭代
  - 负责业务模块的接口实现，包括物料管理、工单流转、审批流等
  - 与产品协作，实现需求上线落地
  - 排查并修复线上问题

  ---
  任职要求
  - ERP / MES / OA / 工作流相关系统开发经验
  - 1-2 年 Java 后端开发经验
  - 熟悉 Spring Boot 等主流框架，了解 RESTful API 设计规范
  - 掌握主流数据库，具备 SQL 与非 SQL 数据库的基本使用能力
  - 熟悉 Git ，有多人协作开发经验
  - 对 AI 有真实理解与实践，具备 Vibe Coding 能力，能熟练驾驭 Claude 、Codex 等 AI 编程工具，真正将 AI 融入开发流程以提升效率，而非停留在表层使用
  - 具备飞书或企业微信 SDK 对接能力，如机器人消息推送、审批回调、应用事件订阅、通讯录同步等
  - 思维清晰，善于沟通，能准确理解业务需求并转化为技术方案

  ---
  加分项
  - 了解审批流、状态机等业务设计模式
  - 有 Vue 2/3 基础，能独立完成简单业务页面
  - 了解 Redis 、消息队列等中间件基本用法
  - 有 Docker 基础，能看懂部署配置
