## 正文

Hello, my name is Berend Graham. My cofounder Shiv Oberai and I have been working on Limma for a year now with the goal of building a proactive solution to the reliability issues that plague practical AI and agentic use in companies with RAG.Limma is a single MCP that exists for the sole purpose of ensuring that the right information is retrieved with every query and no information is skipped and or missed. This means total precision and recall. We've found that this approach leads to the lowest rate of hallucination vs. solely targeting agent action verification which has made tremendous strides in capability.We do this by building a map and structuring all data-points within unstructured data as well as federating structured data for addressability so that agents don't need to search through chunks directly and instead only get the right information . We wanted this to be extremely easy to use so that anyone can set it up and try it within minutes so that the precision issues (especially with large quantities of data) that LLMs struggle with can finally be remedied. We use self-hosted models (primarily Qwen models as of current) so that the system can be deployed on one's own server if needed, and also to optimize for speed.We have a free monthly version on our website if anyone would like to try it out and provide feedback!
