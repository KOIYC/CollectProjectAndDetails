Hi, I built an hancrafted HTML-first JavaScript framework called Places.js that outperforms React, Svelte, Lit, and Vue.- Components are created with HTML-first templating, which allows for flexibility in how HTML is generated.- No build step. Places.js can be downloaded from a CDN and directly added to a project.- JavaScript enhanced web components that can be dynamically rendered with API endpoint data.- Rendering agnostic stores that can be integrated with other frameworks.To test Places.js,download the latest version from JSDelivr:https://cdn.jsdelivr.net/gh/createthirdplaces/places-js@0.1....Here is a reference guide: https://createthirdplaces.org/tech/placesjs/reference/presen...Other links:Benchmarks for Places.js and other frameworks:https://krausest.github.io/js-framework-benchmark/2026/chrom...Event listing site I made with Places.js: https://dmvboardgames.com/
