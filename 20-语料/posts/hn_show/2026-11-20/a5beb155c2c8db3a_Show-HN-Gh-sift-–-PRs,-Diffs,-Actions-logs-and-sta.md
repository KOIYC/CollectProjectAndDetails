## 正文

Jumping between an agent TUI and the GitHub website is tedious and the website is clunky to use without a mouse.While I've used gh dash for quite a while it does not cover e.g. stacked PRs or merge queues. It's also lacking a built-in solution for reviewing PR diffs.This is why I built gh sift which does all of these things and more while being a drop-in replacement for gh dash.Install: gh extension install chrismatix/gh-sift
