How it works
Three steps. About a minute.
1 Create an agent
 Give it a name and say who it is in plain words. Then pick its brain: Mingle lists the harnesses on this computer and their models, and can install and sign in to one that's missing.
2 Connect a chat app
 Scan a code with your phone for WeChat, WeCom, Feishu, DingTalk and QQ. Paste a token for Slack, Discord and Telegram. Sign in the agent's own GitHub account with a code. On a Mac, iMessage uses your chat with yourself. The console checks each step as you go.
3 Talk to it
 Message it directly, or @ it in a group. It reacts as soon as it starts, and the reply fills in while it works. You're its owner: the one who scanned the code, or who sends it the 6-digit code the console shows.

Brains
Bring the brain you already pay for.
Mingle drives the coding agent you have already installed and signed in to. Pick any of them per agent, and switch any time.
Tested end to end with Claude Code, Codex, OpenCode and Kimi Code.
Your subscription or key Mingle never calls a model itself. The harness you signed in to does.
 A model per agent Change it any time. The next message uses it.
 Quota at a glance Settings shows how much of each harness's quota is left.
 Installed for you A missing harness installs, signs in and updates from the app.
No server
There is no Mingle server.
 So nothing of yours is on one.
Mingle isn't a service you sign up for. It's a program on your computer that links your chat apps to your own agent directly. No account, no cloud relay, no telemetry: no database of your chats for anyone to break into, and no one at Mingle who could read them.

Local only
 The console listens on 127.0.0.1 and nowhere else. The agent's memory and files stay in its own folder on your disk.
Strangers ask first
 On apps anyone can find, like Telegram, Discord and QQ, a new person or group waits for your OK before the agent works for them.
Credentials in the system's store
 Bot tokens live in the macOS Keychain, Windows DPAPI or the Linux Secret Service. Never in the database, the logs or an API response.
Official bot channels first
 Chat apps connect through their official bot APIs. iMessage has none, so it runs on your own Apple ID on your Mac, never through a cloud bridge.
Your messages still pass through the chat app and your model provider. That part is theirs, not ours.
Handoff
Catch it up from any conversation.
Been working on something in Claude Code or Codex? Copy one prompt into that conversation and it writes Alex a handoff: the progress, the decisions, your preferences. Alex files it into its memory and tasks without stopping what it's doing.
Terminal
Also a CLI. Agents use it too.
One command installs the desktop app. From source, the same mingle command runs everything from a terminal, and it's how agents talk back: reply, send, read and search the chat, keep an address book, tasks and reminders.
