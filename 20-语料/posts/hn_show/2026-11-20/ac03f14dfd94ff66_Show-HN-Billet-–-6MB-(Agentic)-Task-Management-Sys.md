## 正文

Ever since AI has come, I've got worse at managing project tasks / goals. When you develop so fast now, things start lacking behind. For that reason I looked into creating a good set of skills I can use in any agent that support skills.The result is billet-skills which you can find at https://github.com/Skytrias/billet-skillsTasks are Markdown files with JSON frontmatter that live in docs/tasks/: ---
 { "id": 7, "title": "Add dark mode", "status": "ready", ... }
 ---
 ## Outcome
 The app follows the system's light or dark setting.

This allows me to create a bunch of tasks upfront and work on things more easily or in parallel.Billet comes in two parts:1. billet-skills, the skills: https://github.com/Skytrias/billet-skills2. Billet, the viewer https://mktwsk.xyz/billetBillet has a few ways of looking at the tasks in your project:- List Mode- Kanban Mode- Plan ModeMultiple Projects can be seen in the Home Dashboard and also a simple Timeline.You can change the skills to whatever you like as long as it conforms to the format.Other than that thats pretty much it. I've also got easy copy&paste support so it becomes easier saying "work on X and Y".Billet is free - Give it a try and have fun! Feedback is welcome :)Billet itself is closed-source though - as I have commercial projects that use the same UI core.---For those interested in the tech:- Software Rendered UI, using Blend2D- Custom immediate mode UI- Custom platform layer- Made in Odin
