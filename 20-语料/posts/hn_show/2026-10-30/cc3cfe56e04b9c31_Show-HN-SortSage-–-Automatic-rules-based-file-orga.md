Common questions about SortSage
 What can I organize with SortSage? Use rules to organize local files by name, extension, type, size or age. Combine conditions, preview actions and choose how collisions are handled. Content Contains searches plain text, not text inside PDFs, Word documents or images.
 Does SortSage move or copy files? Choose Move or Copy in your rules. The five starter rules keep originals by copying by default. Pause watching and use Dry Run before enabling new rules.
 Can SortSage undo every operation? No. Activity History supports undo for supported operations, most recent first, and persists across restarts. Permanent deletion and external script/application effects cannot be undone. Undo stops if the original location is occupied or destination size or modification time changed. Recycle and overwrite backups share 256 MiB; clearing history discards them. Keep a separate backup of important files.
 Does the AI template mean SortSage uses AI? No. SortSage runs local rules and has no built-in AI connection. You can edit JSON yourself or give the downloadable template to an external AI of your choice, then import and review its output. Anything you choose to share with that external service is separate from SortSage.
 What does Dry Run show? A snapshot of up to 1,000 predicted actions without changing files. Pause watching while reviewing because live monitoring can resume after preview generation. Scripts, collision-prompt answers and later file changes can affect actual results.
 Can I run SortSage on startup? Yes. Enable launch at Windows sign-in to start in the background. Closing the window keeps it in the system tray; choose Quit to exit.
 What happens if a file with the same name already exists? Choose SmartRename, Rename, Overwrite, Skip or Ask. SmartRename skips identical colliding contents and retains the source; otherwise it keeps both with a numbered name. Overwrite requires space to preserve the existing destination in undo storage.
 Does SortSage work offline? Yes. Files are processed on your computer. After website activation, no recurring internet check is required.
