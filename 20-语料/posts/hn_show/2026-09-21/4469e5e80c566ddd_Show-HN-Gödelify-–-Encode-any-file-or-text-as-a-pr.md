godelify encodes any file as a prime number using
 Gödel numbering .
 The file is compressed, treated as a large integer, and a small suffix is appended
 until the result is prime. Strip the suffix, decompress, and you recover the original file exactly.
Inspired by Phil Carmody, who in 2001 encoded the banned DeCSS DVD-decryption program as a
 1401-digit prime. Possessing a number cannot be illegal.
