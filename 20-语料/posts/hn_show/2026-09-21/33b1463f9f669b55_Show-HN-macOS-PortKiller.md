# macOS PortKiller

> The fastest way to find and kill processes locking up your ports on macOS.

macOS
Swift
License

PortKiller is a lightweight, menu-bar utility designed for developers who are tired of typing `lsof -i :8080` and `kill -9 PID`.

## Features

- **Beautiful Native UI**: SwiftUI-powered, glassmorphic interface that looks stunning on macOS.
- **Smart Filtering**: Instantly search by port number, process name, PID, or full command path.
- **1-Click Kill**: Prominent hover states make terminating hanging Node, Python, or Ruby servers effortless.
- **Zero Configuration**: Pure Swift performance.

## Installation

Building PortKiller from source is easy.

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/PortKiller.git
   cd PortKiller
   ```
2. Build and install to your Desktop:
   ```bash
   make install
   ```
3. Double click `PortKiller.app` on your Desktop!

## Architecture

PortKiller follows strict modern architecture practices:
- **Clean Architecture & MVVM**: Completely decoupled UI, Business Logic, and Services.
- **Protocol-Oriented**: Dependency injection ready for robust Unit Testing.
