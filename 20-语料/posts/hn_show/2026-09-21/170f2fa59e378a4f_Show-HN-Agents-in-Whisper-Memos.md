steps
 Available steps
 Agents can mix built-in delivery, reminders, and integrations. These are the real step types
 available in Whisper Memos today.
Summary
 Run a summary first using the default summary or one of your custom summaries before the memo is delivered anywhere else.
Default email
 Send the memo to the same default inbox you already use for regular Whisper Memos delivery.
Custom email
 Route to any email address, including Things Mail Drop, Day One, or a shared team inbox.
Assign label
 Apply one of your memo labels automatically so the memo is organized as soon as the agent runs.
Lock screen reminder
 Pin the memo as a persistent lock screen reminder so it stays visible until you dismiss it.
Zapier
 Trigger one of your Zapier integrations and fan the memo out into thousands of apps.
Reflect
 Save the memo directly to Reflect notes using the built-in Reflect integration.
Cursor
 Hand the memo to Cursor as a coding task for your AI agent.
