> The project is called NMLinux. The title refers to NETworkManager by BornToBeRoot (https://github.com/BornToBeRoot/NETworkManager), a Windows GUI tool for network diagnostics that I wanted on Linux. NMLinux has nothing to
>  do with the Linux NetworkManager daemon (/usr/bin/NetworkManager). Built with Python 3 + PySide6 (Qt6). 23 tools in one GUI: IP Scanner, SSH terminal, VNC, RDP, Traceroute map, MTR, Nmap, Firewall viewer, and more. Available on AUR.
