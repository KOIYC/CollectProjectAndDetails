> This is a script tag that library maintainers can enable from their Context7 library settings and add to their own docs site.
> The idea is that if you maintain a library on Context7, you can give your docs an AI chat widget without building a custom chat UI or backend. The widget uses the Context7 data for that library, loads asynchronously, and shows up as a floating chat button.
