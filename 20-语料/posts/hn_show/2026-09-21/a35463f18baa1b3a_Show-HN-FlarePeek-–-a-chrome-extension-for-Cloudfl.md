## Overview

Developer tools for Cloudflare Workers on your production domains.

FlarePeek shows the deployment state of the Cloudflare Worker serving the tab you are on, and lets you act on it without opening the dashboard. Preview a version before it is live. Cloudflare's Version Overrides serve a chosen version to a single browser. Pick a version in the panel and your production domain serves it to you and to nobody else — real DNS, real bindings, no staging environment to keep in sync. Error rate per version, not just the average. A version taking 10% of traffic and failing 6% of the time reads as 0.6% overall. Pin a version while traffic is split. Mid-rollout, a reload can hand you either version. Pinning holds one until you unpin it. Change the split. Move the boundary between two versions, or roll back. Anything that changes production traffic takes a press-and-hold. The rest of a post-deploy check. Requests, error rate and CPU p99 over the last 24 hours. Recent errors. Every KV namespace, D1 database, R2 bucket and Queue the Worker binds, each linking to its own dashboard page. Several sites at once, across more than one Cloudflare account. No server in between. Your browser calls api.cloudflare.com directly with your own API token, the same way wrangler does. The token stays in local extension storage and is never synced to your Google account. To tell whether a site is yours, FlarePeek has to ask Cloudflare about it, so by default it checks the address of each site you visit while the panel is open. Manual detection mode turns that off: it then asks nothing until you click. FlarePeek isn't affiliated with or endorsed by Cloudflare, Inc.
