FAQ
 Everything before your first lookup.
 A small product should have short answers.
What does ScoutLayer return? A structured company profile with the best working email, all public emails and phones found, official social profiles, relevant pages, source URLs and processing metadata.
 Where does the data come from? ScoutLayer reads public company websites and the official pages they link to. Source URLs stay attached so every important result can be reviewed.
 What happens when no email is found? You still receive the company and source information we found, but the lookup costs 0 credits when ScoutLayer cannot return a working email.
 How much does it cost? A single lookup in the Web Playground is free forever, no signup required. Bulk lookups through the Web dashboard, REST API or MCP start from $3.98 per 1,000 contacts found, and a domain with no valid contact is never charged.
 Can I use it without code? Yes. Run one domain in the free Playground, or sign in to use the Web dashboard and export a domain list as CSV or JSON.
 Is there an API and an MCP tool? Yes. The Web dashboard, REST API and MCP access all use the same account, credit balance and result schema.
 Do credits expire? No. Credits are a one-time purchase and never expire.
