Frequently asked questions
 Everything you need to know about one API key for every top AI model.
What is Prizm? Prizm is a single API and web studio that gives you access to the top AI generation models — Veo, Kling, Seedance, Nano Banana, FLUX, and ElevenLabs — through one API key and one prepaid balance. Instead of opening a separate account and paying each provider individually, you top up once and generate video, images, and voice from all of them.
 Which AI models can I use with one API key? Prizm supports leading text-to-video, image-to-video, text-to-image, and text-to-voice models, including Google Veo 3.1, Kling, Seedance, Nano Banana, FLUX, and ElevenLabs. All of them run through the same key and the same wallet, so there are no per-provider API keys to manage.
 How much does the Veo, Kling, or ElevenLabs API cost on Prizm? Pricing is prepaid and pay-as-you-go, and every model is priced below its official rate. Each generation shows its exact price before you run it — for example, a short Veo clip starts around $0.40. See the pricing page for the full, live model catalog with transparent per-generation costs.
 Do I need a subscription? No. Prizm has no subscriptions, monthly fees, or minimums. You load your wallet with any amount, and credits are drawn down only as you generate. Your balance never expires.
 Can I use Prizm inside Claude? Yes. Connect your Prizm API key to Claude via MCP and generate video, images, and voice just by asking in plain language. Claude sees every model you can use, picks the best one for each prompt, runs it, and bills it to your prepaid balance.
 What happens if a generation fails? If a generation fails, the charge is automatically refunded to your balance. You only ever pay for output you actually receive.
 Is there a free trial? Prizm is strictly prepaid — there is no free trial credit. You can create an account for free and load as little as you like to start generating, and because every model is priced below its official rate, a small top-up goes a long way.
