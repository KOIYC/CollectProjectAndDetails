## Common questions

Are these tools really free?

Share tools and offline utilities are free. Vaults are local-first on your device; optional cloud sync is available when signed in.

Do I need to install anything?

No. Everything runs in your browser. You can install the site as a PWA for quicker access if you like.

Is my data sent to a server?

Offline tools never leave your device. Share tools encrypt in the browser before anything is stored. Vaults stay local unless you enable cloud sync (ciphertext only).

Can I use these offline?

Most offline tools and local vaults work after the page loads. Network tools like DNS Lookup need connectivity. Share features and cloud sync need the API.

Encode locally — really?

Yes. Encoders, formatters, hashes, and converters run client-side with Web Crypto and pure JS — nothing is uploaded.
