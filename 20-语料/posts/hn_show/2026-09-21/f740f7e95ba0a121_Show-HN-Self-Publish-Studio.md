# Self Publish Studio

Turn a finished LibreOffice Writer manuscript into clean EPUB, print PDF, and a KDP-ready handoff bundle without babysitting export tools or rebuilding the same release package by hand.

## From Writer file to a traceable published edition.

Self Publish Studio does not claim to bypass KDP controls. It prepares the files, checklist, and metadata draft so the author has one clean package for the final publish step on Amazon.
