littleguys Features Works with Install GitHub
 A little guy for
 every AI agent.
 Your Claude Code, Codex, Gemini, OpenClaw and Hermes agents, living in your Mac menu bar. See who's working, who has news and who needs you. Chat, approve and schedule them from one window.
 Build it from source ★ Star on GitHub
 Free and open source · macOS 13+ · Apple silicon and Intel · no download yet, it builds in a few minutes
▶ Watch the full intro (51s, with sound) One look tells you everything.
 The guy in your menu bar acts out what your agents are doing. No dashboards, no tab-hunting.
Everyone, at a glance.
 Click the guy for every agent on every machine, with a live status ring, the last message and a quick reply.
Approve in one click.
 Commands that need you show up as cards: allow once, always allow or deny. No more “[y/N]” buried in terminal tab #9.
Routines that just run.
 Morning digests, nightly dependency bumps, weekly numbers. Friendly schedules, run-now, and results that land in a thread.
From any machine.
 Guys on your Mac mini, your homelab and your laptop, all in one place. Finds gateways on your tailnet and LAN by itself.
Bring any guy.
 Claude Code Codex Gemini CLI Goose OpenCode OpenClaw gateway Hermes agent any ACP agent
 littleguys speaks the Agent Client Protocol, so new agents are one click away from the ACP registry. It's a friendly face for the agents you already run, not a new place to run them.
 Free. Open source.
Yours.
 littleguys holds your gateway tokens and approves real commands on your machines. You should be able to read every line of it, so you can.
 Read the code
 🔒 Talks straight to your agents. No littleguys account, no cloud.
 📭 No analytics, no telemetry.
 🦀 Rust core + React, built on Tauri.
 Install it.
 There's no download yet, so littleguys builds from source. Paste this into Terminal on any Mac running macOS 13 or later:
 curl -fsSL https://littleguys.hervalicio.us/install.sh | bash
 Copy
It installs anything missing (the Xcode Command Line Tools, Rust, Node, pnpm) without sudo or touching your shell profile, then builds littleguys.app into /Applications . The first build takes a few minutes; then look for the guy in your menu bar. Run it again to update.
 Everything it fetches lives in ~/.littleguys , and you can read install.sh before you run it.
