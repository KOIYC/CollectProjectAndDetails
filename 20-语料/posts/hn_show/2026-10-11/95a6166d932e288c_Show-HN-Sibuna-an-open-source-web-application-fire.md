Hi HN,We are building an open source web application firewall Sibuna to have more control over automated traffic from AI bots and crawlers.Sibuna runs as a reverse proxy or alongside an existing ingress through forward-auth. It includes application inspection, OWASP CRS support and a wasm based management console.Please try it, and give us feedback for improvements.Github Project: https://github.com/insanai/sibuna
