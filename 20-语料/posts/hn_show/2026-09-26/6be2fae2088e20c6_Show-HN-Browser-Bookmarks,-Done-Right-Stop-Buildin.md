# kosh: Bookmark Manager

Overview

Bookmark manager to save, organize, tag, and quickly find your favorite web pages.

kosh is a browser bookmark manager that helps you save, organize, tag, and quickly find your favorite web pages. It works with your browser’s native bookmarks, offering a focused interface for organizing large collections without migrating to a separate service.
