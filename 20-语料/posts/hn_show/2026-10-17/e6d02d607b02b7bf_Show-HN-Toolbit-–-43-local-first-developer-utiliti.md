# Developer Workspace for JSON, JWT, API and Data Tools

Toolbit is a local-first developer workspace with 43 offline tools — JSON formatter, JWT decoder, Base64 encoder, regex tester, SQL formatter, YAML formatter, UUID generator, hash generator, cron parser, CSV to JSON converter and more. Everything runs in your browser: no uploads, no tracking, no sign-up.

## JSON, YAML & Format Tools

Beautify, minify, and validate the structured formats you read all day.

## Encoding & Token Tools

Encode, decode, and inspect Base64, URLs, JWTs, certificates, and wire formats.

## Generators

Produce identifiers, hashes, passwords, QR codes, and realistic test data.

## Converters

Move data between formats, units, colours, timestamps, and cases.

## Inspect & Compare

Test regular expressions, diff text, read git patches, and decode schedules.

## API & Command Builders

Compose HTTP requests, WebSocket sessions, cron entries, and Docker commands.

## Text & Document Tools

Clean up text, preview Markdown, work with PDFs, and do date maths.

### Runs locally

Every transformation happens in your browser with standard Web APIs. There is no backend to send your data to.

### No uploads

Files you drop in are read from disk and processed in the tab. They are never transmitted, so confidential documents stay confidential.

### Works offline

Install it once and the whole toolbox keeps working on a plane, on a locked-down network, or on an air-gapped machine.

### 40+ developer utilities

Formatters, encoders, generators, converters, and inspectors for the tasks that interrupt real work.

### Workspace mode

Open several tools as tabs, pipe output from one into the next, and keep your working set in view.

### Keyboard shortcuts

A command palette and shortcuts for everything, so you never reach for the mouse mid-thought.

## Frequently asked questions

Does Toolbit upload my files?
: Local transformations process input in your browser. HTTP and WebSocket tools send user-initiated requests. Nothing else leaves the device: there is no analytics, no tracking, and tool input and output are never uploaded.
Can I use Toolbit offline?
: Toolbit installs as a PWA in supported browsers. Cached local tools can work without a connection; network tools still require their endpoints.
Is Toolbit free?
: Yes. Every tool is free to use, there is no sign-up, no account, no paid tier, and no advertising. The project is open source under the MIT licence.
Does Toolbit support JSON?
: Yes. Toolbit includes a JSON formatter, a JSON Schema validator, a CSV to JSON converter, and YAML and XML converters that read and write JSON.
Does Toolbit track me?
: No. Toolbit has no analytics and no tracking. Tool inputs and outputs are never collected, and apart from the requests you explicitly send with the API and WebSocket tools, processing happens locally in your browser.
Is there a desktop version?
: Toolbit installs as a PWA from supported browsers on computers and mobile devices. Cached local tools are available offline.
