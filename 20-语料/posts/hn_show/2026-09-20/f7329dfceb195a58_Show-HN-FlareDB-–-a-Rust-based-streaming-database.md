I’m building FlareDB, a Rust-based streaming database with Apache Beam as programing interfere The latest release, v0.2.0, i launched FlareDbIO, which lets data processing pipelines write results into FlareDB, query them using SQL, and read the results back into another pipeline. The goal is to make processed data persistent and without having to maintain a external serving database
