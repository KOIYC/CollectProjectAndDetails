TeXposit - Modern Collaborative LaTeX Editor

# Easy Work, Serious Results.

TeXposit is a modern LaTeX and Markdown editor for collaboration and responsible AI-assisted writing, built in the EU.

### Live Preview in Your Browser

A real LaTeX engine runs client-side and recompiles as you type. No compile button, no server queue, no waiting. The last good render stays on screen while the next one builds.

### Real-Time Collaboration

Edit with unlimited collaborators. Live editing, per-user version history, and real-time chat.

### AI Assistant & Ollama Support

Research discovery, review, writing assistance and more. Connect Ollama to use models running on your own machine directly.

### Markdown, Visual Editor & Hybrid .tex.md

Switch between LaTeX, Markdown and a visual editor at any time. Write prose in Markdown, drop into LaTeX where you need it, and compile to the same publication-ready output.

### Built-In Reference Search and Management

Search arXiv and other databases without leaving the editor. One click from result to BibTeX in your bibliography.

### Document Provenance

Every project carries a cryptographically signed authorship record. Share a tamper-proof report showing who wrote what and how much was AI-assisted.

### Version History & Comments

Every project is a git repository and every save is an attributed commit. Comment on any line and propose inline suggestions without overwriting a co-author's text.

### LaTeX Verification & Error Checking

Compilation errors explained in plain language, with the line that caused them. Citation keys, references and bibliography entries are checked continuously as you write.

### EU-Hosted & Self-Hostable

All data on European servers, GDPR compliant. Deploy on your own infrastructure with a single Docker command for full control.

## User Guide

Every feature documented. Start here or go straight to what you need.

Is TeXposit free to use?

Yes. TeXposit is in free public beta. Unlimited projects, unlimited collaborators, live preview, the AI assistant and full version history are all free, with no compile timeouts.

How is TeXposit different from Overleaf?

The main differences are live preview that compiles in your browser instead of on a server, unlimited collaborators on the free tier, local file sync, the hybrid .tex.md format, cryptographic authorship provenance, and EU hosting with a self-hosting option.

Can I import my Overleaf projects?

Yes. Upload your project as a ZIP or connect the repository and TeXposit imports the files, bibliography and folder structure. It takes about 30 seconds and nothing stops you continuing to use both editors.

Is my data safe?

All data is stored on European servers and TeXposit is GDPR compliant. We never train models on user data. You can also self-host TeXposit on your own infrastructure with a single Docker command for complete data control.

What is live preview and how is it faster?

Live preview runs a real LaTeX engine compiled to WebAssembly inside your browser, so your document recompiles as you type with no upload, no server queue and no compile button. Final PDFs are still produced by a full TeX Live installation.

Do I have to use the AI assistant?

No. The AI assistant is entirely optional and TeXposit works as a normal LaTeX editor without it. When you do use it, it searches real academic databases for citations rather than generating them, and you can connect a local model through Ollama so your text never leaves your machine.

What is document provenance?

Every project keeps a cryptographically signed record of who wrote which parts of the document and how much was AI-assisted. You can export it as a tamper-evident report, which is increasingly useful as journals and funders ask authors to disclose AI involvement.

Can I work on files stored on my own computer?

Yes. Local file sync lets you edit a project directly on your own disk while still using the editor's features, so you keep full control of your files rather than having them live only in the cloud.

Does TeXposit work with my LaTeX packages and journal templates?

Final compilation runs on a full TeX Live installation, so standard packages and journal classes work as expected. Live preview ships a subset of TeX Live, so a document using very unusual packages may fall back to server compilation for an accurate render.

Can I self-host TeXposit?

Yes. TeXposit can be deployed on your own infrastructure with a single Docker command, which is the same deployment we run ourselves rather than a separate enterprise edition.
