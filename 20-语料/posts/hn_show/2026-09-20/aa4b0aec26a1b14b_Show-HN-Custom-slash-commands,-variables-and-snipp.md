# Text Expander & Autofill - Slash Commands Anywhere

slashanywhere.com

Overview

Create custom slash commands to insert text, snippets and variables on any website, plus AI commands for any selected text.

Type "/" and instantly access your favorite commands, text snippets, templates, and shortcuts on any website. Stop copying and pasting the same information over and over again. With Slash Anywhere, you can create custom slash commands that let you insert text instantly wherever you type. Just type "/" in any text field, choose a command, press Enter, and you're done. Prefer something other than "/"? You can set any symbol you like as your trigger, or skip the trigger entirely and open your commands with a keyboard shortcut such as ⌘+K or Ctrl+Shift+Space. ⚡ FAST SLASH COMMANDS Type "/" to instantly open your command palette. Use your keyboard to search and navigate through commands, then press Enter to insert the result. Slash Anywhere is designed to be fast, lightweight, and keyboard-first. You choose how the command palette opens: • "/" — the default trigger • Any custom symbol you prefer • A keyboard shortcut like ⌘+K or Ctrl+Shift+Space 📋 CUSTOM TEXT SNIPPETS Create your own commands for anything you type repeatedly. For example: /email → john@example.com /address → 123 Main Street, New York /signature → Best regards, John /phone → +1 555 123 4567 Instead of searching for information, opening another app, or copying and pasting, just type "/". 🌎 WORKS ANYWHERE YOU TYPE Use your slash commands across the web. Gmail ChatGPT Reddit Forms Text fields Textareas Contenteditable fields & more Your commands are available wherever you need to type. 📅 BUILT-IN COMMANDS Slash Anywhere also includes useful built-in commands that work out of the box: /clip — Paste something you copied earlier /voice - Speech to text /emoji — Open an emoji picker /date — Insert today's date /time — Insert the current time And more commands can be added over time. 🗂️ CLIPBOARD HISTORY Slash Anywhere remembers what you copy, so you can paste something from earlier without digging through other apps or copying it a second time. Type "/clip" to see your recent copies, or press Option+V on Mac (Alt+V on Windows) to jump straight to them from wherever you are typing. • One shortcut opens your clipboard, no command list in between • Set your own key combination instead, if Option+V is already taken on your machine • Search your copies once the list gets long • Optionally include text you copied outside the browser Your clipboard stays yours: • Your copies stay on this device — never synced, never uploaded, never sent anywhere • Anything that looks like a password, key, or card number is skipped rather than saved • Only your most recent copies are kept — 10 on the free plan, 50 with Pro • Clear your history whenever you like, with one click Clipboard history is switched off until you turn it on, and Slash Anywhere asks for clipboard access at that moment — not before. ✨ AI COMMANDS Select text on any page, open the command palette, and let AI work on it. For example: /summarize — Turn a long article or email into a short summary /fix — Correct spelling, grammar, and punctuation More AI commands are on the way. • Works on any selected text — in a text field, an email, or anywhere on a page • In a text field, insert the result in place of your selection with one keystroke • Anywhere else, read the result and copy it with one click • Nothing changes on the page until you choose to insert AI commands run on your own OpenAI API key: • Add your key once in Settings to turn AI commands on • Available on the free plan — no Pro subscription needed • Your key is stored encrypted and is never shown again after you save it • Only the text you select is sent to OpenAI, and only when you run a command • Requires a free Slash Anywhere account 🔀 COMMAND VARIANTS Need multiple versions of the same command? Create variants for a single command. For example: /email - Personal - Work /signature - Short - Professional /address - Home - Office Keep related snippets together instead of creating a separate command for every variation. 🕐 RECENT COMMANDS Your recently used commands appear at the top of the command palette, making frequently used snippets even faster to access. ⌨️ KEYBOARD-FIRST Slash Anywhere is built around the keyboard. 1. Type "/" 2. Search or navigate 3. Press Enter 4. Keep typing No need to reach for your mouse or interrupt your workflow. 🔧 CUSTOM COMMANDS Create commands that match the way you work. Use slash commands for: • Email addresses • Phone numbers • Addresses • Email signatures • Meeting links • Frequently used messages • Customer support replies • Company information • URLs • Templates • Repeated phrases • Any other text you type frequently You decide what each command does. 🔢 VARIABLES Make your snippets dynamic with variables. For example: /greeting Hello {name}, Thanks for reaching out. Variables let you reuse the same command while keeping parts of the inserted text flexible. Variables are available with Slash Anywhere Pro. ⭐ SLASH ANYWHERE PRO The free version lets you create up to 10 custom commands and use all built-in commands. Upgrade to Pro to unlock: • Unlimited custom commands • Variables • A longer clipboard history — 50 copies instead of 10 • More powerful reusable snippets • All the tools you need to build your personal command library Whether you use a handful of shortcuts or build a complete library of commands, Slash Anywhere grows with your workflow. 🚀 BUILT FOR SPEED Slash Anywhere is designed for one simple idea: Type "/". Choose a command. Get things done. No complicated workflows. No switching between apps. No repetitive copy and paste. Turn the things you type every day into instant slash commands. Get started with Slash Anywhere and create your first command today.
