## FAQ

 Why FastRecall? +

Nobody wants to be locked into a single AI model. With routers and multi-agent systems becoming essential infrastructure, your context should move seamlessly between models and providers. Existing memory solutions are overcomplicated, slow, and expensive. Along with SOTA model-free compaction, FastRecall lets the model organize its own context. This is faster, cheaper, and more performant.

 Do you host models? +

No, we do not call any model APIs on your behalf.

 How is FastRecall so cheap? +

FastRecall uses highly optimized and efficient context storage to deliver fast and free context recalls. You only pay for context storage on disk, the cheapest part of the stack. We do not use expensive LLM-based memory compaction techniques. These techniques introduce latency, cost, and retrieval errors.

 What if I want to make use of model provider caching? +

FastRecall is designed to work alongside existing model provider caching mechanisms. If you re-use the same model and context, you can leverage the existing cache for reduced token costs. See the Native continuation section of the Docs for more information.

 Do I need to pass in the entire context into every model call? +

No, we offer our SOTA model-free FlashCompact system to intelligently organize contexts over 1M tokens, or as an option flag in your API calls. See the FlashCompact section of the Docs for more information.

Persistent context, anywhere.
