# Hishel An elegant HTTP caching library for Python

HTTP caching for Python — RFC-compliant, transport-agnostic, streaming-friendly

## Sans-IO Design

Ships with pure-python RFC-compliant state machine for HTTP caching.

## Streaming friendly

Avoids buffering entire responses in memory, which most caches do.

## Built-in Integrations

Ready-to-use integrations for HTTPX, Requests, FastAPI, and more.
