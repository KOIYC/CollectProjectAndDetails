### Full Windows remote desktop, from your phone

Not a viewer — a real RDP client built into the app. Trackpad or direct touch, pinch-zoom, two-finger scroll, right-click, hardware keys and modifier locks, at a desktop resolution your phone letterboxes instead of squashing. No gateway, no desktop relay: the phone speaks RDP itself.

### AI agent that runs your terminal, not just answers questions

Press one shortcut, describe the task in plain language. The agent reads your real terminal output, executes commands, and stops to confirm before anything destructive. Native to the session — no separate chat window.

### Full-featured before you ever sign in

Connections, groups, scripts, and encrypted local storage all work completely offline with zero account. Sign in only when you actually want multi-device sync — not before.

sync

### Unlimited devices, end-to-end encrypted

Phone, laptop, work desktop — no device cap and no per-seat pricing. Connections, groups, scripts and keys sync as ciphertext the server cannot read, and anything you mark 'this device only' never leaves the device at all.

### Cross-platform RDP remote desktop

Connect to Windows desktops from Windows, macOS, or Linux. Competitors either don't support RDP at all, or lock it to Windows only. XConnect is the only cross-platform option.

### Background SSH tunnels that survive terminal close

Port-forwarding tunnels run independently of any terminal session — closing a tab or window never drops them. Multiple tunnels can share one SSH connection. Start, stop, and monitor everything from one panel.

### SSH key library: one key, many servers

Manage private keys in a central library and link each key to as many servers as you want. No more filling in file paths per-connection. Keys are stored AES-256 encrypted — never plaintext on disk.

### Script center: write once, run on any schedule or selection

Bash, Python, or JavaScript — your choice. Scripts are organized in built-in categories (ops, security, backup, custom), each with version history and changelogs. Run across a batch of servers in parallel or series, or schedule automatic runs on a timer. No more manual logins for routine tasks.

### Built-in SFTP file manager

No need to open a separate FileZilla or WinSCP. Browse remote files, drag-and-drop upload or download, with concurrent transfers and real-time progress — all inside XConnect.

### Tamper-evident audit log

Every command is logged in a cryptographic chain — and you can prove it. One click runs an integrity check that verifies whether any entry has been altered, pinpointing the exact record if anything was changed. Exportable and built for teams where 'tamper-evident' needs to mean something.

### Server Monitor: see every node's health at a glance

Know which servers are up before you need them — no connection required. Scan all hosts in one click, color-coded latency, configurable auto-refresh, grid and list view, and group filtering. Essential when you're managing more than a handful of servers.

### Global search across all connections

One shortcut to search across every connection, group, and script. No need to remember which group a server lives in — type and jump directly to it.

### Built-in local shell

Open a local terminal session inside XConnect without switching to another app. Work side-by-side with remote sessions, test scripts locally, or handle quick local tasks — without ever leaving the window.
