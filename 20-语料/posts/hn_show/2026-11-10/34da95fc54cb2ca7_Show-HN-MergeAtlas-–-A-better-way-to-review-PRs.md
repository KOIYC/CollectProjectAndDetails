## 正文

Hey HN community, I built MergeAtlas - a better way to review PRs when bulk of the code is written by AI agents. It is a skill for your coding agent plus a small python script.MergeAtlas was built from a simple premise - When AI agents are writing the code, there's no need to review every single line of code. Instead it is better to understand the intent, important lines, and the blast radius.MergeAtlas helps you see the intents behind file changes, understand why each file was changed, and PR's scope all before you read a single line of code. When you are ready to read the code, MergeAtlas singles out the key lines from each file, so you are only focused on the most important lines.It goes further than GitHub's Files Changed tab as it also determines what files outside of the PR are affected by the changes.I tuned the skill till I was satisfied with the result in terms of structure, explanations, and verbosity.There's a live demo on the website based on an actual PR from excalidraw. Play around with it, and any feedback is welcome.Github: https://github.com/ismayilkarimli/MergeAtlas
