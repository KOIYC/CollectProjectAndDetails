다시 불러오기 기간과 집계 기준 각 항목의 기간은 숫자 위에 표시합니다. 일별 집계는 KST 하루 동안 관측한 누적 스냅샷 증가량의 추정치입니다. 일별 자료가 없으면 최근 24시간 최고 사용량과 누적 모델 순위를 구분해 보여줍니다. 최고 사용량은 사람이 아닌 익명 설치 1대 기준이며 이름이나 ID를 공개하지 않습니다. 리셋 전망은 보정된 확률이 아닌 외부 공개 신호 점수입니다. 출처가 서로 맞지 않거나 오래되면 수치 대신 원문으로 연결합니다.
