10 Questions and answers
 Everything remains editable on the canvas.
FAQ
01
 What is Recto?
Recto is a visual design canvas for coding agents. It lets you create UI, motion, SVG and 3D designs with agents such as Claude Code and Codex while keeping everything directly editable.
02
 Is Recto an AI model?
No. Recto works with the coding agents already installed on your computer instead of replacing them.
03
 Which coding agents does Recto support?
Recto automatically detects supported coding agents installed on your system and lets you use them directly inside Recto. You can also work with multiple agents.
04
 Can I edit what my agent creates?
Yes. Everything remains editable on the canvas. You can drag, resize, style, animate and modify elements directly, then continue prompting from where you left off.
05
 Does Recto generate real code?
Yes. Recto uses HTML and CSS underneath your designs, making them easy to export and use outside Recto.
06
 Does Recto require MCP or an API?
No. Recto works locally with your coding agents without requiring MCP, API configuration or additional network calls between Recto and the agent.
07
 Can I import existing designs?
You can bring designs from websites into Recto. Figma import is coming soon.
08
 How much does Recto cost?
Recto is free.
09
 Which platforms are supported?
Recto is available for Mac, Windows and Linux.
