> **kagen** · 2026-10-21T21:03:14.000Z　
> Hello HN! Zooki World is a small low-poly zoo that runs in your browser, and is now also available on mobile. You can walk around with other visitors and see the same animals as they do in real time. What makes Zooki World unique is that there is no simulation server. All animal behaviors are deterministic; each two-minute block is used to calculate movement based on an animal's ID, the version of their enclosure, and the current time block.Therefore, each browser will independently reproduce the exact same movements and pathing. The only role of the server is to synchronize time and send player positions. You can also interact with the animals or purchase treats for them. When you feed an animal, all other visitors will see it happen at the same time. The animals were created using SDF (signed distance field) sculpting instead of traditional blender models. I wrote the simulation, path finding, and server code myself. Claude Code was very helpful, however, I did personally review and refine all of the code. The monetization model is inspired by the "Million Dollar Homepage" where you can "adopt" any enclosure for $1 until someone else outbids you by at least 10%. So far, the numbers are modest: 183 visits since October 9th with one enclosure adopted — by another project of mine. You can view the public statistics here: https://zooki.world/stats I would love to get your feedback: How does it run on your device (GPU, browser, FPS)?How do the animals look from a standard camera angle?
