## 正文

I have built a note taking, to-do application, what makes this different then others?This app targets to make note taking fun, and efficient. - Most important feature it's fast. Performance wise, and usage wise. It's a combination of convenient, clever (actually obvious) keyboard shortcuts, and focused optimizations to make it extremely simple to take notes fast.
 - This is completely hand crafted application, Not an AI slop, nor AI assisted. And, a lot of thought has been put to architect the app, and design.
 - Stores all notes in a simple text file, so personal data is never locked down. If you are a Linux user, you can simply use grep/ripgrep to filter/search your data.
 - Every note is one liners, actions are done through keyboard shortcuts
 - Local only
 - Organize notes using Projects, Tags
 - A simple but effecting Task management system
 - Unlimited undo/redo
 - Search
 - Filtering by date, date range
 - Context system to group notes and focused work
 - Notes are archived, instead of being deleted. But in future there will be way to purge archived notes

WIP feature: Reminders- Planned features
Back-links, Simple Bookmark manager, Kanban, Timer, Eisenhower matrix, while storing all data in text file.This app is still in development, and many things will be cleaned up gradually. But even in current state it's a complete powerful, efficient note taking application.[Check here for more details, and screenshots](https://mtarin.com/projects/nift/)[Demo video here](https://youtu.be/r4c6hFey-8M)[Demo version download](https://github.com/tmahmood/fluffy_sparrow/releases)Let me know what do you think!NB: Previously I posted this app as FluffySparrow, NiFT uses same back-end, but the UI is completely rewritten using Tauri, with more features.
