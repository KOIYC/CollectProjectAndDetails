Walk through your first PDF ↗ 05 A FEW GOOD QUESTIONS
 Before you
 bring your files.
 Know what to expect before you download.
 Explore the documentation ↗
 Does it really work completely offline? + Yes. Once installed, every PDF tool runs on your Mac without network access. You need an internet connection to download the app or read this website, but not to process your documents.
 How your data is handled ↗
 Where do my documents go? + You open files from your Mac and choose where to save the results. DipperPDF does not upload your PDFs or use external PDF services. If you save into an iCloud or other synchronized folder, that service may upload the saved file according to its own settings.
 Read about local processing ↗
 Is every tool free? + Yes. Every tool is included, with no trial, subscription, or paid upgrade. You do not need an account or payment details. The source code is available on GitHub.
 Explore the source code ↗
 Will my original PDF change? + No. DipperPDF prepares a separate result and prevents saving over an imported source. Review the output, then save it with a fresh filename. To use another tool, import the copy you just saved.
 See the open-to-save workflow ↗
 Can I work with password-protected PDFs? + Use Unlock PDF first with the password and permissions needed for the document. Other tools require an unencrypted input. Unlocking happens locally and saves a separate, unencrypted copy; it does not crack passwords.
 Learn about password-protected files ↗
 Can it read scanned text? + DipperPDF does not include OCR. Text extraction, comparison, and redaction work with existing selectable text, not words inside scanned images. Compression can reduce image-heavy PDFs, but savings depend on the document.
 More answers in the documentation ↗
 Does it work on my Mac? + DipperPDF is a native Mac app with support for Apple silicon and Intel. Visit the installation guide for system requirements and step-by-step setup instructions.
 View installation requirements ↗
