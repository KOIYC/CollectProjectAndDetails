## 正文

Each creature in this data lab is a real text classifier. You put together a workflow, and the creatures execute it. Just set a stream of incoming messages and watch them work: one filters out the spam, another tags each message's mood, finally a router sends each message to the right bin, and anything it isn't sure about goes to reviewThe classifiers run entirely in your browser. It uses a 22.7M parameter model, int8 ONNX, about 10 ms a message, no API callsOutside the lab, the creatures also evolve, chat, gossip, build huts, plot charts, count numbers, process and eat words, code and dream when asleep. You can also see their stream of consciousness, which they turn into thoughts that they tag. And when they are asleep, you can watch their dreamsThere are a lot of ways of modifying or evolving the environment and the creatures, including adding elements from other websites, playing music and changing the weatherAnd if you want to change anything at all, talk to the Operator (or make it smarter), connect it to your Claude or OpenAI subscription, or setup your API key, or point it to a local model in Ollama or LM Studio, and you can edit the whole world via chat, without limits (get the code here: https://github.com/nicobrenner/id-le)What else would you like the creatures to do?PS: Happy Halloween
