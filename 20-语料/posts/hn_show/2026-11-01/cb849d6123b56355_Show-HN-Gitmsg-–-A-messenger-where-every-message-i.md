## 正文

Connecting… Some things should exist just for the fun of it.
 We turned GitHub into a messenger. Chats are repositories. Messages are commits. “I never said that” now comes with a git log . Not because the world needed another chat app — because we wanted to see if it would work.
 No pitch deck. No grand plan to reinvent human connection. Just a weird idea, a familiar interface, and the unreasonable satisfaction of making them fit. Software can still be a playground.
 Bring your GitHub account. Invite a friend. Send a photo, leave a voice note, react to something stupid. No fake conversations, no bot pretending to be your friend. Real people. Real messages. A little Git underneath.
 No magic privacy claims, either. GitHub can read standard messages; public channels are public. Browser encryption is optional, and your keys are yours to keep. Deleting a message hides it from the chat — Git still remembers.
 Not everything needs to become the next big thing. Sometimes “holy shit, it works” is enough.
