Basecase is a playground for designing buildable robotics.

### Requirements

- macOS and Node.js 22 or later
- Claude Code

The optional AI agent uses your locally running Claude Code through the Agent Client Protocol.

### Install & run

```bash
npm install
npm start
```

`npm start` builds the app and runs it at full speed. For development with hot reload, use `npm run electron:dev`.

### Contributing

Read AGENTS.md §0 first. Formatting, lint rules and tests are enforced by a pre-commit hook; run `npm run check` before you push, and `npm run test:e2e` after UI changes.

To add a part to the catalog, ask your coding agent to “add this part: ⟨link⟩”. It follows .agents/skills/add-part/SKILL.md, which you can also follow by hand.
