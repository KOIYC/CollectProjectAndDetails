# This Open-Source Cybersecurity Platform Uses AI Agents to Detect Threats and Protect Businesses Automatically

Thomas Unise

Hey everyone , I built ARGUS, a free, open-source cybersecurity platform designed to help businesses find security threats, investigate attacks, and respond to them automatically.

I wanted to build something that could handle much of the work a cybersecurity team normally does, using AI agents, without giving up control over what actions get taken.

Here’s what it actually does:

- 24/7 security monitoring: Watches your servers, cloud infrastructure, networks, employee accounts, devices, and code for suspicious activity.
- * Threat detection: Identifies unusual logins, security vulnerabilities, potential attacks, and other signs that something is wrong.
- * AI investigations: Uses seven specialized AI agents to investigate alerts, review evidence, identify potential threats, and recommend what to do.
- * Automated protection: Can block suspicious IP addresses, isolate compromised devices, and take other protective actions. You decide which actions can happen automatically and which require approval.
- * Security testing: Tests your authorized systems for vulnerabilities and weaknesses before someone else finds them.
- * AI security: Detects unauthorized AI tools and suspicious AI agent activity. It also includes tools to test whether your systems can detect attacks involving AI agents.
- * Security reporting: Records security events, investigations, approvals, and actions. Includes support for common security compliance frameworks.

It also integrates with services like AWS, Azure, Google Cloud, GitHub, Cloudflare, CrowdStrike, and others.

A few other things worth mentioning:

You can host it on your own infrastructure, use OpenAI, Anthropic, or locally hosted models, and decide exactly how much access and autonomy you want to give it.

The automated response features are disabled by default, and there are approval requirements, safety limits, and rollback controls.

It’s released under the MIT license, so anyone can use it, modify it, or contribute to its development.

I built ARGUS because I think businesses should have access to better cybersecurity tools without needing an enormous security budget.

It’s available on GitHub now. I’d love to get feedback from developers, security engineers, and anyone interested in trying it.

https://github.com/thomasunise/argus
