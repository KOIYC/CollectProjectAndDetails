DADGPT Costume

Ask Dad anything.

## Every. Single. Time.

## It’s a costume.

1. Wear a black t-shirt and a black hat.
2. Set a phone sideways on the brim, screen out.
3. Pin the printed logo to your chest.
4. Open DADGPT. People walk up, talk to Dad, or get roasted.

## Tap. Talk. Groan.

Why won’t skeletons fight each other?

They don’t have the guts.

Your browser hears you. A language model writes one pun. Dad says it out loud.

## Snap. Roast. Burn.

Roast me.

Nice vampire cape. Shame the only thing it scares off is dates.

Tap the camera. Dad counts down, snaps a photo, and roasts what he sees. Photos are never saved.

Vector files print sharp at any size. The PDF fills a letter page.

## Make your own Dad

Paste this into Claude Code or any coding agent. It sets up DADGPT with your own keys.

```
Set up my own copy of DADGPT, the dad joke costume app at https://github.com/johnpolacek/dadgpt. Read the README first.

1. Clone it and install with pnpm. It needs Node 24.
2. Copy .env.example to .env.local. Ask me for my Anthropic API key and a passcode to lock live mode. An OpenAI key is optional and gives Dad a better voice.
3. Run pnpm dev. Open /live and confirm Dad answers out loud with a joke, and that the camera button roasts a photo.
4. Deploy it to Vercel with the same environment variables, then give me the URL.
```
