## 正文

Hello HN! We have recently launched a scanning and remediation system for AI-built web applications. It is fully agentic as well as has a web UI that supports GitHub sign-in. Would love some hackers and tinkerers to try it out.An agent can natively interact with the system when you pass the prompt: "Scan with cleanslop.com" to it within the context of a codebase. It uses Stripe's new Link identity to verify an agent.It is currently super specific for TypeScript, NodeJS and JavaScript apps, for eg Next.js + Supabase stack, typically built out by LLM powered coding agents and vibecoding platforms like Replit, Lovable etc.I have put together an under-the-hood page that briefly explains the workings of the system: https://cleanslop.com/under-the-hood
