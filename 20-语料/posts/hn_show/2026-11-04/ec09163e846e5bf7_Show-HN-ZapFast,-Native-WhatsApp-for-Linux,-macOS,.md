ZapFast
WhatsApp, native and fast
A lightweight WhatsApp app for Linux, macOS, and Windows. Chat, send voice messages, and share files.
Download
What is ZapFast?
GitHub
⚡
Lightweight
Opens in under a second and uses about 200MB of RAM. No browser engine.
🦀
Native, in Rust
Built with egui and fastframe , the framework behind a family of native desktop apps. No browser engine inside.
🎤
Voice messages
Play, seek, and record voice messages in the chat. OGG/Opus support is built in.
🖼️
Attachments
Photos, GIFs, stickers, documents, polls, locations, and link previews appear in the chat. Add captions before sending files.
🔔
Background mode
Closing the window keeps ZapFast linked in the tray. Notifications show the chat picture, and muted chats stay quiet.
👥
Several numbers
Link more than one WhatsApp number and switch between them from your picture at the foot of the rail beside the chat list.
🎨
Themes
Light, dark, or the system’s appearance, custom colour themes, and on Omarchy your desktop theme.
Make a theme
⌨️
Keyboard shortcuts
Search, switch chats, reply, and record with shortcuts. Select and copy text, including across messages.
🔓
Open source
MIT-licensed Rust that links through whatsapp-rust. The linking process is documented.
Read the source
Want Spotify just as fast and native? Spotifast is ZapFast's sibling: the same native interface, for Spotify. Both are built on fastframe , the shared foundation for native Rust apps built with egui .
