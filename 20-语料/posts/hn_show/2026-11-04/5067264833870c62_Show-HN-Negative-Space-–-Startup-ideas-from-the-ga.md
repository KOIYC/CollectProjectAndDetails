## 正文

There was a tweet[1] a while ago describing a simple way to come up with new game ideas: embed the descriptions of every game on Steam, find the areas of the space where there’s nothing, and turn those points back into descriptions. It’s a fun idea, so I vibe coded something quick and dirty to do the same for companies, using the YC directory.It embeds 6,304 company descriptions, blends a few related companies, pushes that point away from everything else, and has Claude write up what could live there. Each draft is then embedded and measured against real companies.The code and embeddings are on GitHub[2], along with a Claude skill so you can run it yourself.Footnotes:
