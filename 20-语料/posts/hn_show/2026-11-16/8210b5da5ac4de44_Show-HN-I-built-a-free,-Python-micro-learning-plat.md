Before you start.
Do I need any programming experience? +
 No. Beginner Python Block starts with your first line of code and introduces each concept along the way.
 You can start from zero.
Is the entire beginner course free? +
 Yes! The complete Beginner Python Block, including its quizzes, coding exercises, and projects, is free!
Do I need an account or any software? +
 No account or installation is needed to start. Python runs in your browser. You can create a free account
 whenever you want to sync lesson progress across devices.
How is my progress saved? +
 Without an account, your lesson progress stays in this browser on this device. Signing in lets you sync
 lesson progress across devices. If you started before signing in, you can import that browser progress
 from your account settings. In both cases your code and project files stay in the browser where you wrote
 them.
