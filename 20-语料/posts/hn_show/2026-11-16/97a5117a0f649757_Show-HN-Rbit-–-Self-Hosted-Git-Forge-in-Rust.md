## 正文

rbit is a self hosted git forge designed around three core philosophies: speed, security, and efficiency.We built rbit using Rust, Axum, Askama, Gitoxide, SQLite + redb, HTMX + Tailwind. Every piece of the stack was carefully considered to provide users with the fastest possible experience working with their repos without sacrificing the functionality you've come to expect from your existing git forge.Our team is actively working to help make rbit the best it can be and we'd love to get your feedback while we continue improving!rbit is built using rbit and it's CI/CD pipeline, we are dogfooding as we build it in the open. It has been localized into 9 languages including: English, Spanish, Portuguese, French, German, Russian, Chinese (Simplified), Japanese, and Korean. If you're a native speaker we would happily accept translation fixes!
