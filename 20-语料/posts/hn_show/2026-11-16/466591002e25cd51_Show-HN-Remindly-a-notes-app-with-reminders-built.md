FAQ
 Questions people ask.
Which devices does Remindly run on?
 There are native apps for iPhone (iOS 18 or later), iPad (iPadOS 18 or later) and Mac (macOS 15 or later), plus a web app. On Windows, install the web app from Edge or Chrome: it opens in its own window, but it needs a connection, because your notes aren't stored on the PC. There's no Android app.
Does it work without an internet connection?
 Yes. The iPhone, iPad and Mac apps keep every note on the device, so you can read, write and search offline. Your changes sync when you're back online. Remindly AI (Labs), when turned on, also answers from your notes on the device with the Wi‑Fi off.
Is there a limit on how many notes I can keep?
 No. Notes and notebooks are unlimited on every plan, including the free one.
Can I get my notes out later?
 Yes. In the Mac app, File → Export All Notes as Markdown… writes every note as a .md file, one folder per notebook, with attachments alongside. The folder opens in Obsidian or any text editor.
How do I move my notes from Evernote?
 Export your notebooks from Evernote as .enex files, then choose File → Import from Evernote… in Remindly for Mac. The switching guide covers what comes over.
Does Remindly work with ChatGPT or Claude?
 Yes. Once you allow it, Claude and ChatGPT can search and read your notes, add a note or add to one, share a note by link and set reminders. They can't delete a note for good, and you can take the access back any time in Settings → Integrations. Remindly is listed in Claude's connectors directory. It has been submitted to ChatGPT's directory but isn't listed there yet, so in ChatGPT you add it yourself with the server address. The guide covers both.
What is Remindly AI?
 Remindly AI is a Labs feature in the iPhone, iPad and Mac apps. Turn it on in Settings → Labs and an Ask anything bar answers from your notes on the device: it can tidy a note, make a checklist, propose a reminder, and find what you saved, even with the Wi‑Fi off. Fast uses Apple Intelligence where it is available; Smarter downloads Remindly's own model once after you say yes. Locked notes never reach it. Free while it is in Labs.
What leaves my device when I use AI?
 Remindly AI runs on your iPhone, iPad or Mac, so those questions and answers stay on the device. Connecting Claude or ChatGPT is optional: only the notes those assistants' tools request leave your account for that chat, and you can revoke access any time. Notes are never used to train AI. I originally just wanted a notes tool that was quick to add to and that surfaced the right note when I needed it, through search and reminders. It's since become where I keep pretty much everything.It's a notes app where any note can carry a reminder (one-off, repeating, all-day, or location-based). There are native Mac and iOS apps, a web client, and a browser clipper for Chrome and Firefox.Your notes aren't locked in: the Mac app exports everything as Markdown files, one folder per notebook, with attachments alongside and links between notes intact. Any single note can be shared as Markdown from any of the apps.There's also an MCP server, so Claude and ChatGPT can search and write notes. Two things I use that for myself:
> - Keeping my agent skills as notes, so they stay portable between tools instead of living in one vendor's config (ended up being easier than my Github setup)
> - Sourdough (missed out on the trend during COVID): I adapt and write recipes in a Claude session, and they're saved straight back as notesIt also imports Evernote libraries, and optional AI features run on-device with small open models.
