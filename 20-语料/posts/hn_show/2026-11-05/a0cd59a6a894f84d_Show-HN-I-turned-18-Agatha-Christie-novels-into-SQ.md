Start Investigation
Learn SQL by solving murder mysteries
Query the Murder is a free SQL game built around Agatha Christie mysteries. Every case comes with a real database of suspects, alibis and evidence. You write SQL queries to check the alibis, follow the clues and name the killer.
There are 18 cases. The early ones teach SELECT and WHERE. Later cases bring in JOINs, GROUP BY, subqueries and window functions. No account needed.
How it works
Pick a case. Each one is based on an Agatha Christie novel, from Murder on the Orient Express to Endless Night.
Read the case brief and explore the tables of suspects, alibis and events.
Answer 5 questions by writing SQL. Each question teaches you something new.
Solve the last question to name the killer and close the case.

Beginners learning SQL for the first time
