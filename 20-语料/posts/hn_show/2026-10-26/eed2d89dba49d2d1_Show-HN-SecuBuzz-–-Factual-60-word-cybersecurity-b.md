## Latest briefs

Vulnerability MEDIUM 9h ago

### Malicious AGENTS.md File Hijacks AI Coding Agent

A malicious AGENTS.md file placed in a user’s Downloads folder deceives an AI coding agent into installing a rogue npm package, compromising the environment. The flaw exploits the agent’s instruction parsing logic, allowing unauthorized code execution without user interaction, potentially exposing source code and credentials. Users should delete suspicious markdown files and update the agent to mitigate the risk.

### CVE-2026-111497: Critical Brotli Decoder Remote Code Execution

CVE-2026-111497 is a critical vulnerability in the Brotli decoder that permits remote code execution via malformed compressed data. The flaw, rated CVSS 9.8, allows attackers to execute arbitrary code on affected systems without authentication, posing a severe threat to web servers and content delivery networks. A patch is available from the vendor; administrators should apply the update immediately to neutralize the risk.

### Palo Alto GlobalProtect VPN Exploited Flaw CVE‑2026‑109618

Palo Alto Networks’ GlobalProtect VPN suffered an exploited flaw that allows attackers to bypass authentication and gain remote access. The vulnerability, identified as CVE‑2026‑109618, carries a CVSS v4.0 score of 9.2, and a public PoC demonstrates its exploitability. Palo Alto released a patch in the upcoming security update; administrators should apply the fix immediately and verify VPN configuration.
