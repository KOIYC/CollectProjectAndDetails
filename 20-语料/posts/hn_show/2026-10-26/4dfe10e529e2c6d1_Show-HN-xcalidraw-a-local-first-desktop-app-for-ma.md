## README

 A local-first desktop app for managing your Excalidraw drawings.

## Features

- **Local files:** Choose the folder where your `.excalidraw` drawings live.
- **Library management:** Create, rename, and delete drawings and folders.

## Download

Get the latest Windows, macOS, and Linux builds from GitHub Releases.

## Development

### Requirements

- Node.js 24
- Vite+

## Run locally

```sh
git clone https://github.com/xdagiz/xcalidraw.git
cd xcalidraw
vp install
vpr dev
```
