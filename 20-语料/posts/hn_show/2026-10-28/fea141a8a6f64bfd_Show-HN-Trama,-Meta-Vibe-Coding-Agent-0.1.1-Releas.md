For VS Code and omp
 Your AI agent writes code fast. Trama makes sure it's the code you meant.
Trama keeps a map of your app next to your code, as plain Markdown in .trama/ drawn for you as a diagram. Your
 agent reads the map before it writes a line, and every change arrives as a Proposal you approve before any code exists.
Read the guide Install
The loop, in five steps
 From a sentence to running code, with you deciding at every turn.
1
 Step 1: Describe a change
 Say what you want in plain words, as you'd tell a colleague. The request lands on the Board, ready for the agent.
New request
 Customers may send a shipped order back.
 Proposal · Returns after shipping
2
 Step 2: Answer the agent's questions
 Only what it can't decide alone, with its recommendation already selected. Pick an option, or say something else.
Your answer
 ✓ Within 30 days recommended
3
 Step 3: Approve the Proposal
 The change drawn on the map, with every decision and assumption beside it. Nothing is built until you approve.
Proposal
 Approve Approved ✓
4
 Step 4: Run the Tasks
 The agent builds what you approved, one Task at a time or all together, while you follow along on the Board.
Running 3 Tasks
Task 3 of 3 · Returns after shipping
5
 Step 5: Resolve the Drifts
 When the code and the map stop telling the same story, Trama raises a Drift. Fix the code, or keep it and update the map: you decide which one is right.
Drift
 The code and the map disagree: you choose which is right.
Requirements and install
 What you need
 VS Code 1.106 or later, the only editor Trama supports.
 Linux (x64), macOS (Apple silicon) or Windows (x64, in preview).
 omp, the only agent Trama supports.
 The GitHub CLI ( gh ), only for Team.
Install
Install Trama from the VS Code Marketplace , or download the .vsix for your platform from
 Releases and run Extensions: Install from VSIX… from the command palette.
Install Read the install guide
Windows is in preview: trama.exe is not signed, so SmartScreen or an antivirus may warn the first time it runs.
