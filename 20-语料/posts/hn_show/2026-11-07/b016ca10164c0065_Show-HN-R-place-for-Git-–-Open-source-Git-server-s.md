hey hn, sven from Reason Machines (YC F26).we've been experimenting with how fast we can push our ci/cd and code storage systems when swarms of coding agents are all pushing at once. turns out giving 100 agents git push basically ddos'es normal git servers.so we wrote aspen: an open-source git server (apache 2.0) that hits 567 pushes/sec on a single 8-core box with stock git clients.to stress test it live, we put up a shared canvas where every pixel is a real git push:
