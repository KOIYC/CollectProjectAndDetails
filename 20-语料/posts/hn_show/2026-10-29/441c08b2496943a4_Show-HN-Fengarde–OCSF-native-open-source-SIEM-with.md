## One pipeline. Receipts included.

Seven things FENGARDE does that a log viewer does not. Each names the place in the repository where you can check it.

## Nine services. One bus.

No service calls another. Each reads topics from the bus and writes topics back, so any stage can be restarted, swapped or scaled alone. Every box opens its directory on GitHub, and during a replay the boxes light as the attack passes through them.

Swipe sideways to see the whole bus.

## 46 rules, all listed.

Read straight from the rule files in the repository: level, title and the MITRE ATT&CK (or ATLAS, or ICS) tag each one carries.

## Twelve views. Open any.

Each tile opens that view of the real console on the recorded data.

## One take, no cuts.

Recorded in a scripted browser against a running stack. A real SSH brute force and a DNS burst go in over UDP 5514 at about 0:30.

## Run it in ten minutes.

```
$ git clone https://github.com/supermhel/fengarde.git
$ cd fengarde && make preflight
$ make demo          # an SSH brute force becomes a real alarm
# console on http://localhost:8080

$ cd tools/console_e2e && npm install
$ node check.mjs       # every view as admin, analyst, read-only
$ node tour.mjs out    # re-records the video, sends the attack
```

- Docker Desktop with enough memory for OpenSearch. make preflight checks ports and limits before the first start.
- The console, its checks and this page's video all come from the repository: `services/ws7-dashboard/app`, `tools/console_e2e`.
- The UDP syslog listener is unauthenticated: expose port 5514 on a trusted network or VPN only.
- Status, proven versus claimed: SSOT.md. Features per view: console feature matrix.

## You've seen the pipeline run. Now make it yours.

The 10-minute install is the first step, not the last. Pick the next one that fits.

FENGARDE is open source under Apache-2.0. Everything on this page, the console, its checks, the video and the board, is in the repository.

Lab data. The attack is generated by `tools/console_tour_traffic.py` with documentation-range addresses and sent to a stack on the author's machine.

GitHub · README · Apache-2.0 · Fonts: Archivo and JetBrains Mono (OFL-1.1), self-hosted. No third-party trackers, no third-party requests. An optional, self-hosted visit counter (GoatCounter) ships in the observability profile: nothing leaves your network.
