### **3. YAML 配置紧急修复**

**问题**: `_meta/channels.yaml` 第 355 行语法错误
```yaml
# ❌ 旧格式（解析失败）
unlock: 装 OpenCLI 浏览器扩展并保持 Chrome 打开（chrome web store: OpenCLI）；或 agent-reach configure xhs-cookies 走 xiaohongshu-mcp

# ✅ 新格式（修复后）
note_unlock: >-
  装 OpenCLI 浏览器扩展并保持 Chrome 打开（chrome web store: OpenCLI）；或 agent-reach configure xhs-cookies 走 xiaohongshu-mcp
```

**原因**: 中文分号 `；` 在 YAML 中被误认为 key-value 分隔符

**影响范围**: xiaohongshu 渠道配置无法加载

**修复验证**:
```bash
python -c "import yaml; d=yaml.safe_load(open('_meta/channels.yaml','r',encoding='utf-8')); print('Channels:', len(d['channels'])); print('[OK]')"
# Output: Channels: 18 [OK]
```
