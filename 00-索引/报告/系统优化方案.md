# 独立开发知识库系统优化方案
> **基于全网竞品与论文调研**（2026-09-22）  
> **目标**: 明确差距 → 列出改进点 → 系统架构升级

---

## 📊 调研总结

### Top 竞品对比矩阵

| 竞品 | Stars | 核心差异 | 借鉴价值 |
|------|-------|---------|---------|
| **BigSet** (tinyfish-io) | 🔥 Hot | Auto schema + refresh cadence + per-cell provenance | ⭐⭐⭐ 增量更新/溯源机制 |
| **AutoData** (arXiv 2025) | 论文 | Multi-agent + HyperGraph cache + Instruct2DS benchmark | ⭐⭐⭐ 代理分工/基准测试 |
| **RESerch_MON** (FabioLiberti) | arXiv | Cross-source dedup + citation network + Zotero sync | ⭐⭐ 引用网络可视化 |
| **BuilderPulse** | ~50 | Daily email brief (20 questions framework) | ⭐ Alert 机制/问题模板 |
| **weijunext/indie-hacker-tools** | ~20K | Curated tool list (中文友好) | ⭐ 中文场景覆盖 |

### 当前方案优势（领先行业）

✅ **Medallion 数据分层** —— 比 BigSet 更清晰的事实源管理  
✅ **不可变原始归档** (`90-原始/*.jsonl`) —— 支持版本回溯（竞品导出即静态 CSV）  
✅ **九项不变量质检** —— AutoData 只有评估指标，无运行时守卫  
✅ **语义 lint + 近重复检测** —— 超越竞品的内容质量治理  
✅ **导航段设计** —— 避免"死胡同"，优于所有竞品

## 🎯 六大关键改进点

### 1️⃣ 增量更新机制缺失

**问题**: `kb_collect.py` 必须全量重跑或指定 `--days` 窗口  
**影响**: 无法像 BigSet 那样设置 30m/daily 等刷新频率  

**实施方案**:
```bash
# 新增 kb_incremental.py 或增强 kb_backfill.py
python tools/kb_backfill.py --since-seen <timestamp> \
                             --stale-check 30 \
                             --delta-mode \
                             --report
```

**优先级**: ⭐⭐⭐ (高)  
**工作量**: 2-3 天

---

### 2️⃣ 数据来源溯源不足

**问题**: 语料页有 `url/source`，但**缺少单字段的来源追溯**  
**影响**: 无法回答"这句话来自哪个 URL"，降低可信度  

**实施方案**:
```yaml
# _meta/schema.json 扩展
fields:
  - name: quotes
    type: array
    description: "extracted segments with source_url and confidence"
  - name: attribution_score
    type: float
    description: "how much of this field is grounded in actual sources"
```

**优先级**: ⭐⭐ (中)  
**工作量**: 1-2 天

---

### 3️⃣ 引用网络可视化缺失

**问题**: 项目间/人物间的引用关系未显式建模  
**影响**: 无法分析"哪些项目常被一起讨论"、"谁在引用谁"  

**实施方案**:
```python
# 新增工具：co_mention miner
python tools/kb_citation_net.py --build --graphviz-export
# 在项目页增加「引用网络」表
```

**优先级**: ⭐⭐ (中)  
**工作量**: 2-3 天

---

### 4️⃣ 缺少多语言场景覆盖

**问题**: 中文渠道（小红书/B 站）目前覆盖率低  
**影响**: 错过大量中文独立开发者社区内容  

**实施方案**:
```yaml
# _meta/channels.yaml 追加
xiaohongshu:
  enabled: true
  topics: ["独立开发", "SaaS 中国", "副业项目"]

bilibili:
  layer: signal  # 可扩展视频字幕提取
```

**优先级**: ⭐⭐⭐ (高，符合用户地域)  
**工作量**: 1 天

---

### 5️⃣ 缺少主动 Alert 机制

**问题**: 只能被动查询，无法订阅项目/话题的变化  
**影响**: 无法像 BuilderPulse 那样每日简报  

**实施方案**:
```bash
# 新增 kb_alert.py
python tools/kb_alert.py subscribe --project "ObsidianMSA" \
                                    --trigger "comment_count>+50%"
python tools/kb_alert.py check  # 每日采集后触发
```

**优先级**: ⭐ (低，锦上添花)  
**工作量**: 1-2 天

---

### 6️⃣ 缺少 Benchmark 与性能基线

**问题**: 无明确的采集成功率/覆盖率指标  
**影响**: 难以量化进步，无法跟 AutoData 的 Instruct2DS 对标  

**实施方案**:
```python
# 新增 kb_benchmark.py
python tools/kb_benchmark.py evaluate \
    --target-db "product_hunt_archive" \
    --metrics recall precision freshness
```

**优先级**: ⭐⭐ (中)  
**工作量**: 2 天
