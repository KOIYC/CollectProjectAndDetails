## ⚠️ **三、发现问题汇总**

### **P1 (高优): Unicode 编码问题**

**位置**: `tools/kb_healthcheck.py` L218

**现象**:
```python
print(f"·路径漂移：slug {len(drift)} + ↔修正{len(extra)}/{ghost}…")
# ↑ 箭头字符在 Windows GBK 终端无法显示
```

**影响**: 终端输出乱码，但不影响程序正常运行

**修复方案**:
```python
# 方案 1: 替换为 ASCII
print(f"- Path drift: slug {len(drift)}, fixed {len(extra)}/{ghost}")

# 方案 2: 设置环境变量
export PYTHONUTF8=1  # Bash
set PYTHONUTF8=1      # CMD/Powershell
```

**优先级**: ⭐⭐ P1  
**工作量**: 10 分钟
