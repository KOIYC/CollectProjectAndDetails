### **2. "数据库视图" (浏览.md L52-140)**

当前提供 **8 种视图切换**：
1. 按赛道分组
2. 按渠道分组  
3. 按发布日排序
4. 按采集批次分组
5. 项目池
6. 历史实体
7. 人物
8. 渠道健康

#### ✅ **优点**
- **灵活**: 一键切换维度
- **可过滤**: 支持条件筛选
- **分层**: 主表 + 子表钻取

#### ⚠️ **问题**
1. **信息过载**: 表格列太多（title/source/topic/kind/pub_day/comments_count/url），桌面小屏看不清
2. **缺少聚合统计**: 每组有多少条？中位值？最大值？
3. **缺少高亮异常**: 哪些是低质条目需要复核？
4. **缺少交互**: 无法点击某组只看这一维（需手动改 filter）

#### 💡 **改进建议**

**A. 精简默认视图列**
```base
views:
  - type: table
    name: 语料·精选字段
    filters:
      and:
        - 'type == "corpus"'
        - 'available == true'  # 只显示可用
    columns:           # 只展这 6 列，其余折叠
      - title
      - topic
      - source_name
      - published_at
      - comments_count
      - quality_flag    # 新增：质量标记
    groupBy:
      property: topic   # 默认按赛道分组
```

**B. 增加"维度摘要卡片"**
在每组的标题旁显示统计：
```
📂 AI 工具/Agent (968 条 | 中位评论=5 | 最新=2 天前)
├─ `[[Project A]]` → 15 条评论
├─ `[[Project B]]` → 8 条评论
└─ ...
```

**C. 新增"异常监控"视图**
```base
views:
  - type: table
    name: ⚠️ 需要人工复核
    filters:
      and:
        - 'type == "corpus"'
        - or:
          - 'quality == "summary"'          # 正文不完整
          - 'comments_count > 100'         # 超常热度（可能误判）
          - 'published_at is null'         # 缺发布时间
          - 'project_url is null'          # 缺归并键
    order:
      - quality_flag DESC
      - comments_count DESC
```
